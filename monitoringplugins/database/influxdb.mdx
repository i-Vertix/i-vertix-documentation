## Description

Monitors InfluxDB through its HTTP API: connection time, database statistics, HTTP server and write statistics, and the results of queries.

The plugin pack provides these checks:

* [InfluxDB Connection time](#database-influxdb-connection-time)
* [InfluxDB Database statistics](#database-influxdb-database-statistics)
* [InfluxDB HTTP Server statistics](#database-influxdb-http-server-statistics)
* [InfluxDB Query](#database-influxdb-query)
* [InfluxDB Write statistics](#database-influxdb-write-statistics)

<summary>

### InfluxDB Query {/* #database-influxdb-query */}

</summary>

#### Macros

<div className="plugin-pack-macros">

| Macro | Default value | Description |
|-------|---------------|-------------|
| `QUERY` |  | Set a InfluxQL query. Query option must be like --query='label,query'. Query must contain an "AS" keyword to rename the column of the selected data, and must match the label. (Example: --query='mymetric,SELECT the_data AS "mymetric" FROM "database"."retention"."measurement" GROUP BY "instance"') |
| `INSTANCE` |  | Set the instance label on which the results should be calculate for (Example: --instance='name'). The instance label must be the same label as the "GROUP BY" keyword. |
| `OUTPUT` |  | Set the output for each instances (Example: --output='Object %\{instance\} value is \{label\}') |
| `MULTIPLE-OUTPUT` |  | Set the global output in case everything is fine for multiple instances (Example: --multiple-output='All instance values are ok') |
| `AGGREGATION` |  | Set the aggregation on metric values (Can be: 'average', 'min', 'max', 'sum') (Default: 'average') |
| `WARNING-STATUS` |  | Set warning threshold for status (Default: ''). Can use special variables like %\{instance\} and any other labels you set through --query |
| `CRITICAL-STATUS` |  | Set critical threshold for status (Default: ''). Can use special variables like %\{instance\} and any other labels you set through --query |

</div>

</details>

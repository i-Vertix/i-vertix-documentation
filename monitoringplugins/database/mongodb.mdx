## Description

Monitors MongoDB: connection time and connections, database and collection statistics, queries and the replication status.

The plugin pack provides these checks:

* [MongoDB Collection statistics](#database-mongodb-collection-statistics)
* [MongoDB Connection time](#database-mongodb-connection-times)
* [MongoDB Connections](#database-mongodb-connections)
* [MongoDB Database statistics](#database-mongodb-database-statistics)
* [MongoDB Queries](#database-mongodb-queries)
* [MongoDB Replication Status](#database-mongodb-replications-status)

## Discovery

### Service Discovery

The service discovery creates one service per discovered object, with these rules:

| Service template | Service name |
|------------------|--------------|
| [MongoDB Collection statistics](#database-mongodb-collection-statistics) | `MongoDB Collection statistics - <name>` |
| [MongoDB Database statistics](#database-mongodb-database-statistics) | `MongoDB Database statistics - <name>` |

See [Service Discovery](/monitoring/monitoring-resources/discovery/service-discovery) for how to run it.

| `CRITICAL-INSTANCE-LAG` | `-120:120` | Threshold critical for replication lag between primary and secondary members. Must not be over 0 (between minus slaveDelay and 0) |
| `WARNING-STATUS` |  | Set warning threshold for checked instance status (Default: ''). Can used special variables like: %\{state\}, %\{sync_host\} |

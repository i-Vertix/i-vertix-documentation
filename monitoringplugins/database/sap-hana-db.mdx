## Description

Monitors SAP HANA databases through SQL queries: connection time, connected users, blocked transactions, disk and volume usage, and host CPU and memory usage.

The plugin pack provides these checks:

* [SAP HANA - Blocked transactions](#database-sap-hana-blocked-transactions)
* [SAP HANA - Connected users](#database-sap-hana-connected-users)
* [SAP HANA - Connection time](#database-sap-hana-connection-time)
* [SAP HANA - Disk usage](#database-sap-hana-disk-usage)
* [SAP HANA - Host CPU usage](#database-sap-hana-host-cpu)
* [SAP HANA - Host memory usage](#database-sap-hana-host-memory)
* [SAP HANA - Volume usage](#database-sap-hana-volume-usage)

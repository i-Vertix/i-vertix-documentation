## Description

Monitors Firebird databases through SQL queries: connection time, long queries, memory usage, page and query statistics, SQL requests and connected users.

The plugin pack provides these checks:

* [Firebird connection time](#database-firebird-connection-time)
* [Firebird long queries](#database-firebird-long-queries)
* [Firebird memory](#database-firebird-memory)
* [Firebird pages](#database-firebird-pages)
* [Firebird queries](#database-firebird-queries)
* [Firebird SQL](#database-firebird-sql)
* [Firebird users](#database-firebird-users)

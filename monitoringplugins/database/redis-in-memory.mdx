## Description

Monitors Redis servers through SSH: clients, commands, connections, CPU, memory, persistence and replication.

The plugin pack provides these checks:

* [Redis Clients](#database-redis-cli-clients) (`database-redis-cli-clients`)
* [Redis Clients](#database-redis-perlmod-clients) (`database-redis-perlmod-clients`)
* [Redis Commands](#database-redis-cli-commands) (`database-redis-cli-commands`)
* [Redis Commands](#database-redis-perlmod-commands) (`database-redis-perlmod-commands`)
* [Redis Connections](#database-redis-cli-connections) (`database-redis-cli-connections`)
* [Redis Connections](#database-redis-perlmod-connections) (`database-redis-perlmod-connections`)
* [Redis CPU](#database-redis-cli-cpu) (`database-redis-cli-cpu`)
* [Redis CPU](#database-redis-perlmod-cpu) (`database-redis-perlmod-cpu`)
* [Redis Memory](#database-redis-cli-memory) (`database-redis-cli-memory`)
* [Redis Memory](#database-redis-perlmod-memory) (`database-redis-perlmod-memory`)
* [Redis Persistence](#database-redis-cli-persistence) (`database-redis-cli-persistence`)
* [Redis Persistence](#database-redis-perlmod-persistence) (`database-redis-perlmod-persistence`)

## Host Templates

### Redis-DB-cli

*Redis in-memory data structure store - CLI* · Parent template: `generic-host`

<details className="plugin-pack-details">
<summary>Macros (10)</summary>

<div className="plugin-pack-macros">

| Macro | Default value | Description |
|-------|---------------|-------------|
| `SSH-BACKEND` | `sshcli` | Define the backend you want to use. It can be: `sshcli` (default for most plugins), `plink` and `libssh`. |
| `SSHCLI-OPTION` | `-o=StrictHostKeyChecking=no` | Specify SSH CLI options (example: --sshcli-option='-o=StrictHostKeyChecking=no -o=LogLevel=ERROR'). The default parameter is --sshcli-option='-o=LogLevel=ERROR' which hides the SSH banner. If you override this parameter, make sure to append '-o=LogLevel=ERROR' to your new value to maintain this behavior. This parameter can be used multiple times and multiple options can be specified in the same parameter. |
| `REDIS-PORT` | `6379` | Redis port (default: 6379). |
| `REDIS-SERVER` | `127.0.0.1` | Redis server. |
| `SSHCLI-OPTION2` | `-o=LogLevel=ERROR` | hides the SSH banner |
| `REDIS-EXTRAOPTS` |  |  |
| `REDIS-USERNAME` |  | Redis username (redis-cli >= 6.x mandatory). |
| `SSH-PASSWORD` |  | Define the password associated with the user name. Cannot be used with the `sshcli` backend. Warning: using a password is not recommended. Use `--ssh-priv-key` instead. |
| `SSH-PRIV-KEY` |  | Define the private key file to use for user authentication. |
| `SSH-USERNAME` |  | Define the user name to log in to the host. |

</div>

Macros without a default value are only defined in the check commands. Set them on the host where needed.

</details>

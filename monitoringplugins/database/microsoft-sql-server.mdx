## Description

Monitors Microsoft SQL Server: connection time and connected users, database and log sizes, backups, blocked processes, deadlocks, locks, cache, page life expectancy, jobs, transactions and custom SQL queries.

The plugin pack provides these checks:

* [MS SQL Backup age](#database-mssql-backup-age)
* [MS SQL Blocked processes](#database-mssql-blocked-processes)
* [MS SQL Cache hitratio](#database-mssql-cache-hitratio)
* [MS SQL collection](#database-mssql-collection)
* [MS SQL Connected users](#database-mssql-connected-users)
* [MS SQL Connection time](#database-mssql-connection-time)
* [MS SQL custom SQL (number)](#database-mssql-sql)
* [MS SQL custom SQL (string)](#database-mssql-sql-string)
* [MS SQL Databases size](#database-mssql-databases-size)
* [MS SQL Dead locks](#database-mssql-dead-locks)
* [MS SQL Failed jobs](#database-mssql-failed-jobs)
* [MS SQL Locks wait](#database-mssql-locks-wait)
* [MS SQL Page Live Expectancy](#database-mssql-page-life-expectancy)
* [MS SQL Tables](#database-mssql-tables)
* [MS SQL Transactions](#database-mssql-transactions)

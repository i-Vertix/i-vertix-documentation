## Description

Monitors IBM Informix databases: connection time, sessions, dbspace and chunk states, checkpoints, logfile usage, locks, long transactions, cache, level-0 backups and SQL requests.

The plugin pack provides these checks:

* [Informix Archive Level-0 backup execution time](#database-informix-sql-archivelevel0)
* [Informix Checkpoints](#database-informix-sql-checkpoints)
* [Informix Chunk states](#database-informix-sql-chunkstates)
* [Informix Connection time](#database-informix-sql-connection-time)
* [Informix Database space usage](#database-informix-sql-dbspace-usage)
* [Informix Global cache](#database-informix-sql-global-cache)
* [Informix Lockoverflow](#database-informix-sql-lockoverflow)
* [Informix Logfile usage](#database-informix-sql-logfile-usage)
* [Informix Long TXS](#database-informix-sql-longtxs)
* [Informix Sessions](#database-informix-sql-sessions)
* [Informix SQL](#database-informix-sql-sql)
* [Informix Table locks](#database-informix-sql-table-locks)

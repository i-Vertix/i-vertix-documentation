## Description

Monitors MariaDB and MySQL servers through SQL queries: connection time, database sizes, buffer and cache hit rates, queries, threads, open files and tables, replication, backups and uptime.

The plugin pack provides these checks:

* [MariaDB Backup](#database-mysql-backup)
* [MariaDB collection](#database-mysql-collection)
* [MariaDB Connection time](#database-mysql-connection-time)
* [MariaDB Databases size](#database-mysql-databases-size)
* [MariaDB Innodb bufferpool hitrate](#database-mysql-innodb-bufferpool-hitrate)
* [MariaDB long queries](#database-mysql-long-queries)
* [MariaDB Myisam keycache hitrate](#database-mysql-myisam-keycache-hitrate)
* [MariaDB Open files](#database-mysql-open-files)
* [MariaDB Open tables](#database-mysql-open-tables)
* [MariaDB Password expiration](#database-mysql-password-expiration)
* [MariaDB Qcache hitrate](#database-mysql-qcache-hitrate)
* [MariaDB Queries usage](#database-mysql-queries)
* [MariaDB Replication](#database-mysql-replication)
* [MariaDB Slow queries](#database-mysql-slowqueries)
* [MariaDB Threads connected](#database-mysql-threadsconnected)
* [MariaDB Uptime](#database-mysql-uptime)
* [SQL](#database-mysql-sql)
* [SQL string](#database-mysql-sql-string)

## Description

Monitors IBM DB2 databases: connection time and connected users, database and tablespace usage, transaction logs and high availability disaster recovery (HADR) status.

The plugin pack provides these checks:

* [Connected users](#database-db2-connected-users)
* [Connection time](#database-db2-connections-time)
* [Database Logs](#database-db2-database-logs)
* [Database space usage](#database-db2-database-usage)
* [Database Tablespace usage](#database-db2-tablespaces)
* [HA - DR](#database-db2-hadr)

## Discovery

## Host Templates

### DB2

*DB2 database server* · Parent template: `generic-host`

<details className="plugin-pack-details">
<summary>Macros (6)</summary>

<div className="plugin-pack-macros">

| Macro | Default value | Description |
|-------|---------------|-------------|
| `DB2-PORT` | `5000` | TCP/IP server port number that is assigned to the Db2 database system |
| `DB2-TIMEOUT` | `10` | Timeout in seconds for connection. |
| `DB2-PASSWORD` | *(password)* | Password for the defined user name. |
| `DB2-CONNECT-OPTIONS` |  | Add connection options for the DBI connect method. Format: name=value,name2=value2,... |
| `DB2-DATABASE` |  | Name for the Db2 database system. If --server is not set, it's a cataloged connection (database alias). |
| `DB2-USERNAME` |  | User name used to connect to the database. |

</div>

Macros without a default value are only defined in the check commands. Set them on the host where needed.

</details>

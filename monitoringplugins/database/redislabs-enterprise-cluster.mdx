## Description

Monitors Redis Enterprise clusters through the REST API: statistics of the cluster, nodes, databases and shards.

The plugin pack provides these checks:

* [Cluster Stats](#apps-redis-rlec-restapi-cluster-stats)
* [Databases Stats](#apps-redis-rlec-restapi-databases-stats)
* [Nodes Stats](#apps-redis-rlec-restapi-nodes-stats)
* [Shards Stats](#apps-redis-rlec-restapi-shards-stats)

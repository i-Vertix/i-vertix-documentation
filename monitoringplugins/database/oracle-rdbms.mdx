## Description

Monitors Oracle databases: connection time, sessions, tablespaces and data files, caches, redo logs, RMAN backups, Data Guard, ASM disk groups, fast recovery area and TNS ping.

The plugin pack provides these checks:

* [Oracle ASM Diskgroup usage](#database-oracle-asm-diskgroup-usage)
* [Oracle collection](#database-oracle-collection)
* [Oracle Connected users](#database-oracle-connected-users)
* [Oracle Connection time](#database-oracle-connection-time)
* [Oracle Corrupted blocks](#database-oracle-corrupted-blocks)
* [Oracle Data File status](#database-oracle-data-files-status)
* [Oracle Datacache hitratio](#database-oracle-datacache-hitratio)
* [Oracle Dataguard](#database-oracle-dataguard)
* [Oracle Dictionary Cache usage](#database-oracle-dictionary-cache-usage)
* [Oracle Event Waits usage](#database-oracle-event-waits-usage)
* [Oracle Fast Recovery usage](#database-oracle-fra-usage)
* [Oracle Invalid Objects](#database-oracle-invalid-object)
* [Oracle Library Cache usage](#database-oracle-library-cache-usage)
* [Oracle Long Queries](#database-oracle-long-queries)
* [Oracle Password expiration](#database-oracle-password-expiration)
* [Oracle Process usage](#database-oracle-process-usage)
* [Oracle Redolog usage](#database-oracle-redolog-usage)
* [Oracle RMAN backup age](#database-oracle-rman-backup-age)
* [Oracle RMAN backup problems](#database-oracle-rman-backup-problems)
* [Oracle RMAN Online backup problems](#database-oracle-rman-online-backup-age)
* [Oracle Rollback Segment usage](#database-oracle-rollback-segment-usage)

| `FILTER-NAME` |  | Filter by name (regexp can be used) |
| `WARNING-USAGE-FAILURE` |  | Threshold warning usage failure |
| `CRITICAL-USAGE-FAILURE` |  | Threshold critical usage failure |
| `WARNING-OFFLINE-DISKS` |  | Set warning threshold for offline disks (Default: '(%\{offline_disks\} > 0 && %\{type\} eq "extern") \|\| (%\{offline_disks\} > 1 && %\{type\} eq "high")'). Can used special variables like: %\{offline_disks\}, %\{type\}, %\{display\} |

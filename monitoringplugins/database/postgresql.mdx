## Description

Monitors PostgreSQL databases: connections, database size, hit ratio, locks, bloat, vacuum, query time, tablespaces, statistics, time synchronization and custom SQL queries.

The plugin pack provides these checks:

* [Backends](#database-postgres-backends)
* [Bloat](#database-postgres-bloat)
* [Connection time](#database-postgres-connection-time)
* [Database size](#database-postgres-database-size)
* [Hitratio](#database-postgres-hitratio)
* [Locks](#database-postgres-locks)
* [Query time](#database-postgres-query-time)
* [SQL numeric](#database-postgres-sql)
* [SQL string](#database-postgres-sql-string)
* [Statistics](#database-postgres-statistics)
* [Tablespace](#database-postgres-tablespace)
* [Timesync](#database-postgres-timesync)
* [Vacuum](#database-postgres-vacuum)

## Discovery

### Service Discovery

The service discovery creates one service per discovered object, with these rules:

| Service template | Service name |
|------------------|--------------|
| [Database size](#database-postgres-database-size) | `Database size - <name>` |
| [Statistics](#database-postgres-statistics) | `Statistics - <name>` |

See [Service Discovery](/monitoring/monitoring-resources/discovery/service-discovery) for how to run it.

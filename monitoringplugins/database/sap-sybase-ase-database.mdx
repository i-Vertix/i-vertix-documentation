## Description

Monitors SAP Sybase ASE databases: connection time, connected users, blocked processes, database sizes and custom SQL queries.

The plugin pack provides these checks:

* [ASE Blocked processes](#database-sybase-blocked-processes)
* [ASE Connected users](#database-sybase-connected-users)
* [ASE Connection time](#database-sybase-connection-time)
* [Sybase Databases Size](#database-sybase-databases-size)
* [Sybase SQL](#database-sybase-sql)

## Description

Monitors Apache CouchDB servers through the HTTP API: database size and the number of current and deleted documents.

The plugin pack provides these checks:

* [CouchDB Server](#database-couchdb-restapi-server)


## Host Templates

### Apache-CouchDB

*Apache CouchDB* · Parent template: `generic-host`

<details className="plugin-pack-details">
<summary>Macros (6)</summary>

| Macro | Default value | Description |
|-------|---------------|-------------|
| `PORT` | `5984` | Port used (default: 5984) |

#### Macros

<div className="plugin-pack-macros">

| Macro | Default value | Description |
|-------|---------------|-------------|
| `FILTER-DB-NAME` | `.*` | Filter database name (can be a regexp) |
| `CRITICAL-STATUS` | `'%{status} !~ /^ok/i'` | Set critical threshold for status (Default: '%\{status\} !~ /^ok/i'). Can used special variables like: %\{status\} |
| `UNKNOWN-STATUS` |  | Set unknown threshold for status (Default: ''). Can used special variables like: %\{status\} |
| `UNKNOWN-COMPACTION-STATUS` |  | Set unknown threshold for status (Default: ''). Can used special variables like: %\{compaction_status\}, %\{display\} |
| `WARNING-STATUS` |  | Set warning threshold for status (Default: ''). Can used special variables like: %\{status\} |
| `WARNING-COMPACTION-STATUS` |  | Set warning threshold for status (Default: ''). Can used special variables like: %\{compaction_status\}, %\{display\} |
| `WARNING-DATABASE-SIZE-ACTIVE` |  | Threshold warning database size active (B) |
| `WARNING-DATABASE-SIZE-FILE` |  | Threshold warning database size file (B) |
| `WARNING-DATABASE-DOCUMENTS-DELETED` |  | Threshold warning database documents deleted |
| `WARNING-DATABASE-DOCUMENTS-CURRENT` |  | Threshold warning database documents current |
| `CRITICAL-COMPACTION-STATUS` |  | Set critical threshold for status (Default: ''). Can used special variables like: %\{compaction_status\}, %\{display\} |
| `CRITICAL-DATABASE-SIZE-ACTIVE` |  | Threshold critical database size active (B) |
| `CRITICAL-DATABASE-SIZE-FILE` |  | Threshold critical  database size file (B) |

</div>

#### Metrics

<div className="plugin-pack-macros">

| Metric | Unit | Description | Threshold macros |
|--------|------|-------------|------------------|

| `server.database.documents.deleted.count` |  | number of deleted documents | `WARNING-DATABASE-DOCUMENTS-DELETED`, `CRITICAL-DATABASE-DOCUMENTS-DELETED` |

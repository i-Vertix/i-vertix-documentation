## Description

Monitors a legacy i-Vertix3 poller: broker statistics, the platform processes (centengine, gorgone, snmptrapd and others), SMTP login and system resources such as CPU, memory, swap and load.

The plugin pack provides these checks:

* [CPU](#os-linux-snmp-cpu)
* [CPU detailed](#os-linux-snmp-cpu-detailed)
* [Disk IO](#os-linux-snmp-diskio)
* [i-Vertix Broker stats - Poller](#apps-centreon-local-broker-stats-poller)
* [Memory](#os-linux-snmp-memory-no-swap)
* [NTP](#os-linux-snmp-time)
* [Process - centengine](#os-linux-snmp-processcount-centengine)
* [Process - centreontrapd](#os-linux-snmp-processcount-centreontrapd)
* [Process - gorgone-action](#os-linux-snmp-processcount-gorgone-action)
* [Process - gorgone-dbclean](#os-linux-snmp-processcount-gorgone-dbclean)
* [Process - gorgone-engine](#os-linux-snmp-processcount-gorgone-engine)
* [Process - rsyslogd](#os-linux-snmp-processcount-rsyslogd)
* [Process - snmptrapd](#os-linux-snmp-processcount-snmptrapd)
* [SMTP login](#apps-protocols-smtp-login)
* [Swap](#os-linux-snmp-swap)
* [System Load](#os-linux-snmp-load)
* [TCP connections](#os-linux-snmp-tcpcon)
* [UDP connections](#os-linux-snmp-udpcon)
* [Uptime](#os-linux-snmp-uptime)

## Description

Monitors Microsoft Exchange on-premises servers through the i-Vertix agent: database status, mailboxes, queues, replication health, services and mailbox connections via ActiveSync, IMAP, MAPI and OWA.

The plugin pack provides these checks:

* [Activesync connection to a mailbox](#ivertix-agent-apps-microsoft-exchange-local-activesync-mailbox)
* [Exchange Database status](#ivertix-agent-apps-microsoft-exchange-local-databases)
* [Exchange Mailboxes status](#ivertix-agent-apps-microsoft-exchange-local-mailboxes)
* [Exchange Queues](#ivertix-agent-apps-microsoft-exchange-local-queues)
* [Exchange Replication Health](#ivertix-agent-apps-microsoft-exchange-local-replication-health)
* [Exchange Services](#ivertix-agent-apps-microsoft-exchange-local-services)
* [IMAP connection to a mailbox](#ivertix-agent-apps-microsoft-exchange-local-imap-mailbox)
* [MAPI connection to a mailbox](#ivertix-agent-apps-microsoft-exchange-local-mapi-mailbox)
* [OWA connection to a mailbox](#ivertix-agent-apps-microsoft-exchange-local-owa-mailbox)

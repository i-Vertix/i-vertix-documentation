## Description

Monitors Windows DHCP servers through SNMP: the address usage and pending offers of subnets, and the state of the DHCP server service.

The plugin pack provides these checks:

* [DHCP Subnet status](#apps-microsoft-dhcp-subnets)
* [Service DHCP Server](#os-windows-snmp-service-dhcp-server)

## Discovery

### Service Discovery

The service discovery creates one service per discovered object, with these rules:

| Service template | Service name |
|------------------|--------------|
| [DHCP Subnet status](#apps-microsoft-dhcp-subnets) | `DHCP Subnet status - <address>` |

See [Service Discovery](/monitoring/monitoring-resources/discovery/service-discovery) for how to run it.

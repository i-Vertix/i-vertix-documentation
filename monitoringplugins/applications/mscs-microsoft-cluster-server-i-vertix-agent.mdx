## Description

Monitors Microsoft Cluster Server (MSCS) through the i-Vertix agent: the status of nodes, networks, resources and resource groups.

The plugin pack provides these checks:

* [MSCS Network status](#ivertix-agent-apps-microsoft-mscs-local-network-status)
* [MSCS Node status](#ivertix-agent-apps-microsoft-mscs-local-node-status)
* [MSCS Resource status](#ivertix-agent-apps-microsoft-mscs-local-resource-status)
* [MSCS Resourcegroup status](#ivertix-agent-apps-microsoft-mscs-local-resourcegroup-status)

## Discovery

### Service Discovery

The service discovery creates one service per discovered object, with these rules:

| Service template | Service name |
|------------------|--------------|
| [MSCS Node status](#ivertix-agent-apps-microsoft-mscs-local-node-status) | `MSCS Node status - <path>` |
| [MSCS Resource status](#ivertix-agent-apps-microsoft-mscs-local-resource-status) | `MSCS Resource status - <path>` |

See [Service Discovery](/monitoring/monitoring-resources/discovery/service-discovery) for how to run it.

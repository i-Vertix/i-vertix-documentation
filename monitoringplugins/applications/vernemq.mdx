## Description

Monitors VerneMQ MQTT brokers through the HTTP API: cluster nodes, listeners, plugins and sessions.

The plugin pack provides these checks:

* [Clusters](#apps-mq-vernemq-restapi-clusters)
* [Listeners](#apps-mq-vernemq-restapi-listeners)
* [Plugins](#apps-mq-vernemq-restapi-plugins)
* [Sessions](#apps-mq-vernemq-restapi-sessions)

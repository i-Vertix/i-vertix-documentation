## Description

Monitors JBoss (Red Hat) application servers through JMX over HTTP: memory, threads, loaded classes and datasource connection usage.

The plugin pack provides these checks:

* [JBoss Class count](#apps-java-jboss-jmx-class-count)
* [JBoss Datasource usage](#apps-java-jboss-jmx-datasource-usage)
* [JBoss Memory](#apps-java-jboss-jmx-memory)
* [JBoss Memory Detailed](#apps-java-jboss-jmx-memory-detailed)
* [JBoss Threads](#apps-java-jboss-jmx-threads)

## Discovery

### Service Discovery

The service discovery creates one service per discovered object, with these rules:

| Service template | Service name |
|------------------|--------------|
| [JBoss Datasource usage](#apps-java-jboss-jmx-datasource-usage) | `JBoss Datasource usage - <name>` |

See [Service Discovery](/monitoring/monitoring-resources/discovery/service-discovery) for how to run it.

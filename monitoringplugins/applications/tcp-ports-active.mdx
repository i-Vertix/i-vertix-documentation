## Description

Monitors TCP ports with active checks: connection status, response time, round-trip time and packet loss.

The plugin pack provides these checks:

* [TCP connection status](#apps-protocols-tcp-connection-status)
* [TCP response time](#apps-protocols-tcp-response-time)

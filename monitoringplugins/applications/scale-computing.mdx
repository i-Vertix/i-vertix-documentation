## Description

Monitors Scale Computing clusters through the REST API: cluster status, nodes, drives, virtual domains and virtual disk usage.

The plugin pack provides these checks:

* [Cluster status](#apps-scalecomputing-restapi-cluster-status)
* [Drive usage](#apps-scalecomputing-restapi-drive-usage)
* [Node usage](#apps-scalecomputing-restapi-node-usage)
* [Virtual disk usage](#apps-scalecomputing-restapi-virtual-domain-block-device-usage)
* [Virtual domain status](#apps-scalecomputing-restapi-virtual-domain-status)

## Discovery

### Service Discovery

The service discovery creates one service per discovered object, with these rules:

| [Drive usage](#apps-scalecomputing-restapi-drive-usage) | `vdomain <vir_domain_name> - block dev <uuid>` |
| [Virtual domain status](#apps-scalecomputing-restapi-virtual-domain-status) | `Virtual domain status - <name>` |

</div>

See [Service Discovery](/monitoring/monitoring-resources/discovery/service-discovery) for how to run it.

## Description

Monitors Java applications that expose Spring Boot Actuator over HTTP: JVM memory, threads, loaded classes, CPU load, system load and file descriptor usage.

The plugin pack provides these checks:

* [JVM class count](#apps-java-jvm-actuator-class-count)
* [JVM cpu load](#apps-java-jvm-actuator-cpu-load)
* [JVM fd usage](#apps-java-jvm-actuator-fd-usage)
* [JVM load average](#apps-java-jvm-actuator-load-average)
* [JVM memory](#apps-java-jvm-actuator-memory)
* [JVM memory detailed](#apps-java-jvm-actuator-memory-detailed)
* [JVM threads](#apps-java-jvm-actuator-threads)

## Description

Monitors DNS servers with active DNS requests, checking that names are resolved.

The plugin pack provides these checks:

* [DNS request](#apps-protocols-dns-request) (`apps-protocols-dns-request`)

#### Macros

<div className="plugin-pack-macros">

| Macro | Default value | Description |
|-------|---------------|-------------|
| `SEARCH` | `google.com` | Set the search value (required) |
| `WARNING` | `1` | Threshold warning in seconds |
| `CRITICAL` | `2` | Threshold critical in seconds |
| `SEARCH-TYPE` | `A` | Set the search type. Can be: 'MX', 'SOA', 'NS', 'A', 'CNAME' or 'PTR'. 'A' or 'PTR' is used by default (depends if an IP or not) |
| `EXPECTED-ANSWER` |  | What the server must answer (can be a regexp) |

</div>

</details>

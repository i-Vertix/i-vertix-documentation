## Description

Monitors Eclipse Mosquitto MQTT brokers through the broker statistics: connected clients, messages, uptime and the values of selected topics.

The plugin pack provides these checks:

* [Clients](#apps-eclipse-mosquitto-mqtt-clients)
* [Messages](#pps-eclipse-mosquitto-mqtt-messages)
* [Uptime](#apps-eclipse-mosquitto-mqtt-uptime)
* [Value](#apps-eclipse-mosquitto-mqtt-numeric-value) (`apps-eclipse-mosquitto-mqtt-numeric-value`)
* [Value](#apps-eclipse-mosquitto-mqtt-string-value) (`apps-eclipse-mosquitto-mqtt-string-value`)

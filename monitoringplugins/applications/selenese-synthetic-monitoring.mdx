## Description

Monitors web applications with Selenese scenarios run through a headless browser (Chrome or Firefox) and reports the result of each scenario.

The plugin pack provides these checks:

* [Scenario](#apps-selenese-scenario) (`apps-selenese-scenario`)
* [Scenario](#legacy-apps-selenese-scenario-chrome) (`legacy-apps-selenese-scenario-chrome`)
* [Scenario](#legacy-apps-selenese-scenario-firefox) (`legacy-apps-selenese-scenario-firefox`)

#### Macros

<div className="plugin-pack-macros">

| Macro | Default value | Description |
|-------|---------------|-------------|
| `TIMEOUT` | `50` | Set global execution timeout (Default: 60) |
| `STEP-TIMEOUT` | `30` | Set step timeout (Default: 30) |
| `WARNING` | `10` | Threshold warning in seconds (Scenario execution time) |
| `CRITICAL` | `30` | Threshold critical in seconds (Scenario execution response time) |
| `LOG-PATH` | `/var/log/selenese/selenese.log` | ath for the selenese output. Enabled only when --debug is set.             (Default: /tmp/selenese.log) |
| `BROWSER` |  | Browser used by selenese runner. Could be chrome or firefox (Default : 'chrome') |
| `BROWSER-DRIVER` |  | Browser driver used by selenese runner (Default : '/usr/local/selenese/chromedriver') |
| `SCENARIO` |  | Scenario used by Selenium server (with extension: .side or .html) |
| `EXTRA-OPT` |  |  |

</div>

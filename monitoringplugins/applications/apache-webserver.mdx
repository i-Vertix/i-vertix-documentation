## Description

Monitors Apache web servers through the HTTP status page: CPU usage, requests, response time, worker slot states and the number of workers.

The plugin pack provides these checks:

* [Apache CPU](#apps-apache-serverstatus-cpu)
* [Apache requests](#apps-apache-serverstatus-requests)
* [Apache response time](#apps-apache-serverstatus_responsetime)
* [Apache slot states](#apps-apache-serverstatus-slotstates)
* [Apache workers](#apps-apache-serverstatus-workers)

## Description

Monitors Dynatrace through its API: application Apdex, synthetic monitor availability, events and open problems.

The plugin pack provides these checks:

* [Dynatrace apdex](#apps-monitoring-dynatrace-restapi-apdex)
* [Dynatrace availability](#apps-monitoring-dynatrace-restapi-availability)
* [Dynatrace events](#apps-monitoring-dynatrace-restapi-events)
* [Dynatrace problems](#apps-monitoring-dynatrace-restapi-problems)

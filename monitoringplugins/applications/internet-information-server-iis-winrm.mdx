## Description

Monitors Microsoft IIS through WinRM: the state of the application pools and the W3SVC service.

The plugin pack provides these checks:

* [Application pool](#apps-microsoft-iis-wsman-application-pools)
* [Service status - W3SVC](#os-windows-wsman-services-w3svc)

## Discovery

### Service Discovery

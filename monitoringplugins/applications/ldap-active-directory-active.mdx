## Description

Monitors LDAP and Active Directory servers with active checks: login and search requests.

The plugin pack provides these checks:

* [LDAP login](#apps-protocols-ldap-login)
* [LDAP search](#apps-protocols-ldap-search)


## Host Templates

### LDAP search {/* #apps-protocols-ldap-search */}

</summary>

#### Macros

<div className="plugin-pack-macros">

| Macro | Default value | Description |
|-------|---------------|-------------|
| `SEARCH-BASE` |  | Set the DN that is the base object entry relative to which the search is to be performed (required) |
| `SEARCH-FILTER` |  | Set filter that defines the conditions an entry in the directory must meet in order for it to be returned by the search (required) |
| `WARNING-ENTRIES` |  | Threshold warning (number of results) |
| `WARNING-TIME` |  | Threshold warning in seconds |
| `CRITICAL-ENTRIES` |  | Threshold critical (number of results) |
| `CRITICAL-TIME` |  | Threshold critical in seconds |

</div>

#### Metrics

<div className="plugin-pack-macros">

| Metric | Unit | Description | Threshold macros |
|--------|------|-------------|------------------|
| `ldap.request.entries.count` |  | Number of results returned | `WARNING-ENTRIES`, `CRITICAL-ENTRIES` |
| `ldap.request.time.second` | `s` | Response time : s | `WARNING-TIME`, `CRITICAL-TIME` |

</div>

</details>

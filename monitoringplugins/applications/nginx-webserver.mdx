## Description

Monitors NGINX web servers through the status page: accepted and handled connections, dropped connections and requests per second.

The plugin pack provides these checks:

* [NGINX Connections](#apps-nginx-serverstatus-connections)
* [NGINX Requests](#apps-nginx-serverstatus-requests)


## Host Templates

### Nginx-Server

*Nginx Webserver* · Parent template: `generic-host`

<div className="plugin-pack-macros">

| Macro | Default value | Description |

| `NGINX-ENDPOINT` | `/nginx_status` | Set path to get server-status page (default: '/nginx_status') |
| `NGINX-PASSWORD` |  | Specify password for basic authentication |
| `NGINX-PORT` |  | Port used by the web server (default: 80) |
| `NGINX-PROTO` |  | Specify https if needed |
| `NGINX-SSL-OPT` |  | Set SSL Options (--ssl-opt="SSL_version => TLSv1" --ssl-opt="SSL_verify_mode => SSL_VERIFY_NONE"). |
| `NGINX-USERNAME` |  | Specify username for basic authentication. |

</div>

Macros without a default value are only defined in the check commands. Set them on the host where needed.

</details>

## Description

Monitors Commvault CommServe backup environments through the REST API: alerts, jobs, media agents and the space usage of storage pools.

The plugin pack provides these checks:

* [Alerts](#apps-backup-commvault-commserve-restapi-alerts)
* [Jobs](#apps-backup-commvault-commserve-restapi-jobs)
* [Media Agents](#apps-backup-commvault-commserve-restapi-media-agents)
* [Storage Pools](#apps-backup-commvault-commserve-restapi-storage-pools)
* [Token refresh](#apps-backup-commvault-commserve-restapi-token)

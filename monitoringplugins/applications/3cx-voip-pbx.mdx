## Description

Monitors a 3CX VoIP PBX through its API: registered and used extensions, active calls, call and extension capacity, and the license.

The plugin pack provides these checks:

* [Extensions](#apps-voip-3cx-restapi-extension)
* [License](#apps-voip-3cx-restapi-license)
* [System](#apps-voip-3cx-restapi-system)

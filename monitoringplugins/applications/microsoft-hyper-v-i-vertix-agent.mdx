## Description

Monitors Microsoft Hyper-V hosts through the i-Vertix agent: integration services, replication, snapshots, VM status, and CPU, memory, disk and network performance counters.

The plugin pack provides these checks:

* [Hyper-V Node Integration Service status](#ivertix-agent-apps-microsoft-hyperv-local-node-integration-service)
* [Hyper-V Node Replication](#ivertix-agent-apps-microsoft-hyperv-local-node-replication)
* [Hyper-V Node Snapshot](#ivertix-agent-apps-microsoft-hyperv-local-node-snapshot)
* [Hyper-V Node VM status](#ivertix-agent-apps-microsoft-hyperv-local-node-vm-status)
* [Hyper-V: Dynamic Memory Balancer - Average Pressure](#ivertix-nsclient-restapi-check_pdh-hyperv-memory-balancer-average-pressure)
* [Hyper-V: Dynamic Memory VM - Average Pressure](#ivertix-nsclient-restapi-check_pdh-hyperv-dynamic-memory-vm-average-pressure)
* [Hyper-V: Hypervisor Root CPU - Total Run Time](#ivertix-nsclient-restapi-check_pdh-hyperv-hypervisor-cpu-total-run-time)
* [Hyper-V: Logical CPU - Context Switches/Sec](#ivertix-nsclient-restapi-check_pdh-hyperv-logical-cpu-context-switches)
* [Hyper-V: Logical CPU - Total Run Time](#ivertix-nsclient-restapi-check_pdh-hyperv-logical-cpu-total-run-time)
* [Hyper-V: Logical Disk - avg Read latency](#ivertix-nsclient-restapi-check_pdh-hyperv-logical-disk-reads)
* [Hyper-V: Logical Disk - avg Write latency](#ivertix-nsclient-restapi-check_pdh-hyperv-logical-disk-write)
* [Hyper-V: Physical Disk - avg Read latency](#ivertix-nsclient-restapi-check_pdh-hyperv-physical-disk-reads)
* [Hyper-V: Physical Disk - avg Write latency](#ivertix-nsclient-restapi-check_pdh-hyperv-physical-disk-write)
* [Hyper-V: Virtual CPU - Total Run Time](#ivertix-nsclient-restapi-check_pdh-hyperv-virtual-cpu-total-run-time)
* [Network Interface - Output Queue Length](#ivertix-nsclient-restapi-check_pdh-network-interface-output-queue-length)

## Discovery

### Service Discovery

The service discovery creates one service per discovered object, with these rules:

| Service template | Service name |
|------------------|--------------|
| [Hyper-V Node Replication](#ivertix-agent-apps-microsoft-hyperv-local-node-replication) | `Hyper-V Node Replication - <name>` |
| [Hyper-V Node VM status](#ivertix-agent-apps-microsoft-hyperv-local-node-vm-status) | `Node VM Status - <name>` |

See [Service Discovery](/monitoring/monitoring-resources/discovery/service-discovery) for how to run it.

## Description

Monitors an i-Vertix4 monitoring central server: Gorgone, broker statistics, poller delay and database partitioning, together with Apache, MariaDB, PHP-FPM, system resources and the platform processes.

The plugin pack provides these checks:

### Service Discovery

The service discovery creates one service per discovered object, with these rules:

| Service template | Service name |
|------------------|--------------|
| [`os-linux-snmp-inodes`](/monitoringplugins/operating-system/linux-snmp#os-linux-snmp-inodes) | `Inodes <name>` |

See [Service Discovery](/monitoring/monitoring-resources/discovery/service-discovery) for how to run it.

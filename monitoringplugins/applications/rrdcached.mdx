## Description

Monitors RRDcached daemons over TCP and UNIX sockets: availability and statistics such as the queue length and waiting updates.

The plugin pack provides these checks:

* [RRDCached TCP ping](#apps-rrdcached-tcp-ping)
* [RRDCached TCP stats](#apps-rrdcached-tcp-stats)
* [RRDCached UNIX ping](#apps-rrdcached-unix-ping)
* [RRDCached UNIX stats](#apps-rrdcached-unix-stats)

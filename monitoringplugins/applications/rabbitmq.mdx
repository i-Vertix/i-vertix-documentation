## Description

Monitors RabbitMQ through its management API: node, virtual host, queue and system usage, including message counts and disk I/O.

The plugin pack provides these checks:

* [RabbitMQ Node usage](#apps-mq-rabbitmq-restapi-node-usage)
* [RabbitMQ Queue usage](#apps-mq-rabbitmq-restapi-queue-usage)
* [RabbitMQ System usage](#apps-mq-rabbitmq-restapi-system-usage)
* [RabbitMQ VHost usage](#apps-mq-rabbitmq-restapi-vhost-usage)

## Discovery

## Description

Monitors Proxmox VE through its API: node CPU, memory, swap and filesystem usage, storage usage, virtual machine usage (CPU, memory, I/O and network) and the installed version.

The plugin pack provides these checks:

* [Node usage](#apps-proxmox-ve-restapi-node-usage)
* [Storage usage](#apps-proxmox-ve-restapi-storage-usage)
* [Version](#apps-proxmox-ve-restapi-version)
* [VM Usage](#apps-proxmox-ve-restapi-vm-usage)

## Discovery

### Host Discovery

The hosts of this plugin pack are found by these host discoveries:

* [Proxmox-VE](/monitoring/monitoring-resources/discovery/common-discovery#proxmox-virtual-environment)

### Service Discovery

The service discovery creates one service per discovered object, with these rules:

| Service template | Service name |
|------------------|--------------|
| [Node usage](#apps-proxmox-ve-restapi-node-usage) | `Node usage - <name>` |
| [Storage usage](#apps-proxmox-ve-restapi-storage-usage) | `Storage usage - <name>` |
| [VM Usage](#apps-proxmox-ve-restapi-vm-usage) | `VM usage - <name>` |

See [Service Discovery](/monitoring/monitoring-resources/discovery/service-discovery) for how to run it.

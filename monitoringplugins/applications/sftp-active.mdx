## Description

Monitors SFTP servers through SSH: connection time, number and age of files in a directory, and the execution of SFTP scenarios with step timings.

The plugin pack provides these checks:

* [SFTP connection](#apps-protocols-sftp-connection)
* [SFTP files count](#apps-protocols-sftp-files-count)
* [SFTP files date](#apps-protocols-sftp-files-date)
* [SFTP scenario](#apps-protocols-sftp-scenario)

## Description

Monitors Ceph storage clusters through the Ceph API: overall health, object storage daemons (OSD), pools and raw storage capacity.

The plugin pack provides these checks:

* [Ceph health](#apps-ceph-restapi-health)
* [Ceph object storage deamon (OSD)](#apps-ceph-restapi-osd)
* [Ceph pools](#apps-ceph-restapi-pools)
* [Ceph storage](#apps-ceph-restapi-storage)

## Discovery

### Service Discovery

The service discovery creates one service per discovered object, with these rules:

| Service template | Service name |
|------------------|--------------|
| [Ceph pools](#apps-ceph-restapi-pools) | `Pool - <name>` |

See [Service Discovery](/monitoring/monitoring-resources/discovery/service-discovery) for how to run it.

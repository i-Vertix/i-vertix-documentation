## Description

Monitors Podman through its API: container usage, pod status and the state of the system.

The plugin pack provides these checks:

* [Container usage](#apps-podman-restapi-container-usage)
* [Pod status](#apps-podman-restapi-pod-status)
* [System status](#apps-podman-restapi-system-status)

## Discovery

### Service Discovery

The service discovery creates one service per discovered object, with these rules:

<div className="plugin-pack-templates">

| Service template | Service name |
|------------------|--------------|
| [Container usage](#apps-podman-restapi-container-usage) | `Container usage - <name>` |
| [Pod status](#apps-podman-restapi-pod-status) | `Pod status - <name>` |

</div>

See [Service Discovery](/monitoring/monitoring-resources/discovery/service-discovery) for how to run it.

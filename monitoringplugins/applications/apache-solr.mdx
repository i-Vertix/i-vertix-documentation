## Description

Monitors Apache Solr through its HTTP API: cache usage and the usage of the request handlers.

The plugin pack provides these checks:

* [Cache usage](#apps-java-solr-jmx-cache-usage)
* [Request Handler usage](#apps-java-solr-jmx-request-handler-usage)

*Apache Solr JMX (Jolokia)* · Parent template: `generic-host`

## Description

Monitors CIFS/SMB file shares: connection time and file checks (count, age and size), plus scenario-based tests of share access.

The plugin pack provides these checks:

* [CIFS Connection](#apps-protocols-cifs-connection)
* [CIFS Files](#apps-protocols-cifs-files)
* [CIFS Files count](#apps-protocols-cifs-files-count)
* [CIFS Files date](#apps-protocols-cifs-files-date)
* [CIFS Files size](#apps-protocols-cifs-files-size)
* [CIFS Scenario](#apps-protocols-cifs-scenario)

<div className="plugin-pack-macros">

| `WARNING-MTIME-LAST` |  | Warning threshold last modify time |
| `WARNING-SIZE` |  | Warning threshold file site |
| `WARNING-FILES-DETECTED` |  | Warning threshold files detected |
| `CRITICAL-TOTAL-FILES-DETECTED` |  | Critical threshold total files detected |

| `CRITICAL-FILES-DETECTED` |  | Critical threshold files detected |
| `FILE` |  | Check file (Multiple option) |
| `FILTER-FILE` |  | Filter files (can be a regexp. Directory in the name) |

</div>

## Description

Monitors websites and web services over HTTP(S): response and extended timing metrics, expected content, and JSON and SOAP content checks.

The plugin pack provides these checks:

* [HTTP expected content](#apps-protocols-http-expected-content)
* [HTTP JSON content](#apps-protocols-http-json-content)
* [HTTP response](#apps-protocols-http-response)
* [HTTP response - extended metrics](#apps-protocols-http-response-extended-metrics)
* [HTTP SOAP content](#apps-protocols-http-soap-content)

#### Macros

<div className="plugin-pack-macros">

| Macro | Default value | Description |
|-------|---------------|-------------|
| `METHOD` | `GET` | Specify http method used (Default: 'GET') |
| `PROTO` | `https` | Specify https if needed (Default: 'http') |
| `WARNING-TIME` | `1` | Threshold warning in seconds (Webpage response time) |
| `CRITICAL-TIME` | `5` | Threshold critical in seconds (Webpage response time) |
| `UNKNOWN-STATUS` | `'%{http_code} < 200 or %{http_code} >= 300'` | Threshold warning for http response code (Default: '%\{http_code\} &lt; 200 or %\{http_code\} >= 300') |
| `PORT` |  | Port used by Webserver |
| `TIMEOUT` |  | Threshold for HTTP timeout (Default: 5) |
| `URL-PATH` |  | Set path to get Webpage (Default: '/') |
| `EXTRACTED-PATTERN` |  | Set pattern to extracted a number (used --warning-extracted and  --critical-extracted option) |
| `WARNING-STATUS` |  | Threshold warning for http response code |
| `CRITICAL-STATUS` |  | Threshold critical for http response code |
| `WARNING-CONTENT` |  | Set warning threshold for status (Default: ''). Can used special variables like: %\{content\}, %\{header\}, %\{first_header\}, %\{code\} |
| `WARNING-EXTRACTED` |  | Threshold warning for extracted value |
| `WARNING-SIZE` |  | Threshold warning for content size |
| `CRITICAL-CONTENT` |  | Set critical threshold for content page (Default: ''). Can used special variables like: %\{content\}, %\{header\}, %\{first_header\}, %\{code\} |
| `CRITICAL-EXTRACTED` |  | Threshold critical for extracted value |
| `CRITICAL-SIZE` |  | Threshold critical for content size |
| `EXPECTED-STRING` |  | --expected-string='toto' is a shortcut for --critical-content='%\{content\} !~ /toto/mi' Recommend to use directly --critical-content |
| `USERNAME` |  | Specify username for authentication (Mandatory if --credentials is specified) |
| `PASSWORD` |  | Specify password for authentication (Mandatory if --credentials is specified) |
| `CUSTOM-OPTION` |  | --credentials Specify this option if you access webpage with authentication, --basic Specify this option if you access webpage over basic authentication (Use with --credentials) |
| `FQDN` |  | IP Addr/FQDN of the Webserver host |

</div>

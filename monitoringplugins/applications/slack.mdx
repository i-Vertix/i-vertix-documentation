## Description

Monitors Slack workspaces through the Slack API: number of channels and channel members, number of members and the status of the Slack services.

The plugin pack provides these checks:

* [Channels count](#apps-slack-restapi-count-channels)
* [Members count](#apps-slack-restapi-count-members)
* [Serivces](#apps-slack-restapi-services)

## Discovery

### Service Discovery

The service discovery creates one service per discovered object, with these rules:

| Service template | Service name |
|------------------|--------------|
| [Serivces](#apps-slack-restapi-services) | `Service <name>` |

See [Service Discovery](/monitoring/monitoring-resources/discovery/service-discovery) for how to run it.

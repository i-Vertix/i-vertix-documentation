## Description

Monitors Apache Tomcat application servers through JMX: class loading, CPU load, file descriptors, garbage collection, load average, heap and non-heap memory, threads, connectors, datasources and web application sessions.

The plugin pack provides these checks:

* [JMX Class count](#apps-tomcat-jmx-class-count)
* [JMX Connector usage](#apps-tomcat-jmx-connector-usage)
* [JMX CPU Load](#apps-tomcat-jmx-cpu-load)
* [JMX Datasource usage](#apps-tomcat-jmx-datasource-usage)
* [JMX FD usage](#apps-tomcat-jmx-fd-usage)
* [JMX GC usage](#apps-tomcat-jmx-gc-usage)
* [JMX Load average](#apps-tomcat-jmx-load-average)
* [JMX Memory](#apps-tomcat-jmx-memory)
* [JMX Memory detailed](#apps-tomcat-jmx-memory-detailed)
* [JMX Threads](#apps-tomcat-jmx-threads)
* [JMX Web apps sessions](#apps-tomcat-jmx-webapps-sessions)

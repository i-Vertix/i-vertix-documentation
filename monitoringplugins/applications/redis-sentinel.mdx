## Description

Monitors Redis Sentinel clusters through SSH: the Redis instances and the Sentinels, including replicas, down states and ping latency.

The plugin pack provides these checks:

* [Redis cluster](#apps-redis-sentinel-redis-clusters)
* [Sentinel cluster](#apps-redis-sentinel-sentinel-clusters)

## Discovery

### Service Discovery

The service discovery creates one service per discovered object, with these rules:

| Service template | Service name |
|------------------|--------------|
| [Redis cluster](#apps-redis-sentinel-redis-clusters) | `Redis cluster - <name>` |
| [Sentinel cluster](#apps-redis-sentinel-sentinel-clusters) | `Sentinel cluster - <name>` |

See [Service Discovery](/monitoring/monitoring-resources/discovery/service-discovery) for how to run it.

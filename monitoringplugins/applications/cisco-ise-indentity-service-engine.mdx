## Description

Monitors Cisco Identity Services Engine (ISE) through its API and SNMP: active sessions, CPU, memory, disk I/O, system load, NTP, the ISE application and Oracle database processes, TCP services and uptime.

The plugin pack provides these checks:

* [CPU](#os-linux-snmp-cpu)
* [CPU detailed](#os-linux-snmp-cpu-detailed)
* [Disk IO](#os-linux-snmp-diskio)
* [Memory](#os-linux-snmp-memory-no-swap)
* [NTP](#os-linux-snmp-time)
* [Process - Application Server](#os-linux-snmp-processcount-ise-jsvc)
* [Process - MnT Session Database](#os-linux-snmp-processcount-ise-timestend)
* [Process - Oracle Database Listener](#os-linux-snmp-processcount-ise-tnslsnr)
* [Process - Oracle Database Writer](#os-linux-snmp-processcount-ise-ora_dbw)
* [Process - Oracle Log Writer](#os-linux-snmp-processcount-ise-ora_lgwr)
* [Process - Oracle PMON](#os-linux-snmp-processcount-ise-ora_pmon)
* [Process - Oracle SMON](#os-linux-snmp-processcount-ise-ora_smon)
* [Process - Profiler Database](#os-linux-snmp-processcount-ise-redis-server)
* [Sessions](#apps-cisco-ise-restapi-session)
* [System Load](#os-linux-snmp-load)
* [TCP OCPS](#apps-protocols-tcp-connection-status-ise-ocsp)
* [TCP SCEP](#apps-protocols-tcp-connection-status-ise-scep)
* [Uptime](#os-linux-snmp-uptime)

| Macro | Default value | Description |

| `WARNING-MEM-EACH` |  | Threshold warning of memory used by each matching processes (in Bytes) |

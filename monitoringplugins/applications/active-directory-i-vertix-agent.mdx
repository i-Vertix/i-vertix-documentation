## Description

Monitors Active Directory domain controllers through the i-Vertix agent: DCDIAG and Netdom checks, LDAP and directory service performance counters, replication, the status of the core services and security events such as locked out or deleted accounts.

The plugin pack provides these checks:

* [Active Directory - DCDIAG](#ivertix-agent-apps-microsoft-activedirectory-local-dcdiag)

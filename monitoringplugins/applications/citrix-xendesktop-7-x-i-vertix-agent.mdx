## Host Templates

### Citrix-XenDesktop-Broker

*Citrix XenDesktop Broker - NSclient Restapi* · Parent template: `generic-host`

<details className="plugin-pack-details">
<summary>Macros (10)</summary>

<div className="plugin-pack-macros">

| Macro | Default value | Description |
|-------|---------------|-------------|
| `NSCLIENT-PORT` | `8443` | Port used (default: 8443). |
| `NSCLIENT-PROTO` | `https` | Specify http if needed (default: 'https'). |
| `NSCLIENT-PWD` | *(password)* | Specify the password for authentication (mandatory if --credentials is specified). |
| `NSCLIENT-TIMEOUT` | `30` | Define the timeout in seconds (default: 5). |
| `NSCLIENT-USERNAME` | `admin` | User for agent authentication |

</div>

Macros without a default value are only defined in the check commands. Set them on the host where needed.

</details>

## Description

Monitors Proxmox Mail Gateway through its API: incoming and outgoing mail, spam and virus counts, mail traffic and the installed version.

The plugin pack provides these checks:

* [Mail](#apps-proxmox-mg-restapi-mail)
* [Version](#apps-proxmox-mg-restapi-version)

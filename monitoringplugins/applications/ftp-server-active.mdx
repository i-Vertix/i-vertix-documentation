## Description

Monitors FTP servers with active checks: login, custom FTP commands, and the number and modification time of files.

The plugin pack provides these checks:

* [FTP command](#apps-protocols-ftp-command)
* [FTP File modified time](#apps-protocols-ftp-date)
* [FTP Files count](#apps-protocols-ftp-filescount)
* [FTP login](#apps-protocols-ftp-login)


## Host Templates

*FTP login* · Parent template: `generic-host`

### FTP command {/* #apps-protocols-ftp-command */}

</summary>

#### Macros

<div className="plugin-pack-macros">

| Macro | Default value | Description |
|-------|---------------|-------------|
| `WARNING` | `1` | Threshold warning in seconds |
| `CRITICAL` | `5` | Threshold critical in seconds |
| `CUSTOM-OPTION` |  | --ssl   Use SSL connection |
| `FTP-COMMAND` |  | Set command to test (can be multiple). It will be executed in the order and stop on first command problem |

</div>

</details>

<details className="plugin-pack-details">
<summary>

### FTP File modified time {/* #apps-protocols-ftp-date */}

</summary>

#### Macros

<div className="plugin-pack-macros">

| Macro | Default value | Description |
|-------|---------------|-------------|
| `DIRECTORY` |  | Check files in the directory (no recursive) |
| `FILE` |  | Check file |
| `WARNING` |  | Threshold warning in seconds for each files (diff time) |
| `CRITICAL` |  | Threshold critical in seconds for each files (diff time) |
| `CUSTOM-OPTION` |  | --ssl   Use SSL connection |

</div>

</details>

<details className="plugin-pack-details">
<summary>

### FTP Files count {/* #apps-protocols-ftp-filescount */}

</summary>

#### Macros

<div className="plugin-pack-macros">

| Macro | Default value | Description |
|-------|---------------|-------------|
| `DIRECTORY` |  | Check files in the directory |
| `MAX-DEPTH` |  | Don't check fewer levels (Default: '0'. Means current dir only) |
| `FILTER-FILE` |  | Filter files (can be a regexp. Directory is in the name) |
| `WARNING` |  | Threshold warning (number of files) |
| `CRITICAL` |  | Threshold critical (number of files) |
| `CUSTOM-OPTION` |  | --ssl   Use SSL connection |

</div>

</details>

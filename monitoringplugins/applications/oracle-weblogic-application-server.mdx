## Description

Monitors Oracle WebLogic application servers through JMX over HTTP: memory, threads, loaded classes and work managers.

The plugin pack provides these checks:

* [Weblogic Class count](#apps-java-weblogic-jmx-class-count)
* [Weblogic Memory](#apps-java-weblogic-jmx-memory)
* [Weblogic Memory detailed](#apps-java-weblogic-jmx-memory-detailed)
* [Weblogic Threads](#apps-java-weblogic-jmx-threads)
* [Weblogic Work manager](#apps-java-weblogic-jmx-work-manager)

## Description

Monitors HAProxy through its web API: sessions, queues, traffic, denied requests and errors of the frontends, backends and servers.

The plugin pack provides these checks:

* [HA Proxy - backend](#apps-haproxy-web-backend-usage)
* [HA Proxy - frontend](#apps-haproxy-web-frontend-usage)

## Discovery

### Service Discovery

The service discovery creates one service per discovered object, with these rules:

## Description

Monitors Microsoft Hyper-V environments managed by System Center VMM through the i-Vertix agent: VM status, snapshots and integration services.

The plugin pack provides these checks:

* [SCVMM Integration Service status](#ivertix-agent-apps-microsoft-hyperv-local-scvmm-integration-service)
* [SCVMM Snapshot](#ivertix-agent-apps-microsoft-hyperv-local-scvmm-snapshot)
* [SCVMM VM status](#ivertix-agent-apps-microsoft-hyperv-local-scvmm-vm-status)

## Description

Monitors SmarterMail servers through the web interface: services, license expiration and the number of messages in the spool, including spam, virus, quarantine, waiting and throttled queues.

The plugin pack provides these checks:

* [All Spools](#apps-smartermail-restapi-spools)
* [Licenses](#apps-smartermail-restapi-licenses)
* [Services](#apps-smartermail-restapi-services)
* [Spool Default](#apps-smartermail-restapi-spools-default)
* [Spool limit](#apps-smartermail-restapi-spools-spool_limit)
* [Spool Quarantine Limit](#apps-smartermail-restapi-spools-quarantine_limit)
* [Spool Spam](#apps-smartermail-restapi-spools-spam)
* [Spool Throttled Domains](#apps-smartermail-restapi-spools-throttleddomains)
* [Spool Throttled Mailing Lists](#apps-smartermail-restapi-spools-throttledmailinglists)
* [Spool Throttled Users](#apps-smartermail-restapi-spools-throttledusers)
* [Spool Virus](#apps-smartermail-restapi-spools-virus)
* [Spool Waiting](#apps-smartermail-restapi-spools-waiting)

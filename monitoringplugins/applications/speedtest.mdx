## Description

Monitors internet connection quality with Speedtest: ping latency and jitter, download bandwidth and upload bandwidth.

The plugin pack provides these checks:

* [Speedtest - Internet bandwidth](#apps-monitoring-speedtest-internet-bandwidth)

#### Macros

<div className="plugin-pack-macros">

| Macro | Default value | Description |
|-------|---------------|-------------|
| `WARNING-PING-LATENCY` | `200` | Warning threshold Ping time |
| `CRITICAL-PING-LATENCY` | `500` | Critical threshold Ping time |
| `CRITICAL-PING-JITTER` | `25` | Critical threshold Ping jitter (ms) |
| `WARNING-PING-JITTER` | `10` | Warning threshold Ping jitter (ms) |
| `CRITICAL-BANDWIDTH-DOWNLOAD` |  | Critical threshold Bandwidth download (b/s) - example: 100MB: |
| `CRITICAL-BANDWIDTH-UPLOAD` |  | Critical threshold Bandwidth upload (b/s) - example: 100MB: |
| `WARNING-BANDWIDTH-DOWNLOAD` |  | Warning threshold Bandwidth download (b/s) - example: 100MB: |
| `WARNING-BANDWIDTH-UPLOAD` |  | Warning threshold Bandwidth upload (b/s) - example: 100MB: |
| `EXTRA-OPTS` |  | Additional options appended to the plugin command line (host level). |

</div>

#### Metrics

<div className="plugin-pack-macros">

| Metric | Unit | Description | Threshold macros |
|--------|------|-------------|------------------|
| `ping.latency.milliseconds` | `ms` | latency:  ms | `WARNING-PING-LATENCY`, `CRITICAL-PING-LATENCY` |
| `ping.jitter.milliseconds` | `ms` | jitter:  ms | `WARNING-PING-JITTER`, `CRITICAL-PING-JITTER` |
| `internet.bandwidth.download.bitspersecond` | `b/s` | download:  /s | `WARNING-BANDWIDTH-DOWNLOAD`, `CRITICAL-BANDWIDTH-DOWNLOAD` |
| `internet.bandwidth.upload.bitspersecond` | `b/s` | upload:  /s | `WARNING-BANDWIDTH-UPLOAD`, `CRITICAL-BANDWIDTH-UPLOAD` |

</div>

</details>

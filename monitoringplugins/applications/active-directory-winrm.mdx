## Description

Monitors Active Directory domain controllers through WinRM: the dcdiag results and the status of the core services such as AD DS, DNS, DFS, Netlogon, Kerberos and Windows Time.

The plugin pack provides these checks:

* [Active Directory - dcdiag](#apps-microsoft-activedirectory-wsman-dcdiag)
* [Service status - Active Directory Domain Services](#os-windows-wsman-services-ntds)
* [Service status - Active Directory Web Services](#os-windows-wsman-services-adws)
* [Service status - DFS Namespace](#os-windows-wsman-services-dfs)
* [Service status - DFS Replication](#os-windows-wsman-services-dfsr)
* [Service status - DNS Server](#os-windows-wsman-services-dns)
* [Service status - Intersite Messaging](#os-windows-wsman-services-ismserv)
* [Service status - Kerberos Key Distribution Center](#os-windows-wsman-services-kdc)
* [Service status - Netlogon](#os-windows-wsman-services-netlogon)
* [Service status - Remote Procedure Call](#os-windows-wsman-services-rpcss)
* [Service status - Security Accounts Manager](#os-windows-wsman-services-samss)
* [Service status - Windows Time](#os-windows-wsman-services-w32time)

| `WSMAN-PORT` | `5986` | Define the port to connect to (default: 5985). |
| `WSMAN-PATH` | `/wsman` | Define the path of the WSMAN URL if it has been customized (default: '/wsman'). |
| `WSMAN-SCHEME` | `https` | Define the transport scheme (default: 'http'). |
| `WSMAN-TIMEOUT` | `30` | Define the HTTP transport timeout in seconds (default: 30). |
| `WSMAN-AUTH-METHOD` |  | Define the authentication method. Available methods: `noauth`, `basic` (default), `pass`, `digest`, `ntlm`, `gssnegotiate`. |
| `WSMAN-PASSWORD` | *(password)* | Define the password associated with the user name. |
| `WSMAN-USERNAME` |  | Define the username for authentication. |
| `WSMAN-PROXY-URL` |  | Define the URL of the HTTP proxy to use. |

</div>

Macros without a default value are only defined in the check commands. Set them on the host where needed.

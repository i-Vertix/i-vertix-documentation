## Description

Monitors Rubrik backup clusters through the Rubrik REST API: cluster I/O, disk and node status, storage usage, backup compliance, job executions and task results.

The plugin pack provides these checks:

* [Rubrik Cluster status](#apps-backup-rubrik-restapi-cluster)
* [Rubrik Compliance status](#apps-backup-rubrik-restapi-compliance)
* [Rubrik Disks status](#apps-backup-rubrik-restapi-disks)
* [Rubrik Jobs](#apps-backup-rubrik-restapi-jobs)
* [Rubrik Node status](#apps-backup-rubrik-restapi-nodes)
* [Rubrik Storage status](#apps-backup-rubrik-restapi-storage)
* [Rubrik Tasks status](#apps-backup-rubrik-restapi-tasks)

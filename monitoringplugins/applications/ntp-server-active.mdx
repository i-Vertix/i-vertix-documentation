## Description

Monitors NTP servers with active checks: the time offset and the response time.

The plugin pack provides these checks:

* [NTP offset](#apps-protocols-ntp-offset)
* [NTP respone time](#apps-protocols-ntp-response-time)

#### Macros

|-------|---------------|-------------|
| `WARNING` | `-3:3` | Threshold warning in seconds |

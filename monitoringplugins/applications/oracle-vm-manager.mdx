## Description

Monitors Oracle VM Manager through its API: the manager and its jobs, server pools, servers, virtual machines and file servers.

The plugin pack provides these checks:

* [Oracle VM File servers](#apps-oracle-ovm-api-file-servers)
* [Oracle VM Manager](#apps-oracle-ovm-api-manager)
* [Oracle VM Server Pools](#apps-oracle-ovm-api-server-pools)
* [Oracle VM Servers](#apps-oracle-ovm-api-servers)
* [Oracle VM Virtual Maschine](#apps-oracle-ovm-api-vm)

## Description

Monitors web applications with Katalon Studio test scenarios run through Selenium and reports the result of each scenario.

The plugin pack provides these checks:

* [Selenium-Katalon-scenario](#apps-selenium-scenario-katalon)

#### Macros

<div className="plugin-pack-macros">

| Macro | Default value | Description |
|-------|---------------|-------------|
| `BROWSER` | `*firefox` | Browser used by Selenium server (default : '*firefox'). |
| `TIMEOUT` | `50` | Set scenario execution timeout in second (Default: 50) |
| `ACTION-TIMEOUT` | `10` | Set action execution timeout in second (Default: 10) |
| `CRITICAL-FAILED` | `0` | Threshold critical step state count failed |
| `SCENARIO` |  | Scenario to play (without extension) |
| `WARNING-FAILED` |  | Threshold warning step state count failed |
| `WARNING-SUCCESSFUL` |  | Threshold warning step state count successful |
| `WARNING-TIME-SCENARIO` |  | Threshold warning scenario execution time (ms) |
| `WARNING-TIME-STEP` |  | Threshold warning step execution time (ms) |
| `CRITICAL-SUCCESSFUL` |  | Threshold critical step state count successful |
| `CRITICAL-TIME-SCENARIO` |  | Threshold critical scenario execution time (ms) |
| `CRITICAL-TIME-STEP` |  | Threshold critical step execution time (ms) |

</div>

## Description

Monitors any SNMP-capable device with generic requests: numeric and string OID values and the SNMP response time.

The plugin pack provides these checks:

* [Generic numeric SNMP](#apps-protocols-snmp-numeric-value)
* [Generic string SNMP](#apps-protocols-snmp-string-value)
* [SNMP response time](#apps-protocols-snmp-response-time)

#### Macros

<div className="plugin-pack-macros">

| Macro | Default value | Description |
|-------|---------------|-------------|
| `OID-TYPE` | `gauge` | Type of the OID (Default: 'gauge'). Can be 'counter' also. 'counter' will use a retention file |
| `FORMAT` | `current value is %s` | Output format (Default: 'current value is %s') |
| `FORMAT-SCALE-TYPE` | `other` | Could be 'network' (value divide by 1000) or 'other' (divide by 1024) (Default: 'other') |
| `PERFDATA-NAME` | `value` | Perfdata name in perfdata output (default: 'value') |
| `OID` |  | OID value to check (numeric format only) |
| `WARNING` |  | Threshold warning |
| `CRITICAL` |  | Threshold critical |
| `FORMAT-CUSTOM` |  | Apply a custom change on the value (Example to multiply the value: --format-custom='* 8') |
| `PERFDATA-UNIT` |  | Perfdata unit in perfdata output (default: '') |

</div>

</details>

<details className="plugin-pack-details">
<summary>

### SNMP response time {/* #apps-protocols-snmp-response-time */}

</summary>

#### Macros

<div className="plugin-pack-macros">

| Macro | Default value | Description |
|-------|---------------|-------------|
| `TIMEOUT` | `5` | Set timeout in seconds (Default: 5) |
| `PACKETS` | `5` | Number of packets to send (Default: 5 |
| `WARNING-RTA` | `100` | Warning threshold rta |
| `WARNING-PL` | `0` | Warning threshold packet lost |
| `CRITICAL-RTA` | `250` | Critical threshold rta |
| `CRITICAL-PL` | `60` | Critical threshold packet lost |
| `EXTRA-OPTS` |  | Additional options appended to the plugin command line (host level). |

</div>

#### Metrics

<div className="plugin-pack-macros">

| Metric | Unit | Description | Threshold macros |
|--------|------|-------------|------------------|
| `roundtrip.time.average.milliseconds` | `ms` | rta ms | `WARNING-RTA`, `CRITICAL-RTA` |
| `roundtrip.time.maximum.milliseconds` | `ms` |  |  |
| `roundtrip.time.minimum.milliseconds` | `ms` |  |  |
| `packets.loss.percentage` | `%` | lost %% | `WARNING-PL`, `CRITICAL-PL` |

</div>

</details>

<details className="plugin-pack-details">
<summary>

### Generic string SNMP {/* #apps-protocols-snmp-string-value */}

</summary>

#### Macros

<div className="plugin-pack-macros">

| Macro | Default value | Description |
|-------|---------------|-------------|
| `FORMAT-OK` | `current value is: %{details_ok}` | Output format according the threshold |
| `FORMAT-WARNING` | `current value is: %{details_warning}` | Output format according the threshold |
| `FORMAT-CRITICAL` | `current value is: %{details_critical}` | Output format according the threshold |
| `OID` |  | OID value to check (numeric format only) |
| `WARNING-REGEXP` |  | Return Warning if an oid value match the regexp |
| `CRITICAL-REGEXP` |  | Return Critical if an oid value match the regexp |
| `MAP-VALUES` |  | Use to transform an integer value in most common case. Example: --map-values='1=>ok,10=>fan failed,11=>psu recovery' |
| `FILTER-TABLE-INSTANCE` |  | Filter instance from --oid-table option (can be a regexp) |
| `FILTER-TABLE-VALUE` |  | Filter value from --oid-table option (can be a regexp) |
| `OID-INSTANCE` |  | OID table value for the instance (numeric format only). Can be used to have human readable instance name |
| `OID-TABLE` |  | OID table value to check (numeric format only) |

</div>

</details>

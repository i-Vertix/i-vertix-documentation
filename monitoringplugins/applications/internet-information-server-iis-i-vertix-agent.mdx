## Description

Monitors Microsoft IIS through the i-Vertix agent: application pool state, web service statistics and the World Wide Web Publishing Service.

The plugin pack provides these checks:

* [IIS Application Pool state](#ivertix-agent-apps-microsoft-iis-local-applicationpool-state)
* [IIS Webservice statistics](#ivertix-agent-apps-microsoft-iis-local-webservice-statistics)
* [Service World Wide Web Publishing Service](#ivertix-agent-check_service-w3svc)

## Discovery

### Service Discovery

The service discovery creates one service per discovered object, with these rules:

</div>

See [Service Discovery](/monitoring/monitoring-resources/discovery/service-discovery) for how to run it.

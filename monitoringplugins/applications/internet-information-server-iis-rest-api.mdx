## Description

Monitors Microsoft IIS through a REST API: application pools and websites, including requests, traffic and connections.

The plugin pack provides these checks:

* [Application Pools](#apps-microsoft-iis-restapi-application-pools)
* [Websites](#apps-microsoft-iis-restapi-websites)

## Discovery

### Service Discovery

The service discovery creates one service per discovered object, with these rules:

| Service template | Service name |
|------------------|--------------|
| [Application Pools](#apps-microsoft-iis-restapi-application-pools) | `Application Pool - <name>` |
| [Websites](#apps-microsoft-iis-restapi-websites) | `Website - <name>` |

See [Service Discovery](/monitoring/monitoring-resources/discovery/service-discovery) for how to run it.

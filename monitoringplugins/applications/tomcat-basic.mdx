## Description

Monitors Apache Tomcat application servers through the manager status page: active sessions, connector threads, traffic and requests, and memory usage.

The plugin pack provides these checks:

* [Tomcat Application status](#apps-tomcat-web-applications)
* [Tomcat Connectors](#apps-tomcat-web-connectors)
* [Tomcat Memory](#apps-tomcat-web-memory)

## Discovery

### Service Discovery

The service discovery creates one service per discovered object, with these rules:

| Service template | Service name |
|------------------|--------------|
| [Tomcat Application status](#apps-tomcat-web-applications) | `Tomcat Application status - <name>` |

See [Service Discovery](/monitoring/monitoring-resources/discovery/service-discovery) for how to run it.

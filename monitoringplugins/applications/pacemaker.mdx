## Description

Monitors Pacemaker clusters through SSH: node states, failed actions and migrations of resources, constraints and the cluster resource manager.

The plugin pack provides these checks:

* [Pacemaker Cluster Resource Manager](#apps-pacemaker-local-crm)
* [Pacemaker Cluster statistics](#apps-pacemaker-local-clustat)
* [Pacemaker Constraints](#apps-pacemaker-local-constraints)


## Host Templates

### Pacemaker-HA

*Pacemaker HA* · Parent template: `generic-host`

<details className="plugin-pack-details">
<summary>Macros (7)</summary>

<div className="plugin-pack-macros">

| Macro | Default value | Description |
|-------|---------------|-------------|
| `SSH-BACKEND` | `sshcli` | Define the backend you want to use. It can be: `sshcli` (default for most plugins), `plink` and `libssh`. |
| `SSHCLI-OPTION` | `-o=StrictHostKeyChecking=no` | Specify SSH CLI options (example: --sshcli-option='-o=StrictHostKeyChecking=no -o=LogLevel=ERROR'). The default parameter is --sshcli-option='-o=LogLevel=ERROR' which hides the SSH banner. If you override this parameter, make sure to append '-o=LogLevel=ERROR' to your new value to maintain this behavior. This parameter can be used multiple times and multiple options can be specified in the same parameter. |
| `TIMEOUT` | `15` | Timeout in seconds for the command (default: 45). Default value can be override by the mode. |
| `SSHCLI-OPTION2` | `-o=LogLevel=ERROR` | hides the SSH banner |
| `SSH-USERNAME` |  | Define the user name to log in to the host. |
| `SSH-PASSWORD` |  | Define the password associated with the user name. Cannot be used with the `sshcli` backend. Warning: using a password is not recommended. Use `--ssh-priv-key` instead. |
| `SSH-PRIV-KEY` |  | Define the private key file to use for user authentication. |

</div>

Macros without a default value are only defined in the check commands. Set them on the host where needed.

</details>

## Description

Monitors the network path to a target with MTR: the path itself, path changes and the hops along the way.

The plugin pack provides these checks:

* [Path](#apps-protocols-path-path)
* [Path change](#apps-protocols-path-path-change)
* [Path Hops](#apps-protocols-path-hops)

### Path change {/* #apps-protocols-path-path-change */}

</summary>

#### Macros

<div className="plugin-pack-macros">

| Macro | Default value | Description |
|-------|---------------|-------------|
| `PATH-EXTRA-OPTS` | `--no-ecmp-learning` | : |
| `BASELINE-MODE` | `auto` | "auto" (default): a confirmed change becomes the new baseline; the change is reported during --change-hold. "fixed": the baseline is never updated automatically; the first confirmed change is reported until --reset-baseline is used |
| `CONSECUTIVE-CHANGES` | `2` | Number of consecutive runs with a different path before a change is confirmed (integer >= 1, default: 2) |
| `CHANGES-HOLD` | `3600` | Seconds a confirmed change stays reported in auto mode (default: 3600). Not used in fixed mode |
| `HOP-COUNT-TOLERANCE` | `0` | Hop count difference tolerated without reporting a change (default: 0) |
| `WARNING-STATUS` | `'%{as_path_changed} eq "yes" or %{hop_count_changed} eq "yes"'` | Define the conditions to match for the status to be WARNING (default: '%\{as_path_changed\} eq "yes" or %\{hop_count_changed\} eq "yes"'). Hop IP changes on the same AS path are not alerted by default (add '%\{ip_changed\} eq "yes"' if needed) |
| `CRITICAL-STATUS` | `'%{policy_violation} eq "yes"'` | Define the conditions to match for the status to be CRITICAL (default: '%\{policy_violation\} eq "yes"'). You can use the following variables for status options: %\{destination\}, %\{reached\}, %\{changed\}, %\{as_path_changed\}, %\{ip_changed\}, %\{hop_count_changed\}, %\{policy_violation\}, %\{missing\}, %\{forbidden\}, %\{current_as_path\}, %\{baseline_as_path\}, %\{hop_count\}, %\{baseline_hop_count\}, %\{hops_changed\}, %\{pending\}, %\{consecutive\} |
| `WARNING-HOPS` |  | Warning threhold Hops |
| `CRITICAL-HOPS` |  | Crticial threhold Hops |
| `MUST-TRAVERSE` |  | Comma separated list of IP addresses and/or AS numbers (e.g. 'AS3269') the path must traverse. Can be used multiple times. AS numbers require --asn-lookup |
| `MUST-NOT-TRAVERSE` |  | Comma separated list of IP addresses and/or AS numbers the path must not traverse. Can be used multiple times. AS numbers require --asn-lookup |
| `WARNING-HOPS-CHANGED` |  | Warning threhold Hops changed |
| `CRITICAL-HOPS-CHANGED` |  | Crticial threhold Hops changed |

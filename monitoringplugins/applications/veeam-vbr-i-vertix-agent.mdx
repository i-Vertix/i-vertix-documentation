## Description

Monitors Veeam Backup & Replication servers through the i-Vertix agent: job status, licenses, repositories, tape jobs and SureBackup jobs.

The plugin pack provides these checks:

* [Veeam Job Status](#ivertix-agent-apps-backup-veeam-local-job-status) (`ivertix-agent-apps-backup-veeam-local-job-status`)
* [Veeam Job status](#ivertix-agent-apps-backup-veeam13-local-job-status) (`ivertix-agent-apps-backup-veeam13-local-job-status`)
* [Veeam License](#ivertix-agent-apps-backup-veeam-local-license) (`ivertix-agent-apps-backup-veeam-local-license`)
* [Veeam License](#ivertix-agent-apps-backup-veeam13-local-license) (`ivertix-agent-apps-backup-veeam13-local-license`)
* [Veeam Repositories](#ivertix-agent-apps-backup-veeam-local-repositories) (`ivertix-agent-apps-backup-veeam-local-repositories`)
* [Veeam Repositories](#ivertix-agent-apps-backup-veeam13-local-repositories) (`ivertix-agent-apps-backup-veeam13-local-repositories`)
* [Veeam Tape jobs](#ivertix-agent-apps-backup-veeam-local-tape-jobs) (`ivertix-agent-apps-backup-veeam-local-tape-jobs`)
* [Veeam Tape jobs](#ivertix-agent-apps-backup-veeam13-local-tape-jobs) (`ivertix-agent-apps-backup-veeam13-local-tape-jobs`)
* [Veeam VSB Jobs](#ivertix-agent-apps-backup-veeam-local-vsb-jobs) (`ivertix-agent-apps-backup-veeam-local-vsb-jobs`)
* [Veeam VSB jobs](#ivertix-agent-apps-backup-veeam13-local-vsb-jobs) (`ivertix-agent-apps-backup-veeam13-local-vsb-jobs`)

| Macro | Default value | Description |
|-------|---------------|-------------|
| `FILTER-NAME` | `.*` | Filter job name (can be a regexp) |
| `FILTER-END-TIME` | `86400` | Filter job with end time greater than current time less value in seconds (Default: 86400) |
| `CRITICAL-TOTAL` | `1:` | Set critical threshold for total jobs |
| `WARNING-STATUS` | `"%{is_running} == 0 and %{status} =~ /Warning/i"` | Set warning threshold for status. Can used special variables like: %\{display\}, %\{status\}, %\{type\}, %\{is_running\}, %\{scheduled\} |
| `CRITICAL-STATUS` | `"%{is_running} == 0 and %{status} !~ /Success\|Warning/i"` | Set critical threshold for status (Default: '%\{is_running\} == 0 and not %\{status\} =~ /Success/i'). Can used special variables like: %\{display\}, %\{status\}, %\{type\}, %\{is_running\}, %\{scheduled\} |
| `WARNING-TOTAL` |  | Set warning threshold for total jobs |
| `CRITICAL-LONG` |  | Set critical threshold for long jobs. Can used special variables like: %\{display\}, %\{status\}, %\{type\}, %\{elapsed\} |
| `EXCLUDE-NAME` |  | Exclude job name (regexp can be used) |
| `FILTER-TYPE` |  | Filter job type (can be a regexp) |
| `WARNING-LONG` |  | Set warning threshold for long jobs. Can used special variables like: %\{display\}, %\{status\}, %\{type\}, %\{elapsed\} |

</div>

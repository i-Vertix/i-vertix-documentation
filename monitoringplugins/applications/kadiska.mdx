## Description

Monitors Kadiska through its API: alerts, network tracer statistics and watcher statistics.

The plugin pack provides these checks:

* [Alerts](#apps-monitoring-kadiska-alerts)
* [Net tracer statistics](#apps-monitoring-kadiska-nettracer-statistics)
* [Watcher statistics](#apps-monitoring-kadiska-watcher-statistics)

## Discovery

### Service Discovery

The service discovery creates one service per discovered object, with these rules:

<div className="plugin-pack-templates">

| Service template | Service name |
|------------------|--------------|
| [Alerts](#apps-monitoring-kadiska-alerts) | `Alerts - <name>` |
| [Net tracer statistics](#apps-monitoring-kadiska-nettracer-statistics) | `Net tracer statistics - <name>` |
| [Net tracer statistics](#apps-monitoring-kadiska-nettracer-statistics) | `Net tracer statistics - <name>` |
| [Watcher statistics](#apps-monitoring-kadiska-watcher-statistics) | `Watcher statistics - <name>` |

</div>

See [Service Discovery](/monitoring/monitoring-resources/discovery/service-discovery) for how to run it.

## Host Templates

### Kadiska-Net-Tracer

*Kadiska Net-Tracer* · Parent template: `generic-host`

<details className="plugin-pack-details">
<summary>Macros (8)</summary>

<div className="plugin-pack-macros">

| Macro | Default value | Description |
|-------|---------------|-------------|
| `PORT` | `443` | Port used (default: 443) |
| `PROTOCOL` | `https` | Specify https if needed (default: 'https') |
| `TIMEOUT` | `10` | Set timeout in seconds (default: 10). |
| `HTTP-BACKEND` | `lwp` | Perl library to use for HTTP transactions. Possible values are: lwp (default) and curl. |
| `PERIOD` | `15` | Set period in minutes from which you want to get information. (default: '15') Example: --period=60 would return you the data from last hour. |
| `CLIENT-SECRET` | *(password)* | Set client secret. |
| `HOSTNAME` | `app.kadiska.com` | Set hostname (default: 'app.kadiska.com'). |
| `CLIENT-ID` |  | Set client id. |

</div>

Macros without a default value are only defined in the check commands. Set them on the host where needed.

</details>

### Net tracer statistics {/* #apps-monitoring-kadiska-nettracer-statistics */}

</summary>

#### Macros

<div className="plugin-pack-macros">

| Macro | Default value | Description |
|-------|---------------|-------------|
| `WARNING-ROUND-TRIP` | `500` | Warning threshold for round trip in milliseconds |
| `WARNING-PACKET-LOSS-PRCT` | `0` | Warning threshold for packets' loss in percentage |
| `CRITICAL-ROUND-TRIP` | `1000` | Critical threshold for round trip in milliseconds |
| `CRITICAL-PACKET-LOSS-PRCT` | `25` | Critical threshold for packets' loss in percentage |
| `FILTER-RUNNER-NAME` |  | Filter on runner name to display net tracer targets' statistics linked to a particular runner |
| `FILTER-TARGET-NAME` |  | Filter to display statistics for particular net tracer targets. Can be a regex or a single tracer target. A target name must be given |
| `WARNING-PATH-LENGHT` |  | Warning threshold for path length to reach targets |
| `CRITICAL-PATH-LENGHT` |  | Critical threshold for path length to reach targets |

</div>

## Description

Monitors OpenVPN servers: connected clients and incoming and outgoing traffic of the server.

The plugin pack provides these checks:

* [Server usage](#apps-openvpn-omi-server-usage)

#### Macros

<div className="plugin-pack-macros">

| Macro | Default value | Description |
|-------|---------------|-------------|
| `WARNING-NUM-CLIENTS` |  | Threshold warning number of clients |
| `WARNING-TRAFFIC-IN` |  | Threshold warning traffic in |
| `WARNING-TRAFFIC-OUT` |  | Threshold warning traffic out |
| `CRITICAL-NUM-CLIENTS` |  | Threshold critical number of clients |
| `CRITICAL-TRAFFIC-IN` |  | Threshold critical traffic in |
| `CRITICAL-TRAFFIC-OUT` |  | Threshold critical traffic out |

</div>

#### Metrics

<div className="plugin-pack-macros">

| Metric | Unit | Description | Threshold macros |
|--------|------|-------------|------------------|
| `clients.current.count` |  | Current Clients | `WARNING-NUM-CLIENTS`, `CRITICAL-NUM-CLIENTS` |
| `server.traffic.in.bitspersecond` | `b/s` | Traffic In:  /s | `WARNING-TRAFFIC-IN`, `CRITICAL-TRAFFIC-IN` |
| `server.traffic.out.bitspersecond` | `b/s` | Traffic Out:  /s | `WARNING-TRAFFIC-OUT`, `CRITICAL-TRAFFIC-OUT` |

</div>

</details>

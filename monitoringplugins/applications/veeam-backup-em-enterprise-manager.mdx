## Description

Monitors Veeam Backup Enterprise Manager through its REST API: job status and execution results, and the space usage of the backup repositories.

The plugin pack provides these checks:

* [Job status](#apps-backup-veeam-vbem-restapi-jobs)
* [Repositories](#apps-backup-veeam-vbem-restapi-repositories)

## Discovery

### Service Discovery

The service discovery creates one service per discovered object, with these rules:

<div className="plugin-pack-templates">

| Service template | Service name |
|------------------|--------------|
| [Job status](#apps-backup-veeam-vbem-restapi-jobs) | `Job status - <jobName>` |
| [Repositories](#apps-backup-veeam-vbem-restapi-repositories) | `Repository - <name>` |

</div>

See [Service Discovery](/monitoring/monitoring-resources/discovery/service-discovery) for how to run it.

#### Macros

<div className="plugin-pack-macros">

| Macro | Default value | Description |
|-------|---------------|-------------|
| `TIMEFRAME` | `86400` | Timeframe to get BackupJobSession (in seconds. Default: 86400) |
| `UNIT` | `h` | Select the unit for last execution time threshold. May be 's' for seconds, 'm' for minutes, 'h' for hours, 'd' for days, 'w' for weeks. Default is seconds |
| `WARNING-EXECUTION-STATUS` | `%{status} =~ /warning/i` | Set warning threshold for last job execution status (Default: %\{status\} =~ /warning/i). You can use the following variables like: %\{status\}, %\{jobName\} |
| `CRTICAL-EXECUTION-STATUS` | `%{status} =~ /failed/i` | Set critical threshold for last job execution status (Default: %\{status\} =~ /failed/i). You can use the following variables: %\{status\}, %\{jobName\} |
| `WARNING-JOBS-EXECUTIONS-DETECTED` | `1:` | Warning threshold Jobs executions detected |
| `FILTER-UID` |  | Filter jobs by UID |
| `FILTER-NAME` |  | Filter jobs by name |
| `FILTER-TYPE` |  | Filter jobs by type |
| `UNKNOWN-EXECUTION-STATUS` |  | Set unknown threshold for last job execution status. You can use the following variables: %\{status\}, %\{jobName\} |
| `WARNING-JOB-EXECUTION-FAILED-PRCT` |  | Warning threshold Jobs execution failed (%) |
| `WARNING-JOB-EXECUTION-LAST` |  | Warning threshold Jobs last execution |
| `WARNING-JOB-RUNNING-DURATION` |  | Warning threshold Jobs running duration |
| `CRTICAL-JOBS-EXECUTIONS-DETECTED` |  | Critical threshold Jobs executions detected |
| `CRTICAL-JOB-EXECUTION-FAILED-PRCT` |  | Critical threshold Jobs execution failed (%) |
| `CRTICAL-JOB-EXECUTION-LAST` |  | Critical threshold Jobs last execution |
| `CRTICAL-JOB-RUNNING-DURATION` |  | Critical threshold Jobs running duration |

</div>

#### Metrics

<div className="plugin-pack-macros">

| Metric | Unit | Description | Threshold macros |
|--------|------|-------------|------------------|
| `jobs.executions.detected.count` |  | executions detected | `WARNING-JOBS-EXECUTIONS-DETECTED`, `CRTICAL-JOBS-EXECUTIONS-DETECTED` |
| `job.executions.failed.percentage` | `%` | number of failed executions:  %% | `WARNING-JOB-EXECUTION-FAILED-PRCT`, `CRTICAL-JOB-EXECUTION-FAILED-PRCT` |
| `job.execution.last` |  | last execution | `WARNING-JOB-EXECUTION-LAST`, `CRTICAL-JOB-EXECUTION-LAST` |
| `job.running.duration` |  | running duration | `WARNING-JOB-RUNNING-DURATION`, `CRTICAL-JOB-RUNNING-DURATION` |

</div>

</details>

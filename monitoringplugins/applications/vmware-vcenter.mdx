## Description

Monitors VMware vCenter and ESX infrastructures through the VMware connector: clusters, datacenters, ESX hosts (CPU, memory, network, health, services, alarms), datastores, virtual machines, snapshots and licenses.

The plugin pack provides these checks:

* [VMware Cluster status](#apps-vmware-connector-status-cluster)
* [VMware Connector statistics](#apps-vmware-connector-stat-connectors)
* [VMware Datacenter Alarm](#apps-vmware-connector-alarm-datacenter)
* [VMware Datastore count VM](#apps-vmware-connector-datastore-countvm)
* [VMware Datastore IO](#apps-vmware-connector-datastore-io)
* [VMware Datastore IOPS](#apps-vmware-connector-datastore-iops)
* [VMware Datastore latency](#apps-vmware-connector-datastore-host)
* [VMware Datastore usage](#apps-vmware-connector-datastore-usage)
* [VMware Host Alarm](#apps-vmware-connector-alarm-host)
* [VMware Host count VM](#apps-vmware-connector-countvm-host)
* [VMware Host CPU](#apps-vmware-connector-cpu-host)
* [VMware Host Health status](#apps-vmware-connector-health-host)
* [VMware Host Maintenance mode](#apps-vmware-connector-maintenance-host)
* [VMware Host Memory](#apps-vmware-connector-memory-host)
* [VMware Host Network](#apps-vmware-connector-net-host)
* [VMware Host NTP](#apps-vmware-connector-time-host)
* [VMware Host Services](#apps-vmware-connector-service-host)
* [VMware Host status](#apps-vmware-connector-status-host) (`apps-vmware-connector-status-host`)
* [VMware Host status](#apps-vmware-connector-status-host-standalone) (`apps-vmware-connector-status-host-standalone`)
* [VMware Host storage adapters](#apps-vmware-connector-storage-host)
* [VMware Host Swap](#apps-vmware-connector-swap-host)
* [VMware Host Uptime](#apps-vmware-connector-uptime-host)
* [VMware License usage](#apps-vmware-connector-licenses)
* [VMware Snapshot usage size](#apps-vmware-connector-datastore-snapshot)
* [VMware VM CPU](#apps-vmware-connector-cpu-vm)
* [VMware VM Datastore](#apps-vmware-connector-datastore-vm)

## Discovery

### Host Discovery

The hosts of this plugin pack are found by these host discoveries:

* [VMware Discovery](/monitoring/monitoring-resources/discovery/vmware-discovery)

### Service Discovery

The service discovery creates one service per discovered object, with these rules:

| Service template | Service name |
|------------------|--------------|
| [VMware Datastore count VM](#apps-vmware-connector-datastore-countvm) | `VMWare Datastore count VM - <name>` |
| [VMware Datastore latency](#apps-vmware-connector-datastore-host) | `VMWare Datastore latency - <name>` |
| [VMware Datastore IO](#apps-vmware-connector-datastore-io) | `VMWare Datastore IO <name>` |
| [VMware Datastore IOPS](#apps-vmware-connector-datastore-iops) | `VMWare Datastore IOPS <name>` |
| [VMware Snapshot usage size](#apps-vmware-connector-datastore-snapshot) | `VMWare Snapshot usage <name>` |
| [VMware Datastore usage](#apps-vmware-connector-datastore-usage) | `VMWare datastore usage <name>` |
| [VMware Host Network](#apps-vmware-connector-net-host) | `VMWare Host network - <name>` |

See [Service Discovery](/monitoring/monitoring-resources/discovery/service-discovery) for how to run it.

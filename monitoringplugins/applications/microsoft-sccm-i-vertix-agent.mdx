## Description

Monitors Microsoft SCCM through the i-Vertix agent: the site status and the database replication status.

The plugin pack provides these checks:

* [Database Replication Status](#ivertix-agent-apps-microsoft-sccm-local-database-replication-status)
* [Site status](#ivertix-agent-apps-microsoft-sccm-local-site-status)

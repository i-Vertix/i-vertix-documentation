## Description

Monitors Microsoft WSUS servers: connected computers, updates, synchronisation status and server statistics.

The plugin pack provides these checks:

* [WSUS Computers status](#ivertix-agent-apps-microsoft-wsus-local-computers-status)
* [WSUS Server statistics](#ivertix-agent-apps-microsoft-wsus-local-server-statistics)
* [WSUS Synchronisation status](#ivertix-agent-apps-microsoft-wsus-local-synchronisation-status)
* [WSUS Updates status](#ivertix-agent-apps-microsoft-wsus-local-updates-status)

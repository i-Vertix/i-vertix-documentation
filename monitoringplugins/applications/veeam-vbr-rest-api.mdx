## Description

Monitors Veeam Backup & Replication servers through the REST API: jobs, license usage and expiration, managed servers and the space usage of repositories.

The plugin pack provides these checks:

* [VBR Jobs](#apps-backuo-veeam-vbr-restapi-jobs)
* [VBR Licenses](#apps-backuo-veeam-vbr-restapi-licenses)
* [VBR Managed servers](#apps-backuo-veeam-vbr-restapi-managed-servers)
* [VBR Repositories](#apps-backuo-veeam-vbr-restapi-repositories)

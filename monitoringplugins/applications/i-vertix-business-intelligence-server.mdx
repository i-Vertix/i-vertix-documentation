## Description

Monitors the i-Vertix Business Intelligence server through its API and SNMP: BI status, ETL runs and data consistency, MariaDB performance, and system resources such as CPU, memory, swap, load and disk I/O.

The plugin pack provides these checks:

* [CPU](#os-linux-snmp-cpu)
* [CPU detailed](#os-linux-snmp-cpu-detailed)
* [Disk IO](#os-linux-snmp-diskio)
* [i-vertix BI API response](#apps-protocols-http-response-ivertix-bi)
* [i-Vertix BI database update API](#apps-protocols-http-json-content-ivertix-bi-database-update-api)
* [i-Vertix BI database update ETL](#apps-protocols-http-json-content-ivertix-bi-database-update-etl)
* [i-Vertix BI ETL data consistency](#apps-protocols-http-json-content-ivertix-bi-data-consistency)
* [i-Vertix BI ETL data recovery](#apps-protocols-http-json-content-ivertix-bi-data-recovery)

## Description

Monitors the validity of x509 SSL/TLS certificates: HTTPS, SMTP, IMAP, POP3 and FTP services as well as certificate files, with the days left until expiration.

The plugin pack provides these checks:

* [Certificate File validity](#apps-protocols-x509-certificate-file)
* [Certificate validity](#apps-protocols-x509-certificate-opensslcli)
* [FTP certificate validity](#apps-protocols-x509-certificate-tcp-ftp)
* [IMAP certificate validity](#apps-protocols-x509-certificate-tcp-imap)
* [POP3 certificate validity](#apps-protocols-x509-certificate-tcp-pop3)
* [SMTP certificate validity](#apps-protocols-x509-certificate-tcp-smtp)
* [SSL certificate validity](#apps-protocols-x509-certificate-https) (`apps-protocols-x509-certificate-https`)
* [SSL certificate validity](#apps-protocols-x509-certificate-https-internal) (`apps-protocols-x509-certificate-https-internal`)
* [SSL certificate validity](#apps-protocols-x509-certificate-https-letsencrypt) (`apps-protocols-x509-certificate-https-letsencrypt`)

## Description

Monitors Apache Zookeeper through its HTTP API: server statistics.

The plugin pack provides these checks:

* [Zookeeper statistics](#apps-java-zookeeper-jmx-stats)


## Host Templates

### Apache-Zookeeper-JMX

*Apache Zookeeper JMX (Jolokia)* · Parent template: `generic-host`

<details className="plugin-pack-details">
<summary>Macros (4)</summary>

<div className="plugin-pack-macros">

| Macro | Default value | Description |
|-------|---------------|-------------|
| `JMX-URL` | `http://localhost:8080/jolokia` | Url where the jolokia agent is deployed (required). Example: http://localhost:8080/jolokia |
| `JMX-TIMEOUT` | `10` | Timeout in seconds for HTTP requests (default: 30 seconds) |
| `JMX-PASSWORD` | *(password)* | Credentials to use for the HTTP request |
| `JMX-USERNAME` |  | Credentials to use for the HTTP request |

</div>

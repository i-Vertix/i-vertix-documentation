## Description

Monitors Veeam Backup & Replication servers through WinRM: job status, licenses, repository space usage, tape jobs and SureBackup jobs.

The plugin pack provides these checks:

* [Veeam Job status](#apps-backup-veeam-wsman-job-status)
* [Veeam License](#apps-backup-veeam-wsman-licenses)
* [Veeam Repositories](#apps-backup-veeam-wsman-repositories)
* [Veeam Tape jobs](#apps-backup-veeam-wsman-tape-jobs)
* [Veeam VSB jobs](#apps-backup-veeam-wsman-vsb-jobs)

## Discovery

## Description

Monitors Sophos XGS firewalls through SNMP: CPU, memory, swap and storage usage, HA and license status, services, requests, VPN, interfaces and the ARP table.

The plugin pack provides these checks:

* [ARP](#os-linux-snmp-arp)
* [CPU](#os-linux-snmp-cpu)
* [HA status](#network-cyberoam-snmp-ha-status)
* [Interfaces](#network-cyberoam-snmp-interfaces)
* [License status](#network-cyberoam-snmp-license)
* [Memory & Swap](#network-cyberoam-snmp-memory)
* [Requests](#network-cyberoam-snmp-requests)
* [Services](#network-cyberoam-snmp-services)
* [Storage](#network-cyberoam-snmp-storage)
* [Uptime](#os-linux-snmp-uptime)
* [VPN status](#network-cyberoam-snmp-vpn-status)

## Discovery

### Host Discovery

The hosts of this plugin pack are found by these host discoveries:

* [Network Topology Discovery](/monitoring/monitoring-resources/discovery/nedi)

### Service Discovery

The service discovery creates one service per discovered object, with these rules:

| Service template | Service name |
|------------------|--------------|
| [Interfaces](#network-cyberoam-snmp-interfaces) | `Interface - <name>` |
| [VPN status](#network-cyberoam-snmp-vpn-status) | `VPN status- <name>` |

See [Service Discovery](/monitoring/monitoring-resources/discovery/service-discovery) for how to run it.

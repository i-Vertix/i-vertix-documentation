## Description

Monitors Ubiquiti UniFi WLAN controllers through SNMP: CPU, memory, swap, load and disks, interfaces, virtual access points and uptime.

The plugin pack provides these checks:

* [CPU](#network-ubiquiti-unifi-snmp-cpu)
* [Disks](#network-ubiquiti-unifi-snmp-disks)
* [Interfaces](#network-ubiquiti-unifi-snmp-interfaces)
* [Memory](#network-ubiquiti-unifi-snmp-memory)
* [Swap](#network-ubiquiti-unifi-snmp-swap)
* [System Load](#network-ubiquiti-unifi-snmp-load)
* [Uptime](#network-ubiquiti-unifi-snmp-uptime)
* [Virtual Access Points](#network-ubiquiti-unifi-snmp-virtual-access-points)

## Description

Monitors Cisco Email Security Gateways through their API: system status and resource usage such as CPU, memory, swap, disk I/O and logging disk, message queues and connections.

The plugin pack provides these checks:

* [System](#network-cisco-esa-restapi-system)
* [System Usage](#network-cisco-esa-xmlapi-system-usage)

## Description

Monitors ADVA FSP 150 network elements through SNMP: alarms, hardware, system CPU and memory usage and the interfaces.

The plugin pack provides these checks:

* [Alarms](#network-adva-fsp150-snmp-alarms)
* [Hardware](#network-adva-fsp150-snmp-hardware)
* [Interfaces](#network-adva-fsp150-snmp-interfaces)
* [Systems](#network-adva-fsp150-snmp-systems)
* [Uptime](#os-linux-snmp-uptime)

### Hardware {/* #network-adva-fsp150-snmp-hardware */}

</summary>

#### Macros

<div className="plugin-pack-macros">

| Macro | Default value | Description |
|-------|---------------|-------------|
| `COMPONENT` |  | Which component to check (Default: '.*'). Can be: 'shelf', 'card' |
| `FILTER` |  | Exclude some parts (comma seperated list) (Example: --filter=shelf) Can also exclude specific instance: --filter=card,psu.1.1.4 |
| `THRESHOLD-OVERLOAD` |  | Set to overload default threshold values (syntax: section,[instance,]status,regexp) It used before default thresholds (order stays). Example: --threshold-overload='card,WARNING,initializing' |
| `NO-COMPONENT` |  | Define the expected status if no components are found (default: critical) |

</div>

</details>

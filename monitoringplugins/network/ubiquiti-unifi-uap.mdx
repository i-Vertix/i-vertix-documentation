## Description

Monitors Ubiquiti UniFi access points through SNMP: CPU, memory and load, interfaces, radio health, virtual access point health and uptime.

The plugin pack provides these checks:

* [CPU](#network-ubiquiti-uap-snmp-cpu)
* [Interfaces](#network-ubiquiti-uap-snmp-interfaces)
* [Load](#network-ubiquiti-uap-snmp-load)
* [Memory](#network-ubiquiti-uap-snmp-memory)
* [Radio health](#network-ubiquiti-uap-snmp-radio-health)
* [Uptime](#network-ubiquiti-uap-snmp-uptime)
* [Virtual access point health](#network-ubiquiti-uap-snmp-vap-health)

## Discovery

### Host Discovery

The hosts of this plugin pack are found by these host discoveries:

* [Network Topology Discovery](/monitoring/monitoring-resources/discovery/nedi)

The service discovery creates one service per discovered object, with these rules:

| `EXTRA-OPTS` |  | Additional options appended to the plugin command line (host level). |

| `SNMPVERSION` |  | Version of the SNMP protocol. 1 for SNMP v1 (default), 2 for SNMP v2c, 3 for SNMP v3. |

| `SNMPAUTH-PASSPHRASE` |  | SNMP v3 only: Pass phrase hashed using the authentication protocol defined in the --authprotocol option. |
| `SNMPAUTH-PROTOCOL` |  | SNMP v3 only: Authentication protocol: MD5\|SHA. Since net-snmp 5.9.1: SHA224\|SHA256\|SHA384\|SHA512. |

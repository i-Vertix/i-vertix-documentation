## Description

Monitors Cisco APIC (Application Policy Infrastructure Controller) through its REST API: the health of the fabric, nodes and tenants.

The plugin pack provides these checks:

* [Fabric](#network-cisco-aci-apic-restapi-fabric)
* [Node](#network-cisco-aci-apic-restapi-node)
* [Tenant](#network-cisco-aci-apic-restapi-tenant)

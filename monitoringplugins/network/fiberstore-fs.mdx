## Description

Monitors FiberStore (FS) switches through SNMP: CPU and memory usage, hardware health, interfaces, ARP and uptime.

The plugin pack provides these checks:

* [ARP](#os-linux-snmp-arp)
* [CPU](#network-fiberstore-snmp-cpu)
* [Hardware](#network-fiberstore-snmp-hardware)
* [Interfaces](#network-fiberstore-snmp-interfaces)
* [Memory](#network-fiberstore-snmp-memory)
* [Uptime](#os-linux-snmp-uptime)

## Discovery

### Service Discovery

The service discovery creates one service per discovered object, with these rules:

See [Service Discovery](/monitoring/monitoring-resources/discovery/service-discovery) for how to run it.

### Hardware {/* #network-fiberstore-snmp-hardware */}

</summary>

#### Macros

<div className="plugin-pack-macros">

| Macro | Default value | Description |
|-------|---------------|-------------|
| `COMPONENT` | `.*` | Which component to check (Default: '.*'). Can be: 'fan', 'power', 'slot' |
| `FILTER` |  | Exclude some parts (comma seperated list) (Example: --filter=power) Can also exclude specific instance: --filter=power,1 |
| `WARNING` |  | Set warning threshold for 'fan.speed' (syntax: type,regexp,threshold) Example: --warning='fan.speed,.*,90' |
| `CRITICAL` |  | Set critical threshold for 'fan.speed' (syntax: type,regexp,threshold) Example: --critical='fan.speed,.*,95' |
| `THRESHOLD-OVERLOAD` |  | Set to overload default threshold values (syntax: section,status,regexp) It used before default thresholds (order stays). Example: --threshold-overload='fan,CRITICAL,notInstall' |

</div>

</details>

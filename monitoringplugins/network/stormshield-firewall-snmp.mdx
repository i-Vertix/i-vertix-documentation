## Description

Monitors Stormshield firewalls through SNMP: CPU, memory, load, swap and storage, hardware and health, HA nodes and cluster, interfaces, connections, QoS, licenses, auto update, VPN status and SD-WAN/VPN routes.

The plugin pack provides these checks:

* [Auto update](#network-stormshield-snmp-auto-update)
* [Connections](#network-stormshield-snmp-connections)
* [CPU](#network-stormshield-snmp-cpu)
* [CPU detailed](#network-stormshield-snmp-cpu-detailed)
* [HA cluster](#network-stormshield-snmp-ha-cluster)
* [HA nodes](#network-stormshield-snmp-ha-nodes)
* [Hardware](#network-stormshield-snmp-hardware)
* [Health](#network-stormshield-snmp-health)
* [Interfaces](#network-stormshield-snmp-interfaces)
* [Interfaces detailed](#network-stormshield-snmp-interfaces-disco)
* [Licenses](#network-stormshield-snmp-licenses)
* [Load](#network-stormshield-snmp-load)
* [Memory](#network-stormshield-snmp-memory)
* [Memory detailed](#network-stormshield-snmp-memory-detailed)
* [QoS](#network-stormshield-snmp-qos)
* [SD-WAN/VPN routes](#network-stormshield-snmp-router-disco)
* [Storage](#network-stormshield-snmp-storage)
* [Swap](#network-stormshield-snmp-swap)
* [Uptime](#network-stormshield-snmp-uptime)
* [VPN Status](#network-stormshield-snmp-vpn-status)

## Host Templates

### Stormshield-FW

*Stormshield Firewall* · Parent template: `generic-host`

<details className="plugin-pack-details">
<summary>Macros (9)</summary>

<div className="plugin-pack-macros">

| Macro | Default value | Description |
|-------|---------------|-------------|
| `SNMPCOMMUNITY` |  | SNMP community (default value: public). It is recommended to use a read-only community. |
| `SNMPVERSION` |  | Version of the SNMP protocol. 1 for SNMP v1 (default), 2 for SNMP v2c, 3 for SNMP v3. |
| `SNMPUSERNAME` |  | SNMP v3 only: User name (`securityName`). |
| `SNMPAUTH-PASSPHRASE` |  | SNMP v3 only: Pass phrase hashed using the authentication protocol defined in the --authprotocol option. |
| `SNMPAUTH-PROTOCOL` |  | SNMP v3 only: Authentication protocol: MD5\|SHA. Since net-snmp 5.9.1: SHA224\|SHA256\|SHA384\|SHA512. |
| `SNMPPRIV-PASSPHRASE` |  | SNMP v3 only: Privacy pass phrase (`privPassword`) to encrypt messages using the protocol defined in the --privprotocol option. |
| `SNMPPRIV-PROTOCOL` |  | SNMP v3 only: Privacy protocol (`privProtocol`) used to encrypt messages. Supported protocols are: DES\|AES and since net-snmp 5.9.1: AES192\|AES192C\|AES256\|AES256C. |
| `EXTRA-OPTS` |  | Additional options appended to the plugin command line (host level). |

</div>

Macros without a default value are only defined in the check commands. Set them on the host where needed.

</details>

| `ABSENT-PROBLEM` |  | Return an error if a component is not present (default: skip). Can be set globally or per instance: --absent-problem='component_name' or --absent-problem='component_name,instance_value' |

## Description

Monitors Huawei wireless LAN controllers through SNMP: CPU and memory usage, hardware health, interfaces, and the status and radios of the managed access points.

The plugin pack provides these checks:

* [AP health](#network-huawei-wlc-snmp-ap-health)
* [AP radio](#network-huawei-wlc-snmp-ap-radio) (`network-huawei-wlc-snmp-ap-radio`)
* [AP radio](#network-huawei-wlc-snmp-ap-status) (`network-huawei-wlc-snmp-ap-status`)
* [CPU](#network-huawei-wlc-snmp-cpu)
* [Global AP status](#network-huawei-wlc-snmp-wlan-global)
* [Hardware](#network-huawei-wlc-snmp-hardware)
* [Interfaces](#network-huawei-wlc-snmp-interfaces)
* [Memory](#network-huawei-wlc-snmp-memory)
* [Uptime](#network-huawei-wlc-snmp-uptime)

## Description

Monitors Stormshield firewalls through the REST API: CPU and memory usage, hardware, HA status, interfaces, VPN tunnels and uptime.

The plugin pack provides these checks:

* [CPU](#network-stormshield-api-cpu)
* [HA status](#network-stormshield-api-ha)
* [Hardware](#network-stormshield-api-hardware)
* [Interfaces](#network-stormshield-api-interfaces)
* [Memory](#network-stormshield-api-memory)
* [Uptime](#network-stormshield-api-uptime)
* [VPN tunnels](#network-stormshield-api-vpn-tunnels)

## Discovery

### Hardware {/* #network-stormshield-api-hardware */}

</summary>

#### Macros

<div className="plugin-pack-macros">

| Macro | Default value | Description |
|-------|---------------|-------------|
| `COMPONENT` | `.*` | Which component to check (Default: '.*'). Can be: 'disk', 'fan', 'psu', 'temperature' |
| `FILTER` |  | Exclude some parts (comma seperated list) (Example: --filter=fan) Can also exclude specific instance: --filter=fan,1 |
| `WARNING` |  | Set warning threshold for 'temperature', 'fan' (syntax: type,regexp,threshold) Example: --warning='temperature,.*,40' |
| `CRITICAL` |  | Set critical threshold for 'temperature', 'fan' (syntax: type,regexp,threshold) Example: --critical='temperature,.*,50' |
| `THRESHOLD-OVERLOAD` |  | Set to overload default threshold values (syntax: section,[instance,]status,regexp) It used before default thresholds (order stays). Example: --threshold-overload='disk,WARNING,missing' |
| `NO-COMPONENT` |  | Define the expected status if no components are found (default: critical) |

</div>

</details>

## Description

Monitors Cambium cnMatrix switches through SNMP: hardware health, interfaces, SFP ports, ARP, TCP and UDP connections and uptime.

The plugin pack provides these checks:

* [ARP](#network-cambium-cnmatrix-snmp-arp)
* [Hardware](#network-cambium-cnmatrix-snmp-hardware)
* [Interfaces](#network-cambium-cnmatrix-snmp-interfaces)
* [SFP port](#network-cambium-cnmatrix-snmp-sfp-port)
* [TCP connections](#network-cambium-cnmatrix-snmp-tcpcon)
* [UDP connections](#network-cambium-cnmatrix-snmp-udpcon)
* [Uptime](#network-cambium-cnmatrix-snmp-uptime)

## Discovery

### Host Discovery

The hosts of this plugin pack are found by these host discoveries:

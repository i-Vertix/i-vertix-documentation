## Description

Monitors Extreme MLX switches through SNMP: CPU and memory usage, hardware status, interfaces, SFP ports, TCP and UDP connections and uptime.

The plugin pack provides these checks:

* [CPU](#network-extreme-mlx-snmp-cpu)
* [Hardware status](#network-extreme-mlx-snmp-hardware)
* [Interfaces](#network-extreme-mlx-snmp-interfaces)
* [Memory](#network-extreme-mlx-snmp-memory)
* [SFP port status](#network-extreme-mlx-snmp-sfp-port-status)
* [TCP connections](#os-linux-snmp-tcpcon)
* [UDP connections](#os-linux-snmp-udpcon)
* [Uptime](#os-linux-snmp-uptime)

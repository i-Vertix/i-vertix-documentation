## Description

Monitors Huawei network devices through SNMP: CPU and memory usage, hardware health, interfaces, spanning tree and the health, traffic and Ethernet ports of connected ONTs.

The plugin pack provides these checks:

* [CPU](#network-huawei-standard-snmp-cpu)
* [Hardware](#network-huawei-standard-snmp-hardware)
* [Interfaces](#network-huawei-standard-snmp-interfaces)
* [Memory](#network-huawei-standard-snmp-memory)
* [ONT ethernet port](#network-huawei-standard-snmp-gpon-ont-ethernet-port)
* [ONT health](#network-huawei-standard-snmp-gpon-ont-health)
* [ONT traffic](#network-huawei-standard-snmp-gpon-ont-traffic)
* [Spanning tree](#network-huawei-standard-snmp-spanning-tree)
* [Uptime](#network-huawei-standard-snmp-uptime)

## Discovery

The hosts of this plugin pack are found by these host discoveries:

## Description

Monitors Juniper MX routers through SNMP: CPU, memory and storage, hardware, interfaces and class of service, plus BGP peers, LDP sessions, LSPs and RSVP sessions.

The plugin pack provides these checks:

* [BGP peer prefix status](#network-juniper-mseries-snmp-bgp-peer-prefix-statistics)
* [BGP peer state](#network-juniper-mseries-snmp-bgp-peer-state)
* [CoS](#network-juniper-mseries-snmp-cos)
* [CPU](#network-juniper-mseries-snmp-cpu)
* [Hardware](#network-juniper-mseries-snmp-hardware)
* [Interfaces](#network-juniper-mseries-snmp-interfaces)
* [LDP session status](#network-juniper-mseries-snmp-ldp-session-status)
* [LSP status](#network-juniper-mseries-snmp-lsp-status)
* [Memory](#network-juniper-mseries-snmp-memory)
* [RSVP session status](#network-juniper-mseries-snmp-rsvp-session-status)
* [Storage](#network-juniper-mseries-snmp-storage)
* [Uptime](#os-linux-snmp-uptime)

## Discovery

### Service Discovery

The service discovery creates one service per discovered object, with these rules:

| Service template | Service name |
|------------------|--------------|
| [BGP peer state](#network-juniper-mseries-snmp-bgp-peer-state) | `BGP peer state - <name>` |
| [Interfaces](#network-juniper-mseries-snmp-interfaces) | `Interface - <name>` |

See [Service Discovery](/monitoring/monitoring-resources/discovery/service-discovery) for how to run it.

## Description

Monitors Fortinet FortiGate firewalls through SNMP and the HTTPS API: CPU, memory and disk usage, cluster and HA status, hardware, interfaces, sessions, VPN, SD-WAN, IPS and virus statistics, licenses, certificates, VDOMs, managed access points and switches.

The plugin pack provides these checks:

* [AP usage](#network-fortinet-fortigate-snmp-ap-usage)
* [Certificates](#network-fortinet-fortigate-restapi-certificates)
* [Cluster CPU](#network-fortinet-fortigate-snmp-cpu-cluster)
* [Cluster Memory](#network-fortinet-fortigate-snmp-memory-cluster)
* [Cluster status](#network-fortinet-fortigate-snmp-cluster-status)
* [CPU](#network-fortinet-fortigate-snmp-cpu)
* [Disk](#network-fortinet-fortigate-snmp-disk)
* [HA status](#network-fortinet-fortigate-restapi-ha)
* [Hardware status](#network-fortinet-fortigate-snmp-hardware)
* [Health](#network-fortinet-fortigate-restapi-health)
* [Interfaces](#network-fortinet-fortigate-snmp-interfaces)
* [IPS statistics](#network-fortinet-fortigate-snmp-ips-stats)
* [License status](#network-fortinet-fortigate-restapi-licenses)
* [Link monitor](#network-fortinet-fortigate-snmp-link-monitor)
* [Memory](#network-fortinet-fortigate-snmp-memory)
* [SD-WAN](#network-fortinet-fortigate-snmp-sdwan)
* [Sessions](#network-fortinet-fortigate-snmp-sessions)
* [Signatures update](#network-fortinet-fortigate-snmp-signatures)
* [Switch usage](#network-fortinet-fortigate-snmp-switch-usage)
* [System](#network-fortinet-fortigate-restapi-system)
* [Uptime](#network-fortinet-fortigate-snmp-uptime)
* [VDOM usage](#network-fortinet-fortigate-snmp-vdom-usage)
* [Virus events](#network-fortinet-fortigate-snmp-virus)
* [VPN](#network-fortinet-fortigate-snmp-vpn)

### Fortinet-Fortigate-Cluster

*Fortinet Fortigate Cluster* · Parent template: `generic-host`

<details className="plugin-pack-details">
<summary>Macros (8)</summary>

<div className="plugin-pack-macros">

| Macro | Default value | Description |
|-------|---------------|-------------|
| `SNMPCOMMUNITY` |  | SNMP community |
| `SNMPVERSION` |  | SNMP version |
| `SNMPUSERNAME` |  | SNMP v3 only: User name (`securityName`). |
| `SNMPTIMEOUT` |  | Time to wait before sending the request again if no reply has been received, in seconds (default: 1). See also --snmp-retries. |
| `SNMPAUTH-PASSPHRASE` |  | SNMP v3 only: Pass phrase hashed using the authentication protocol defined in the --authprotocol option. |
| `SNMPAUTH-PROTOCOL` |  | SNMP v3 only: Authentication protocol: MD5\|SHA. Since net-snmp 5.9.1: SHA224\|SHA256\|SHA384\|SHA512. |
| `SNMPPRIV-PASSPHRASE` |  | SNMP v3 only: Privacy pass phrase (`privPassword`) to encrypt messages using the protocol defined in the --privprotocol option. |
| `SNMPPRIV-PROTOCOL` |  | SNMP v3 only: Privacy protocol (`privProtocol`) used to encrypt messages. Supported protocols are: DES\|AES and since net-snmp 5.9.1: AES192\|AES192C\|AES256\|AES256C. |

</div>

Macros without a default value are only defined in the check commands. Set them on the host where needed.

</details>

| `WARNING-TOTAL-NODES` |  | Threshold warning Total nodes |
| `WARNING-SYNCHRONIZED` |  | Threshold warning synchronized |
| `WARNING-TOTAL-CHECKSUMS` |  | Threshold warning total checksums |
| `CRITICAL-SYNCHRONIZED` |  | Threshold critical synchronized |
| `CRITICAL-TOTAL-CHECKSUMS` |  | Threshold critical total checksums |
| `WARNING-STATUS` |  | Set warning threshold for status. Can used special variables like: %\{serial\}, %\{hostname\}, %\{sync_status\}, %\{role\}, %\{roleLast\} |

</div>

## Description

Monitors Alcatel-Lucent OXE PBX systems through SNMP: CPU, memory, swap and storage usage, PBX role and state, domains and trunks.

The plugin pack provides these checks:

* [CPU](#network-alcatel-oxe-snmp-cpu)
* [Domains](#network-alcatel-oxe-snmp-domains)
* [Memory usage](#network-alcatel-oxe-snmp-memory)
* [PBX Role](#network-alcatel-oxe-snmp-pbx-role)
* [PBX State](#network-alcatel-oxe-snmp-pbx-state)
* [Storage usage](#network-alcatel-oxe-snmp-storage)
* [Swap usage](#network-alcatel-oxe-snmp-swap)
* [Trunks](#network-alcatel-oxe-snmp-trunks)
* [Uptime](#os-linux-snmp-uptime)

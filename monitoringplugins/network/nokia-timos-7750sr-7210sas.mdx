## Description

Monitors Nokia TimOS routers (7750 SR, 7210 SAS) through SNMP: CPU and memory, hardware, interfaces, SAS alarms, service access points and the usage of BGP, IS-IS, LDP and L2TP.

The plugin pack provides these checks:

* [BGP usage](#network-nokia-timos-snmp-bgp-usage)
* [CPU](#network-nokia-timos-snmp-cpu)
* [Hardware](#network-nokia-timos-snmp-hardware)
* [Interfaces](#network-nokia-timos-snmp-interfaces)
* [IS-IS usage](#network-nokia-timos-snmp-isis-usage)
* [L2TP usage](#network-nokia-timos-snmp-l2tp-usage)
* [LDP usage](#network-nokia-timos-snmp-ldp-usage)
* [Memory](#network-nokia-timos-snmp-memory)
* [SAS alarm](#network-nokia-timos-snmp-sas-alarm)
* [Service Access Point usage](#network-nokia-timos-snmp-sap-usage)
* [Uptime](#network-nokia-timos-snmp-uptime)

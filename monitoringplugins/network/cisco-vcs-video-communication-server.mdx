## Description

Monitors Cisco VCS (Video Communication Server) through its HTTP(S) API: alerts, calls, registered endpoints, zones and HTTP proxy statistics.

The plugin pack provides these checks:

* [Alerts](#network-cisco-vcs-restapi-alerts)
* [Calls](#network-cisco-vcs-restapi-calls)
* [Endpoints](#network-cisco-vcs-restapi-endpoints)
* [HTTP Proxy statistics](#network-cisco-vcs-restapi-http-proxy-stats)
* [Zones](#network-cisco-vcs-restapi-zones)

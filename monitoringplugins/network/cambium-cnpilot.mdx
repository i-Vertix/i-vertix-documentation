## Description

Monitors Cambium cnPilot access points through SNMP: CPU and memory usage, interfaces, radios, the connection status of the access point and uptime.

The plugin pack provides these checks:

* [AP Connection status](#network-cambium-cnpilot-snmp-connection-status)
* [CPU](#network-cambium-cnpilot-snmp-cpu)
* [Interfaces](#network-cambium-cnpilot-snmp-interfaces)
* [Memory](#network-cambium-cnpilot-snmp-memory)
* [Radios](#network-cambium-cnpilot-snmp-radios)
* [Uptime](#os-linux-snmp-uptime)

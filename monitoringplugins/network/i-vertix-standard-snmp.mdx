## Description

Monitors any SNMP-capable device through the standard MIBs: CPU, memory, swap and load, disks, storage and inodes, interfaces, ARP, processes, TCP and UDP connections, NTP and uptime.

The plugin pack provides these checks:

* [ARP](#ivertix-standard-snmp-arp)
* [CPU](#ivertix-standard-snmp-cpu)
* [CPU detailed](#ivertix-standard-snmp-cpu-detailed)
* [Disk IO](#ivertix-standard-snmp-diskio)
* [Disk usage](#ivertix-standard-snmp-disk-usage)
* [Hardware](#ivertix-standard-snmp-hardware)
* [Inodes usage](#ivertix-standard-snmp-inodes)
* [Interfaces](#ivertix-standard-snmp-interfaces)
* [Memory](#ivertix-standard-snmp-memory)
* [NTP](#ivertix-standard-snmp-time)
* [Process count](#ivertix-standard-snmp-processcount)
* [Storage](#ivertix-standard-snmp-storage)
* [Swap](#ivertix-standard-snmp-swap)
* [System Load](#ivertix-standard-snmp-load)
* [TCP connections](#ivertix-standard-snmp-tcpcon)
* [UDP connections](#ivertix-standard-snmp-udpcon)
* [Uptime](#ivertix-standard-snmp-uptime)

## Discovery

### Service Discovery

The service discovery creates one service per discovered object, with these rules:

| Service template | Service name |
|------------------|--------------|
| [Disk IO](#ivertix-standard-snmp-diskio) | `Disk IO - <name>` |
| [Inodes usage](#ivertix-standard-snmp-inodes) | `Inodes <name>` |
| [Interfaces](#ivertix-standard-snmp-interfaces) | `Interface - <name>` |
| [Process count](#ivertix-standard-snmp-processcount) | `Process memory <name>` |
| [Storage](#ivertix-standard-snmp-storage) | `Storage <name>` |

See [Service Discovery](/monitoring/monitoring-resources/discovery/service-discovery) for how to run it.

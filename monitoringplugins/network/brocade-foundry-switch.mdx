## Description

Monitors Brocade Foundry switches through SNMP: CPU and memory usage, hardware health, interfaces, SFP port status and uptime.

The plugin pack provides these checks:

* [CPU](#network-brocade-foundry-snmp-cpu)
* [Hardware](#network-brocade-foundry-snmp-hardware)
* [Interfaces](#network-brocade-foundry-snmp-interfaces)
* [Memory](#network-brocade-foundry-snmp-memory)
* [SFP port status](#network-brocade-foundry-snmp-sfp-port-status)
* [Uptime](#network-brocade-foundry-snmp-uptime)

## Discovery

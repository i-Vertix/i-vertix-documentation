## Description

Monitors Cisco ASA firewalls through SNMP: CPU and memory usage, interfaces, sensors, failover status, sessions, IPsec tunnels and uptime.

The plugin pack provides these checks:

* [CPU](#network-cisco-asa-snmp-cpu)
* [Failover](#network-cisco-asa-snmp-failover)
* [Interfaces](#network-cisco-asa-snmp-interfaces)
* [IPsec Tunnel](#network-cisco-asa-snmp-ipsec-tunnel)
* [Memory](#network-cisco-asa-snmp-memory)
* [Sensors](#network-cisco-asa-snmp-sensors)
* [Sessions](#network-cisco-asa-snmp-sessions)
* [Uptime](#os-linux-snmp-uptime)

## Discovery

### Host Discovery

The hosts of this plugin pack are found by these host discoveries:

* [Network Topology Discovery](/monitoring/monitoring-resources/discovery/nedi)
* [Network Scan](/monitoring/monitoring-resources/discovery/host-discovery)

The service discovery creates one service per discovered object, with these rules:

## Description

Monitors Waystream network devices through SNMP: CPU and memory usage, hardware, SFP port status, interfaces, TCP and UDP connections, NTP and uptime.

The plugin pack provides these checks:

* [CPU](#network-waystream-snmp-cpu)
* [CPU detailed](#network-waystream-snmp-cpu-detailed)
* [Hardware](#network-waystream-snmp-hardware)
* [Interfaces](#network-waystream-snmp-interfaces)
* [Memory](#network-waystream-snmp-memory)
* [NTP](#network-waystream-snmp-time)
* [SFP port status](#network-waystream-snmp-sfp-port-status)
* [TCP connections](#network-waystream-snmp-tcpcon)
* [UDP connections](#network-waystream-snmp-udpcon)
* [Uptime](#network-waystream-snmp-uptime)

## Discovery

### Host Discovery

The hosts of this plugin pack are found by these host discoveries:

* [Network Topology Discovery](/monitoring/monitoring-resources/discovery/nedi)

### Service Discovery

The service discovery creates one service per discovered object, with these rules:

| Service template | Service name |
|------------------|--------------|
| [Interfaces](#network-waystream-snmp-interfaces) | `Interface - <name>` |
| [SFP port status](#network-waystream-snmp-sfp-port-status) | `SFP port <number> - <interface_name> - status` |

See [Service Discovery](/monitoring/monitoring-resources/discovery/service-discovery) for how to run it.

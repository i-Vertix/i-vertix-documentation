## Description

Monitors Dell OS10 (Force10) switches through SNMP: CPU, load, memory and swap, disk and inode usage, hardware status, interfaces, NTP time and uptime.

The plugin pack provides these checks:

* [CPU](#network-dell-os10-snmp-cpu)
* [Disk usage](#network-dell-os10-snmp-disk-usage)
* [Hardware status](#network-dell-os10-snmp-hardware)
* [Inodes usage](#network-dell-os10-snmp-inodes)
* [Interfaces](#network-dell-os10-snmp-interfaces)
* [Load](#network-dell-os10-snmp-load)
* [Memory](#network-dell-os10-snmp-memory)
* [NTP-time](#network-dell-os10-snmp-time)
* [Swap](#network-dell-os10-snmp-swap)
* [Uptime](#network-dell-os10-snmp-uptime)

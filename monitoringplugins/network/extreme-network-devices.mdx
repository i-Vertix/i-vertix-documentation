## Description

Monitors Extreme network devices through SNMP: CPU and memory usage, hardware status, interfaces, stack status and uptime.

The plugin pack provides these checks:

* [CPU](#network-extreme-snmp-cpu)
* [Hardware status](#network-extreme-snmp-hardware)
* [Interfaces](#network-extreme-snmp-interfaces)
* [Memory](#network-extreme-snmp-memory)
* [Stack status](#network-extreme-snmp-stack)
* [Uptime](#os-linux-snmp-uptime)

## Discovery

### Host Discovery

The hosts of this plugin pack are found by these host discoveries:

* [Network Topology Discovery](/monitoring/monitoring-resources/discovery/nedi)

### Service Discovery

The service discovery creates one service per discovered object, with these rules:

| Service template | Service name |
|------------------|--------------|
| [Interfaces](#network-extreme-snmp-interfaces) | `Interface - <name>` |

See [Service Discovery](/monitoring/monitoring-resources/discovery/service-discovery) for how to run it.

### Extreme-Switch-SNMP

*Extreme Networks Switch SNMP* · Parent template: `generic-host`

<details className="plugin-pack-details">
<summary>Macros (8)</summary>

<div className="plugin-pack-macros">

| Macro | Default value | Description |
|-------|---------------|-------------|
| `SNMPVERSION` |  | SNMP version |
| `SNMPCOMMUNITY` |  | SNMP community |
| `SNMPUSERNAME` |  | SNMP v3 only: User name (`securityName`). |
| `SNMPAUTH-PASSPHRASE` |  | SNMP v3 only: Pass phrase hashed using the authentication protocol defined in the --authprotocol option. |
| `SNMPAUTH-PROTOCOL` |  | SNMP v3 only: Authentication protocol: MD5\|SHA. Since net-snmp 5.9.1: SHA224\|SHA256\|SHA384\|SHA512. |
| `SNMPPRIV-PASSPHRASE` |  | SNMP v3 only: Privacy pass phrase (`privPassword`) to encrypt messages using the protocol defined in the --privprotocol option. |
| `SNMPPRIV-PROTOCOL` |  | SNMP v3 only: Privacy protocol (`privProtocol`) used to encrypt messages. Supported protocols are: DES\|AES and since net-snmp 5.9.1: AES192\|AES192C\|AES256\|AES256C. |
| `SNMPTIMEOUT` |  | Time to wait before sending the request again if no reply has been received, in seconds (default: 1). See also --snmp-retries. |

</div>

Macros without a default value are only defined in the check commands. Set them on the host where needed.

</details>

### Hardware status {/* #network-extreme-snmp-hardware */}

</summary>

#### Macros

<div className="plugin-pack-macros">

| Macro | Default value | Description |
|-------|---------------|-------------|
| `COMPONENT` |  | Which component to check (Default: '.*'). Can be: 'fan', 'psu', 'slot', 'temperature', 'poe' |
| `FILTER` |  | Exclude some parts (comma seperated list) (Example: --filter=fan --filter=psu) Can also exclude specific instance: --filter=fan,101 |
| `WARNING` |  | Set warning threshold for 'temperature', 'fan', 'psu.fan', 'psu' (syntax: type,regexp,threshold) Example: --warning='psu.fan,1.1,5000' |
| `CRITICAL` |  | Set critical threshold for 'temperature', 'fan', 'psu.fan', 'psu' (syntax: type,regexp,threshold) Example: --critical='psu,.*,200' |
| `THRESHOLD-OVERLOAD` |  | Set to overload default threshold values (syntax: section,[instance,]status,regexp) It used before default thresholds (order stays). Example: --threshold-overload='psu,CRITICAL,^(?!(presentOK)$) |
| `ABSENT-PROBLEM` |  | Return an error if a component is not 'present' (default is skipping). It can be set globally or for a specific instance: --absent-problem='component_name' or --absent-problem='component_name,instance_value' |
| `NO-COMPONENT` |  | Define the expected status if no components are found (default: critical) |

</div>

</details>

## Changelog

Changes of the plugin pack per release, compared with the previous release.

<details className="plugin-pack-details" open>
<summary>20251100 - 20260114</summary>

- Command `network-extreme-snmp-hardware`
    - Option `--absent-problem=$_SERVICEABSENT-PROBLEM$` added
    - Option `--no-component=$_SERVICENO-COMPONENT$` added
    - Macro `ABSENT-PROBLEM` added
    - Macro `NO-COMPONENT` added

</details>

<details className="plugin-pack-details">
<summary>20230810 - 20230828</summary>

- Service template [`network-extreme-snmp-interfaces`](#network-extreme-snmp-interfaces)
    - Macro `UNITS-TRAFFIC`: default changed from `%` to `percent_delta`
    - Macro `UNITS-ERROR`: default changed from `%` to `percent_delta`
    - Macro `OID-EXTRA-DISPLAY` added (default `ifAlias`)
- Command `network-extreme-snmp-interfaces`
    - Option `--oid-extra-display=$_SERVICEOID-EXTRA-DISPLAY$` added
    - Macro `OID-EXTRA-DISPLAY` added

</details>

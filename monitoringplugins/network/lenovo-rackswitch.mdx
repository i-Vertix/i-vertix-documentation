## Description

Monitors Lenovo RackSwitch switches through SNMP: CPU and memory usage, hardware health, interfaces and uptime.

The plugin pack provides these checks:

* [CPU](#network-lenovo-rackswitch-snmp-cpu)
* [Hardware](#network-lenovo-rackswitch-snmp-hardware)
* [Interfaces](#network-lenovo-rackswitch-snmp-interfaces)
* [Memory](#network-lenovo-rackswitch-snmp-memory)
* [Uptime](#network-lenovo-rackswitch-snmp-uptime)

## Discovery

### Host Discovery

The hosts of this plugin pack are found by these host discoveries:

* [Network Topology Discovery](/monitoring/monitoring-resources/discovery/nedi)

### Service Discovery

The service discovery creates one service per discovered object, with these rules:

| Service template | Service name |
|------------------|--------------|
| [Interfaces](#network-lenovo-rackswitch-snmp-interfaces) | `Interface - <name>` |

See [Service Discovery](/monitoring/monitoring-resources/discovery/service-discovery) for how to run it.

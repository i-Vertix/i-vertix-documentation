## Description

Monitors Fortinet FortiWLC (Meru) wireless controllers through SNMP: alarms, online access points and wireless stations, CPU and memory usage, interfaces and uptime.

The plugin pack provides these checks:

* [Alarms](#network-meru-snmp-alarms)
* [CPU](#network-meru-snmp-cpu)
* [Interfaces](#network-meru-snmp-interfaces)
* [Memory](#network-meru-snmp-menory)
* [Uptime](#os-linux-snmp-uptime)
* [Wireless](#network-meru-snmp-wireless)

## Discovery

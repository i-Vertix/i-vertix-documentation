## Description

Monitors Siemens RUGGEDCOM network devices through SNMP: memory, temperature, hardware, interfaces, errors and uptime.

The plugin pack provides these checks:

* [Errors](#network-ruggedcom-errors)
* [Hardware](#network-ruggedcom-hardware)
* [Interfaces](#network-ruggedcom-interfaces)
* [Memory](#network-ruggedcom-memory)
* [Temperature](#network-ruggedcom-temperature)
* [Uptime](#os-linux-snmp-uptime)

## Discovery

<div className="plugin-pack-macros">

| Macro | Default value | Description |
|-------|---------------|-------------|
| `NO-COMPONENT` | `critical` | Define the expected status if no components are found (default: critical) |
| `COMPONENT` |  | Which component to check (Default: '.*'). Can be: 'psu', 'fan' |
| `FILTER` |  | Exclude some parts (comma seperated list) (Example: --filter=psu) Can also exclude specific instance: --filter=psu,1 |
| `THRESHOLD-OVERLOAD` |  | Set to overload default threshold values (syntax: section,status,regexp) It used before default thresholds (order stays). Example: --threshold-overload='psu,CRITICAL,^(?!(on)$)' |
| `ABSENT-PROBLEM` |  | Return an error if an entity is not 'present' (default is skipping) (comma separated list) Can be specific or global: --absent-problem=fan,1 |

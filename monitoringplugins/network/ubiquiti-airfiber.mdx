## Description

Monitors Ubiquiti airFiber radio links through SNMP: radios, load, memory, interfaces and uptime.

The plugin pack provides these checks:

* [Interfaces](#network-ubiquiti-airfiber-snmp-interfaces)
* [Load](#network-ubiquiti-airfiber-snmp-load)
* [Memory](#network-ubiquiti-airfiber-snmp-memory)
* [Radios](#network-ubiquiti-airfiber-snmp-radios)
* [Uptime](#os-linux-snmp-uptime)

## Discovery

### Service Discovery

## Description

Monitors Ribbon (Sonus) session border controllers through SNMP: CPU, memory, load, swap and storage, interfaces, call statistics, channels and DSP statistics.

The plugin pack provides these checks:

* [Call Statistics](#network-sonus-sbc-snmp-call-statistics)
* [Channels](#network-sonus-sbc-snmp-channels)
* [CPU](#network-sonus-sbc-snmp-cpu)
* [CPU detailed](#network-sonus-sbc-snmp-cpu-detailed)
* [DSP statistics](#network-sonus-sbc-snmp-dsp-stats)
* [Interfaces](#network-sonus-sbc-snmp-interfaces)
* [Load](#network-sonus-sbc-snmp-load)
* [Memory](#network-sonus-sbc-snmp-memory)
* [Storage](#network-sonus-sbc-snmp-storage)
* [Swap](#network-sonus-sbc-snmp-swap)
* [Uptime](#os-linux-snmp-uptime)

## Description

Monitors HPE ProCurve switches through SNMP: CPU and memory usage, environment sensors, interfaces including PoE and optical values, ARP, spanning tree, stack, virtual chassis and uptime.

The plugin pack provides these checks:

* [ARP](#os-linux-snmp-arp)
* [CPU](#network-hp-procurve-snmp-cpu)
* [Environment](#network-hp-procurve-snmp-environment)
* [Interfaces](#network-hp-procurve-snmp-interfaces)
* [Memory](#network-hp-procurve-snmp-memory)
* [Spanning tree](#network-hp-procurve-snmp-spanning-tree)
* [Stack](#network-hp-procurve-snmp-stack)
* [Uptime](#os-linux-snmp-uptime)
* [Virtual Chassis](#network-hp-procurve-snmp-virtual-chassis)

## Discovery

### Host Discovery

The hosts of this plugin pack are found by these host discoveries:

* [Network Topology Discovery](/monitoring/monitoring-resources/discovery/nedi)
* [Network Scan](/monitoring/monitoring-resources/discovery/host-discovery)

The service discovery creates one service per discovered object, with these rules:

| Service template | Service name |

| Macro | Default value | Description |
|-------|---------------|-------------|
| `ENVIRONMENT` | `.*` | Which component to check (Default: '.*'). Can be: 'sensor', 'psu', 'fan' |
| `EXTRA-OPTS` |  | --verbose |
| `FILTER` |  | Exclude some parts (comma seperated list) (Example: --filter=sensor) Can also exclude specific instance: --filter=sensor,fan.1 |
| `THRESHOLD-OVERLOAD` |  | Set to overload default threshold values (syntax: section,[instance,]status,regexp) It used before default thresholds (order stays). Example: --threshold-overload='sensor,CRITICAL,^(?!(good)$)' |
| `ABSENT-PROBLEM` |  | Return an error if a component is not 'present' (default is skipping). It can be set globally or for a specific instance: --absent-problem='component_name' or --absent-problem='component_name,instance_value' |
| `CRITICAL` |  | Set critical threshold for 'temperature' (syntax: type,regexp,threshold) Example: --critical='temperature,.*,50' |
| `NO-COMPONENT` |  | Define the expected status if no components are found (default: critical) |
| `WARNING` |  | Set warning threshold for 'temperature' (syntax: type,regexp,threshold) Example: --warning='temperature,.*,40' |

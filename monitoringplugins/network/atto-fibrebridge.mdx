## Description

Monitors Atto FibreBridge devices through SNMP: Fibre Channel port traffic and errors (invalid CRC, signal loss), hardware health and uptime.

The plugin pack provides these checks:

* [FC port usage](#network-atto-fibrebridge-snmp-fcport-usage)
* [Hardware](#network-atto-fibrebridge-snmp-hardware)
* [Uptime](#os-linux-snmp-uptime)

#### Macros

<div className="plugin-pack-macros">

| Macro | Default value | Description |
|-------|---------------|-------------|
| `WARNING-TRAFFIC-IN` | `80` | Threshold warning traffic in |
| `WARNING-TRAFFIC-OUT` | `80` | Threshold warning traffic out |
| `WARNING-INVALID-CRC` | `0` | Threshold warning invalid crc |
| `WARNING-SIGNAL-LOSS` | `0` | Threshold warning signal loss |
| `CRITICAL-STATUS` | `'%{admin} =~ /enabled/ and %{status} !~ /online/'` | Set critical threshold for status (Default: '%\{admin\} =~ /enabled/ and %\{status\} !~ /online/'). Can used special variables like: %\{admin\}, %\{status\}, %\{display\} |
| `CRITICAL-TRAFFIC-IN` | `90` | Threshold critical traffic in |
| `CRITICAL-TRAFFIC-OUT` | `90` | Threshold critical traffic out |
| `CRITICAL-INVALID-CRC` | `10` | Threshold critical invalid crc |
| `CRITICAL-SIGNAL-LOSS` | `10` | Threshold critical signal loss |
| `FILTER-COUNTERS` |  | Only display some counters (regexp can be used). Example: --filter-counters='^status$' |
| `FILTER-NAME` |  | Filter name (can be a regexp) |
| `WARNING-STATUS` |  | Set warning threshold for status (Default: ''). Can used special variables like: %\{admin\}, %\{status\}, %\{display\} |

</div>

#### Macros

<div className="plugin-pack-macros">

| Macro | Default value | Description |
|-------|---------------|-------------|
| `COMPONENT` |  | Which component to check (Default: '.*'). Can be: 'psu', 'alarm' |
| `FILTER` |  | Exclude some parts (comma seperated list) (Example: --filter=psu) Can also exclude specific instance: --filter=psu,1 |
| `WARNING` |  | Set warning threshold for temperatures, fan (syntax: type,instance,threshold) Example: --warning='xxxxx,.*,30' |
| `CRITICAL` |  | Set critical threshold for temperatures, fan (syntax: type,instance,threshold) Example: --critical='xxxxx,.*,40' |
| `THRESHOLD-OVERLOAD` |  | Set to overload default threshold values (syntax: section,[instance,]status,regexp) It used before default thresholds (order stays). Example: --threshold-overload='alarm,OK,warning' |

</div>

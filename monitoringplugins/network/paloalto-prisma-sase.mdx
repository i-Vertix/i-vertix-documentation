## Description

Monitors Palo Alto Prisma SASE through its HTTPS API: licenses, remote networks, service connections, tunnel status and the status of edge locations.

The plugin pack provides these checks:

* [Edge location status](#network-paloalto-prisma-sase-restapi-edge-remote-location-status) (`network-paloalto-prisma-sase-restapi-edge-remote-location-status`)
* [Edge location status](#network-paloalto-prisma-sase-restapi-edge-service-location-status) (`network-paloalto-prisma-sase-restapi-edge-service-location-status`)
* [Licenses](#network-paloalto-prisma-sase-restapi-licenses)
* [Remote networks](#network-paloalto-prisma-sase-restapi-remote-networks)
* [Service connections](#network-paloalto-prisma-sase-restapi-service-connections)
* [Tunnel status](#network-paloalto-prisma-sase-restapi-tunnel-status)

## Discovery

### Service Discovery

The service discovery creates one service per discovered object, with these rules:

| Service template | Service name |
|------------------|--------------|
| [Remote networks](#network-paloalto-prisma-sase-restapi-remote-networks) | `Remote network <site_name> status` |
| [Edge location status](#network-paloalto-prisma-sase-restapi-edge-remote-location-status) | `Location <edge_location_type> <edge_location_name> status` |
| [Service connections](#network-paloalto-prisma-sase-restapi-service-connections) | `Service connection <site_name> status` |
| [Edge location status](#network-paloalto-prisma-sase-restapi-edge-service-location-status) | `Location <edge_location_type> <edge_location_name> status` |
| [Tunnel status](#network-paloalto-prisma-sase-restapi-tunnel-status) | `Tunnel <tunnel_type> <tunnel_name> status` |

See [Service Discovery](/monitoring/monitoring-resources/discovery/service-discovery) for how to run it.

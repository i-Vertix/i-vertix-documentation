## Description

Monitors Teldat routers through SNMP: CPU and memory usage, interfaces, radio cells and uptime.

The plugin pack provides these checks:

* [Cells Radio](#network-teldat-snmp-cells-radio)
* [CPU](#network-teldat-snmp-cpu)
* [Interfaces](#network-teldat-snmp-interfaces)
* [Memory](#network-teldat-snmp-memory)
* [Uptime](#network-teldat-snmp-uptime)

## Changelog

Changes of the plugin pack per release, compared with the previous release.

<summary>20240808 - 20240826</summary>

- Plugin pack `Teldat`
    - Description updated
- Service template [`network-teldat-snmp-cells-radio`](#network-teldat-snmp-cells-radio)
    - Macro `WARNING-STATUS`: default changed from `'%{interfaceState} =~ /disconnect/'` to `'%{interfaceState} =~ /disconnect/ && %{interfaceType} =~ /data primary/'`

- Command `network-teldat-snmp-cells-radio`
    - Option `--filter-module=$_SERVICEFILTER-MODULE$` added
    - Option `--filter-imei=$_SERVICEFILTER-IMEI$` added
    - Option `--filter-interface-type=$_SERVICEFILTER-INTERFACY-TYPE$` added
    - Option `--filter-cell-id=$_SERVICEFILTER-CELL-ID$` removed
    - Macro `FILTER-INTERFACY-TYPE` added
    - Macro `FILTER-IMEI` added
    - Macro `FILTER-MODULE` added
    - Macro `FILTER-CELL-ID` removed
- Command `network-teldat-snmp-list-cells-radio`
    - Command added

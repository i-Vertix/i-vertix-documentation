## Description

Monitors Cisco Umbrella virtual appliances through SNMP: appliance status and connectivity, DNS queries, CPU, load, memory and storage usage and uptime.

The plugin pack provides these checks:

* [Appliance status](#network-cisco-umbrella-snmp-appliance)
* [Connectivity](#network-cisco-umbrella-snmp-connectivity)
* [CPU](#network-cisco-umbrella-snmp-cpu)
* [DNS queries](#network-cisco-umbrella-snmp-query)
* [Load](#network-cisco-umbrella-snmp-load)
* [Memory](#network-cisco-umbrella-snmp-memory)
* [Storage](#network-cisco-umbrella-snmp-storage)
* [Uptime](#os-linux-snmp-uptime)

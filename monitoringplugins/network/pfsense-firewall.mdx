## Description

Monitors pfSense firewalls through SNMP and the API: CPU, memory, swap and load, gateways, interfaces, firewall rules, state table, packet statistics, backup files and runtime.

The plugin pack provides these checks:

* [Backup Files](#apps-pfsense-fauxapi-backup-files)
* [CPU](#apps-pfsense-snmp-cpu)
* [CPU detailed](#apps-pfsense-snmp-cpu-detailed)
* [Gateways](#apps-pfsense-fauxapi-gateways)
* [Load](#apps-pfsense-snmp-load)
* [Memory](#apps-pfsense-snmp-memory)
* [Packet Statistics](#apps-pfsense-snmp-packet-stats)
* [PInterfaces](#apps-pfsense-snmp-pfinterfaces)
* [Rules](#apps-pfsense-fauxapi-rules)
* [Runtime](#apps-pfsense-snmp-runtime)
* [State table](#apps-pfsense-snmp-state-table)
* [Swap](#apps-pfsense-snmp-swap)
* [System](#apps-pfsense-fauxapi-system)
* [Uptime](#apps-pfsense-snmp-uptime)

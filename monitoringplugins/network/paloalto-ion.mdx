## Description

Monitors Palo Alto ION SD-WAN devices through SNMP: CPU, memory swap and storage usage, hardware, interfaces and uptime.

The plugin pack provides these checks:

* [CPU](#network-paloalto-ion-snmp-cpu)
* [Hardware](#network-paloalto-ion-snmp-hardware)
* [Interfaces](#network-paloalto-ion-snmp-interfaces)
* [Memory swap](#network-paloalto-ion-snmp-memory)
* [Storage](#network-paloalto-ion-snmp-storage)
* [Uptime](#network-paloalto-ion-snmp-uptime)

## Discovery

### Host Discovery

The hosts of this plugin pack are found by these host discoveries:

* [Network Topology Discovery](/monitoring/monitoring-resources/discovery/nedi)

### Service Discovery

The service discovery creates one service per discovered object, with these rules:

| Service template | Service name |
|------------------|--------------|
| [Interfaces](#network-paloalto-ion-snmp-interfaces) | `Interface - <name>` |

See [Service Discovery](/monitoring/monitoring-resources/discovery/service-discovery) for how to run it.

|-------|---------------|-------------|
| `SNMPCOMMUNITY` |  | SNMP community |

| `SNMPUSERNAME` |  | SNMP v3 only: User name (`securityName`). |
| `SNMPTIMEOUT` |  | Time to wait before sending the request again if no reply has been received, in seconds (default: 1). See also --snmp-retries. |
| `SNMPAUTH-PASSPHRASE` |  | SNMP v3 only: Pass phrase hashed using the authentication protocol defined in the --authprotocol option. |

#### Macros

<div className="plugin-pack-macros">

| Macro | Default value | Description |
|-------|---------------|-------------|
| `COMPONENT` |  | Which component to check (Default: '.*'). Can be: 'fan', 'temperature', 'psu', 'voltage' |
| `EXTRA-OPTS` |  | Additional options appended to the plugin command line (host level). |
| `FILTER` |  | Exclude the items given as a comma-separated list (example: --filter=fan --filter=psu). You can also exclude items from specific instances: --filter=fan,1.0 |
| `WARNING` |  | Set warning threshold for 'fan', 'temperature', 'voltage' (syntax: type,regexp,threshold). Example: --warning='fan,.*,40' |
| `CRITICAL` |  | Set critical threshold for 'fan', 'temperature', 'voltage' (syntax: type,regexp,threshold). Example: --critical='fan,.*,45' |
| `THRESHOLD-OVERLOAD` |  | Set to overload default threshold values (syntax: section,[instance,]status,regexp) It used before default thresholds (order stays). Example: --threshold-overload='fan,WARNING,testing' |

</div>

</details>

## Description

Monitors the Aruba Orchestrator SD-WAN controller through its REST API: active alarms and the status of the managed appliances.

The plugin pack provides these checks:

* [Alarms](#network-aruba-orchestrator-restapi-alarms)
* [Appliances status](#network-aruba-orchestrator-restapi-appliances)

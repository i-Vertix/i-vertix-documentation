## Description

Monitors Check Point firewalls through SNMP: CPU, memory, disk and system load, connections, interfaces, hardware health, HA, VRRP, VSX and VPN status, remote access users and NTP.

The plugin pack provides these checks:

* [Connections](#network-checkpoint-snmp-connections)
* [CPU](#network-checkpoint-snmp-cpu)
* [Disk](#network-checkpoint-snmp-disk)
* [HA status](#network-checkpoint-snmp-hastate)
* [Hardware status](#network-checkpoint-snmp-hardware)
* [Interfaces](#network-checkpoint-snmp-interfaces)
* [Memory](#network-checkpoint-snmp-memory)
* [NTP](#network-checkpoint-snmp-time)
* [Remote Access users](#network-checkpoint-snmp-ra-users)
* [System Load](#os-linux-snmp-load)
* [Uptime](#network-checkpoint-snmp-uptime)
* [VPN status](#network-checkpoint-snmp-vpn-status)
* [VRRP status](#network-checkpoint-snmp-vrrp-status)
* [VSX](#network-checkpoint-snmp-vsx)

| `SNMPVERSION` |  | SNMP version |

| `SNMPAUTH-PROTOCOL` |  | SNMP v3 only: Authentication protocol: MD5\|SHA. Since net-snmp 5.9.1: SHA224\|SHA256\|SHA384\|SHA512. |

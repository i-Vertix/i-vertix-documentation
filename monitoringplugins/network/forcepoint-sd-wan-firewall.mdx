## Description

Monitors Forcepoint SD-WAN firewalls through SNMP: cluster status and load, connections, CPU, load, memory, swap and disk usage, interfaces, dropped and rejected packets and uptime.

The plugin pack provides these checks:

* [Cluster load](#network-forcepoint-sdwan-snmp-cluster-load)
* [Cluster status](#network-forcepoint-sdwan-snmp-cluster-status)
* [Connections](#network-forcepoint-sdwan-snmp-connections)
* [CPU](#network-forcepoint-sdwan-snmp-cpu)
* [CPU detailed](#network-forcepoint-sdwan-snmp-cpu-detailed)
* [Disk usage](#network-forcepoint-sdwan-snmp-disk-usage)
* [Interfaces](#network-forcepoint-sdwan-snmp-interfaces)
* [Load](#network-forcepoint-sdwan-snmp-load)
* [Memory](#network-forcepoint-sdwan-snmp-memory)
* [Packets dropped](#network-forcepoint-sdwan-snmp-dropped-packets)
* [Packets rejected](#network-forcepoint-sdwan-snmp-rejected-packets)
* [Storages](#network-forcepoint-sdwan-snmp-storage)
* [Swap](#network-forcepoint-sdwan-snmp-swap)
* [Uptime](#network-forcepoint-sdwan-snmp-uptime)

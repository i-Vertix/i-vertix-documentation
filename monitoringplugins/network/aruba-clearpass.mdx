## Description

Monitors Aruba ClearPass policy managers through SNMP: CPU, memory, disk and swap usage, interfaces, RADIUS and TACACS request statistics and the response times of authentication repositories.

The plugin pack provides these checks:

* [CPU](#network-aruba-cppm-snmp-cpu)
* [Disks](#network-aruba-cppm-snmp-disks)
* [Interfaces](#network-aruba-cppm-snmp-interfaces)
* [Memory](#network-aruba-cppm-snmp-memory)
* [Radius](#network-aruba-cppm-snmp-radius)
* [Repositories](#network-aruba-cppm-snmp-repositories)
* [Swap](#network-aruba-cppm-snmp-swap)
* [Tacacs](#network-aruba-cppm-snmp-tacacs)
* [Uptime](#os-linux-snmp-uptime)

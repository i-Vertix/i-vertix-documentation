## Description

Monitors WatchGuard firewalls through SNMP: CPU, memory, swap, load and storage, hardware, cluster status, IPsec, policy usage, interfaces, NTP and system status.

The plugin pack provides these checks:

* [Cluster status](#network-watchguard-snmp-cluster)
* [CPU](#network-watchguard-snmp-cpu)
* [Hardware status](#network-watchguard-snmp-hardware)
* [Interfaces](#network-watchguard-snmp-interfaces)
* [IPSEC](#network-watchguard-snmp-ipsec-tunnel)
* [Memory](#network-watchguard-snmp-memory)
* [NTP](#network-watchguard-snmp-time)
* [Policy usage](#network-watchguard-snmp-policy-usage)
* [Storage](#network-watchguard-snmp-storage)
* [Swap](#network-watchguard-snmp-swap)
* [System](#network-watchguard-snmp-system)
* [System Load](#network-watchguard-snmp-load)
* [Uptime](#network-watchguard-snmp-uptime)

## Discovery

### Host Discovery

The hosts of this plugin pack are found by these host discoveries:

* [Network Topology Discovery](/monitoring/monitoring-resources/discovery/nedi)

### Service Discovery

The service discovery creates one service per discovered object, with these rules:

| Service template | Service name |
|------------------|--------------|
| [Interfaces](#network-watchguard-snmp-interfaces) | `Interface - <name>` |
| [Storage](#network-watchguard-snmp-storage) | `Storage - <name>` |

See [Service Discovery](/monitoring/monitoring-resources/discovery/service-discovery) for how to run it.

| `SNMPUSERNAME` |  | SNMP v3 only: User name (`securityName`). |

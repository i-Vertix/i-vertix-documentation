## Description

Monitors Raisecom network devices through SNMP: CPU and memory usage, hardware health, interfaces and uptime.

The plugin pack provides these checks:

* [CPU](#network-raisecom-snmp-cpu)
* [Hardware](#network-raisecom-snmp-hardware)
* [Interfaces](#network-raisecom-snmp-interfaces)
* [Memory](#network-raisecom-snmp-memory)
* [Uptime](#os-linux-snmp-uptime)

## Discovery

### Hardware {/* #network-raisecom-snmp-hardware */}

</summary>

#### Macros

<div className="plugin-pack-macros">

| Macro | Default value | Description |
|-------|---------------|-------------|
| `COMPONENT` | `.*` | Which component to check (Default: '.*'). Can be: 'temperature', 'fan', 'voltage' |
| `FILTER` |  | Exclude some parts (comma seperated list) (Example: --filter=fan Can also exclude specific instance: --filter=fan,1 |
| `WARNING` |  | Set warning threshold for temperatures, fan speed (syntax: type,instance,threshold) Example: --warning='temperature,.*,30' |
| `CRITICAL` |  | Set critical threshold for temperatures, fan speed (syntax: type,instance,threshold) Example: --critical='temperature,.*,40' |
| `THRESHOLD-OVERLOAD` |  | Set to overload default threshold values (syntax: section,[instance,]status,regexp) It used before default thresholds (order stays). Example: --threshold-overload='fan,WARNING,twoHour' |
| `ABSENT-PROBLEM` |  | Return an error if a component is not 'present' (default is skipping). It can be set globally or for a specific instance: --absent-problem='component_name' or --absent-problem='component_name,instance_value' |
| `NO-COMPONENT` |  | Define the expected status if no components are found (default: critical) |

</div>

</details>

## Changelog

Changes of the plugin pack per release, compared with the previous release.

<details className="plugin-pack-details" open>
<summary>20251100 - 20260114</summary>

- Command `network-raisecom-snmp-hardware`
    - Option `--absent-problem=$_SERVICEABSENT-PROBLEM$` added
    - Option `--no-component=$_SERVICENO-COMPONENT$` added
    - Macro `ABSENT-PROBLEM` added
    - Macro `NO-COMPONENT` added

</details>

<details className="plugin-pack-details">
<summary>20230810 - 20230828</summary>

- Service template [`network-raisecom-snmp-interfaces`](#network-raisecom-snmp-interfaces)
    - Macro `UNITS-TRAFFIC`: default changed from `%` to `percent_delta`
    - Macro `UNITS-ERROR`: default changed from `%` to `percent_delta`
    - Macro `OID-EXTRA-DISPLAY` added (default `ifAlias`)
- Command `network-raisecom-snmp-interfaces`
    - Option `--oid-extra-display=$_SERVICEOID-EXTRA-DISPLAY$` added
    - Macro `OID-EXTRA-DISPLAY` added

</details>

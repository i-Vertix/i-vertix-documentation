## Description

Monitors Aruba CX switches through SNMP and the HTTPS API: CPU and memory usage, hardware health, interfaces, spanning tree, stack and virtual chassis status and Virtual Switching Extension.

The plugin pack provides these checks:

* [CPU](#network-aruba-aoscx-snmp-cpu)
* [Hardware](#network-aruba-aoscx-restapi-hardware) (`network-aruba-aoscx-restapi-hardware`)
* [Hardware](#network-aruba-aoscx-snmp-hardware) (`network-aruba-aoscx-snmp-hardware`)
* [Interfaces](#network-aruba-aoscx-snmp-interfaces)
* [Memory](#network-aruba-aoscx-snmp-memory)
* [Spanning tree](#network-aruba-aoscx-snmp-spanning-tree)
* [Stack status](#network-aruba-aoscx-snmp-stack)
* [Uptime](#os-linux-snmp-uptime)
* [Virtual Chassis](#network-aruba-aoscx-snmp-vsf)
* [Virtual Switching Extension](#network-aruba-aoscx-restapi-vsx) (`network-aruba-aoscx-restapi-vsx`)
* [Virtual Switching Extension](#network-aruba-aoscx-snmp-vsx) (`network-aruba-aoscx-snmp-vsx`)

#### Macros

<div className="plugin-pack-macros">

| Macro | Default value | Description |
|-------|---------------|-------------|
| `COMPONENT` | `.*` | Which component to check (Default: '.*'). Can be: 'psu', 'temperature', 'fan', 'fantry' |
| `FILTER` |  | Exclude some parts (comma seperated list) (Example: --filter=psu) Can also exclude specific instance: --filter=fan,1.1 |
| `WARNING` |  | Set warning threshold for 'temperature', 'fan.speed', 'psu.power' (syntax: section,[instance,]status,regexp) Example: --warning='temperature,.*,30' --warning='fan.speed,.*,1000' |
| `CRITICAL` |  | Set critical threshold for 'temperature', 'fan.speed', 'psu.power' (syntax: section,[instance,]status,regexp) Example: --critical='temperature,.*,40' |
| `THRESHOLD-OVERLOAD` |  | Set to overload default threshold values (syntax: section,status,regexp) It used before default thresholds (order stays). Example: --threshold-overload='fan,WARNING,string' |
| `NO-COMPONENT` |  | Define the expected status if no components are found (default: critical) |

</div>

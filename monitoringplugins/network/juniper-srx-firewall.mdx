## Description

Monitors Juniper SRX firewalls through SNMP: CPU and memory usage, forwarding plane usage, hardware, storage, interfaces, IPsec tunnels and session usage of the central point and packet forwarding engine.

The plugin pack provides these checks:

* [Central Point sessions](#network-juniper-srx-snmp-cp-sessions)
* [CPU](#network-juniper-srx-snmp-cpu)
* [CPU forwarding](#network-juniper-srx-snmp-cpu-forwarding)
* [Hardware](#network-juniper-srx-snmp-hardware)
* [Interfaces](#network-juniper-srx-snmp-interfaces)
* [IPsec tunnels](#network-juniper-srx-snmp-ipsec-tunnel)
* [Memory](#network-juniper-srx-snmp-memory)
* [Memory forwarding](#network-juniper-srx-snmp-memory-forwarding)
* [Packet Forwarding Engine sessions usage](#network-juniper-srx-snmp-flow-sessions)
* [Storage](#network-juniper-srx-snmp-storage)
* [Uptime](#os-linux-snmp-uptime)

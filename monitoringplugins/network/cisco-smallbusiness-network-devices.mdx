## Description

Monitors Cisco Small Business switches through SNMP: CPU usage, environment sensors, interfaces, spanning tree, stack status and uptime.

The plugin pack provides these checks:

* [CPU](#network-cisco-smallbusiness-standard-snmp-cpu)
* [Environment](#network-cisco-smallbusiness-standard-snmp-environment)
* [Interfaces](#network-cisco-smallbusiness-standard-snmp-interfaces)
* [Spanning-tree](#network-cisco-smallbusiness-standard-snmp-spanning-tree)
* [Stack status](#network-cisco-smallbusiness-standard-snmp-stack)
* [Uptime](#network-cisco-smallbusiness-standard-snmp-uptime)

## Discovery

| `SNMPUSERNAME` |  | SNMP v3 only: User name (`securityName`). |

### Environment {/* #network-cisco-smallbusiness-standard-snmp-environment */}

</summary>

#### Macros

<div className="plugin-pack-macros">

| Macro | Default value | Description |
|-------|---------------|-------------|
| `COMPONENT` | `.*` | Which component to check (Default: '.*'). Can be: 'fan', 'psu' |
| `FILTER` |  | Exclude some parts (comma seperated list) (Example: --filter=psu) Can also exclude specific instance: --filter=psu,0 |
| `WARNING` |  | Threshold warning. Example: --warning='temperature,.*,30' |
| `CRITICAL` |  | Threshold critical. Example: --warning='temperature,.*,40' |
| `THRESHOLD-OVERLOAD` |  | Set to overload default threshold values (syntax: section,[instance,]status,regexp) It used before default thresholds (order stays). Example: --threshold-overload='fan,CRITICAL,^(?!(normal)$)' |
| `ABSENT-PROBLEM` |  | Return an error if a component is not 'present' (default is skipping). It can be set globally or for a specific instance: --absent-problem='component_name' or --absent-problem='component_name,instance_value' |
| `NO-COMPONENT` |  | Define the expected status if no components are found (default: critical) |

</div>

</details>

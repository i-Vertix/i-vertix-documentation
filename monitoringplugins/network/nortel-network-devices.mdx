## Description

Monitors Nortel network devices through SNMP: CPU and memory usage, hardware health, stack status, interfaces and uptime.

The plugin pack provides these checks:

* [CPU](#network-nortel-standard-snmp-cpu)
* [Hardware](#network-nortel-standard-snmp-hardware)
* [Interfaces](#network-nortel-standard-snmp-interfaces)
* [Memory](#network-nortel-standard-snmp-memory)
* [Stack status](#network-nortel-standard-snmp-stack)
* [Uptime](#os-linux-snmp-uptime)

## Discovery

### Host Discovery

The hosts of this plugin pack are found by these host discoveries:

* [Network Topology Discovery](/monitoring/monitoring-resources/discovery/nedi)

### Service Discovery

The service discovery creates one service per discovered object, with these rules:

| Service template | Service name |
|------------------|--------------|
| [Interfaces](#network-nortel-standard-snmp-interfaces) | `Interface - <name>` |

See [Service Discovery](/monitoring/monitoring-resources/discovery/service-discovery) for how to run it.

</div>

### Hardware {/* #network-nortel-standard-snmp-hardware */}

</summary>

#### Macros

<div className="plugin-pack-macros">

| Macro | Default value | Description |
|-------|---------------|-------------|
| `COMPONENT` |  | Which component to check (default: '.*'). Can be: 'fan', 'psu', 'card', 'entity', 'led', 'temperature' |
| `CRITICAL` |  | Set critical threshold (syntax: type,regexp,threshold) Example: --critical='temperature,.*,40' |
| `FILTER` |  | Exclude some parts (comma seperated list) (Example: --filter=psu) Can also exclude specific instance: --filter=psu,1 |
| `NO-COMPONENT` |  | Define the expected status if no components are found (default: critical) |
| `THRESHOLD-OVERLOAD` |  | Set to overload default threshold values (syntax: section,[instance,]status,regexp) It used before default thresholds (order stays). Example: --threshold-overload='entity,WARNING,disabled' |
| `WARNING` |  | Set warning threshold (syntax: type,regexp,threshold) Example: --warning='temperature,.*,30' --warning=fan.temperature,.*,10 |

</div>

</details>

## Description

Monitors Cisco routers and switches through SNMP: CPU, memory and load, environment sensors, interfaces, spanning tree, stacking, VSS and vPC, BGP and HSRP, IP SLA, QoS, voice calls and configuration status.

The plugin pack provides these checks:

* [AAA Servers](#network-cisco-standard-snmp-aaa-servers)
* [ARP](#network-cisco-standard-snmp-arp)
* [BGP Peer state](#network-cisco-standard-snmp-bgp)
* [Configuration status](#check_nwc_health_cisco-configstatus-snmpv3) (`check_nwc_health_cisco-configstatus-snmpv3`)
* [Configuration status](#network-cisco-standard-snmp-configuration) (`network-cisco-standard-snmp-configuration`)
* [CPU](#network-cisco-standard-snmp-cpu)
* [Environment](#network-cisco-standard-snmp-environment) (`network-cisco-standard-snmp-environment`)
* [Environment](#network-cisco-standard-snmp-environment-catalyst) (`network-cisco-standard-snmp-environment-catalyst`)
* [HSRP](#network-cisco-standard-snmp-hsrp)
* [Interfaces](#network-cisco-standard-snmp-interfaces)
* [IP SLA](#network-cisco-standard-snmp-ipsla)
* [Load](#network-cisco-standard-snmp-load)
* [Memory](#network-cisco-standard-snmp-memory) (`network-cisco-standard-snmp-memory`)
* [Memory](#network-cisco-standard-snmp-memory-catalyst) (`network-cisco-standard-snmp-memory-catalyst`)
* [Memory flash](#network-cisco-standard-snmp-memory-flash)
* [QoS usage](#network-cisco-standard-snmp-qos-usage)
* [Spanning tree](#network-cisco-standard-snmp-spanning-tree)
* [Stack](#network-cisco-standard-snmp-stack)
* [Uptime](#network-cisco-standard-snmp-uptime)
* [Virtual Stack](#network-cisco-standard-snmp-stack-virtual)
* [Voice calls](#network-cisco-standard-snmp-voice-call)
* [vPC](#network-cisco-standard-snmp-vpc)
* [VSS](#network-cisco-standard-snmp-vss)
* [WAN 3G](#network-cisco-standard-snmp-wan3g)

## Host Templates

### Cisco-Bridge-IOS

*Cisco Bridge IOS* · Parent template: `generic-host`

<details className="plugin-pack-details">
<summary>Macros (9)</summary>

<div className="plugin-pack-macros">

| Macro | Default value | Description |
|-------|---------------|-------------|
| `SNMPCOMMUNITY` |  | SNMP community |
| `SNMPVERSION` |  | SNMP version |
| `SNMPUSERNAME` |  | SNMP v3 only: User name (`securityName`). |
| `SNMPAUTH-PASSPHRASE` |  | SNMP v3 only: Pass phrase hashed using the authentication protocol defined in the --authprotocol option. |
| `SNMPAUTH-PROTOCOL` |  | SNMP v3 only: Authentication protocol: MD5\|SHA. Since net-snmp 5.9.1: SHA224\|SHA256\|SHA384\|SHA512. |
| `SNMPPRIV-PASSPHRASE` |  | SNMP v3 only: Privacy pass phrase (`privPassword`) to encrypt messages using the protocol defined in the --privprotocol option. |
| `SNMPPRIV-PROTOCOL` |  | SNMP v3 only: Privacy protocol (`privProtocol`) used to encrypt messages. Supported protocols are: DES\|AES and since net-snmp 5.9.1: AES192\|AES192C\|AES256\|AES256C. |
| `SNMPTIMEOUT` |  | Time to wait before sending the request again if no reply has been received, in seconds (default: 1). See also --snmp-retries. |
| `EXTRA-OPTS` |  | Additional options appended to the plugin command line (host level). |

</div>

Macros without a default value are only defined in the check commands. Set them on the host where needed.

</details>

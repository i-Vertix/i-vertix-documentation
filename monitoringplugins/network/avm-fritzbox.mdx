## Description

Monitors AVM Fritzbox routers through their API: system status and uptime as well as the traffic on the WAN interface.

The plugin pack provides these checks:

* [System status](#network-fritzbox-upnp-system)
* [Traffic](#network-fritzbox-upnp-traffic)


## Host Templates

### FritzBox-Router

*FritzBox Router* · Parent template: `generic-host`

<details className="plugin-pack-details">

<div className="plugin-pack-macros">

| Macro | Default value | Description |

| `PORT` | `49000` | API port (default: 49000) |
| `PROTOCOL` | `http` | Specify https if needed (default: 'http') |
| `HTTP-BACKEND` | `lwp` | Perl library to use for HTTP transactions. Possible values are: lwp (default) and curl. |
| `AGENT` | `igdupnp` | Fritzbox has two different UPNP agents: upnp or igdupnp (default: igdupnp). |
| `API-PASSWORD` | *(password)* | Set API password |
| `TIMEOUT` |  | Set HTTP timeout |
| `API-USERNAME` |  | Set API username |

</div>

Macros without a default value are only defined in the check commands. Set them on the host where needed.

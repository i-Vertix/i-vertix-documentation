## Description

Monitors Cisco Meraki cloud-managed networks through the Meraki Dashboard API: networks, device status and usage, VPN tunnels and the state of the API cache.

The plugin pack provides these checks:

* [Device usage](#network-cisco-meraki-cloudcontroller-restapi-devices) (`network-cisco-meraki-cloudcontroller-restapi-devices`)
* [Device usage](#network-cisco-meraki-cloudcontroller-restapi-devices-cache) (`network-cisco-meraki-cloudcontroller-restapi-devices-cache`)
* [Meraki API cache](#ivertix-host-discovery-meraki-cache)
* [Networks](#network-cisco-meraki-cloudcontroller-restapi-networks)
* [VPN tunnels](#network-cisco-meraki-cloudcontroller-restapi-vpn-tunnels)

## Discovery

### Host Discovery

The hosts of this plugin pack are found by these host discoveries:

* [Cisco Meraki Discovery](/monitoring/monitoring-resources/discovery/meraki-discovery)

### Service Discovery

The service discovery creates one service per discovered object, with these rules:

| Service template | Service name |
|------------------|--------------|
| [Device usage](#network-cisco-meraki-cloudcontroller-restapi-devices) | `Device - <name>` |
| [Device usage](#network-cisco-meraki-cloudcontroller-restapi-devices) | `Devices tag - <name>` |
| [VPN tunnels](#network-cisco-meraki-cloudcontroller-restapi-vpn-tunnels) | `VPN tunnel - <name>` |

See [Service Discovery](/monitoring/monitoring-resources/discovery/service-discovery) for how to run it.

| `TIMEOUT` | `15` | Define the timeout for HTTP requests. |
| `API-FILTER-ORGS` |  | Filter organizations (regexp) |
| `MERAKI-EXTRA-OPTS` |  | Filter organizations (regexp) |

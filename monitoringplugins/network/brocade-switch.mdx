## Description

Monitors Brocade switches through SNMP: CPU and memory usage, hardware health, interfaces including packet errors and optical power values of SFP ports, and uptime.

The plugin pack provides these checks:

* [CPU](#network-brocade-cpu)
* [Hardware status](#network-brocade-hardware)
* [Interfaces](#network-brocade-interfaces)
* [Memory](#network-brocade-memory)
* [SFP port status](#network-brocade-snmp-sfp-port)
* [Uptime](#os-linux-snmp-uptime)

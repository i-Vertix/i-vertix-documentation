## Description

Monitors Nokia (Alcatel) ISAM access nodes through SNMP: CPU and memory usage, hardware, interfaces and hub SAP usage.

The plugin pack provides these checks:

* [CPU](#network-nokia-isam-snmp-cpu)
* [Hardware](#network-nokia-isam-snmp-hardware)
* [Hub SAP usage](#network-nokia-isam-snmp-hub-sap-usage)
* [Interfaces](#network-alcatel-isam-snmp-interfaces)
* [Memory](#network-nokia-isam-snmp-memory)
* [Uptime](#os-linux-snmp-uptime)

## Discovery

#### Macros

<div className="plugin-pack-macros">

| Macro | Default value | Description |
|-------|---------------|-------------|
| `COMPONENT` |  | Which component to check (Default: '.*'). Can be: 'cardtemperature', 'sfp' |
| `FILTER` |  | Exclude some parts (comma seperated list) (Example: --filter=cardtemperature) Can also exclude specific instance: --filter=cardtemperature,1080.1 |
| `WARNING` |  | Set warning threshold for 'sfp.temperature', 'cardtemperature' (syntax: type,regexp,threshold) Example: --warning='sfp.temperature,1.1,30' |
| `CRITICAL` |  | Set critical threshold for 'sfp.temperature', 'cardtemperature' (syntax: type,regexp,threshold) Example: --warning='sfp.temperature,1.1,40' |
| `THRESHOLD-OVERLOAD` |  | Set to overload default threshold values (syntax: section,[instance,]status,regexp) It used before default thresholds (order stays). Example: --threshold-overload='sfp,OK,^los$' |
| `EXTRA-OPTS` |  | Additional options appended to the plugin command line (host level). |

</div>

</details>

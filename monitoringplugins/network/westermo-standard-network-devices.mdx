## Description

Monitors Westermo network devices through SNMP: CPU, memory and load, sensors, interfaces, the spanning tree, TCP and UDP connections and uptime.

The plugin pack provides these checks:

* [CPU](#network-westermo-standard-snmp-cpu)
* [Interfaces](#network-westermo-standard-snmp-interfaces)
* [Memory](#network-westermo-standard-snmp-memory)
* [Sensors](#network-westermo-standard-snmp-sensors)
* [Spanning tree](#network-westermo-standard-snmp-spanning-tree)
* [System Load](#network-westermo-standard-snmp-load)
* [TCP connections](#network-westermo-standard-snmp-tcpcon)
* [UDP connections](#network-westermo-standard-snmp-udpcon)
* [Uptime](#network-westermo-standard-snmp-uptime)

## Discovery

### Host Discovery

The hosts of this plugin pack are found by these host discoveries:

* [Network Topology Discovery](/monitoring/monitoring-resources/discovery/nedi)

### Service Discovery

The service discovery creates one service per discovered object, with these rules:

| Service template | Service name |
|------------------|--------------|
| [Interfaces](#network-westermo-standard-snmp-interfaces) | `Interface - <name>` |
| [Spanning tree](#network-westermo-standard-snmp-spanning-tree) | `Spanning tree - <port>` |

See [Service Discovery](/monitoring/monitoring-resources/discovery/service-discovery) for how to run it.

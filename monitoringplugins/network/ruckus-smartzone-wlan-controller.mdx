## Description

Monitors Ruckus SmartZone WLAN controllers through SNMP: CPU, memory, load and storage, system status, interfaces and the managed access points.

The plugin pack provides these checks:

* [Access Points](#network-ruckus-smartzone-snmp-access-points)
* [CPU](#network-ruckus-smartzone-snmp-cpu)
* [Interfaces](#network-ruckus-smartzone-snmp-interfaces)
* [Load](#network-ruckus-smartzone-snmp-load)
* [Memory](#network-ruckus-smartzone-snmp-memory)
* [Storage](#network-ruckus-smartzone-snmp-storage)
* [System](#network-ruckus-smartzone-snmp-system)
* [Uptime](#os-linux-snmp-uptime)

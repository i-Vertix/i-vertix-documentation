## Description

Monitors Cisco Unified Communications Manager through its SXML API: active alerts and the status of the services.

The plugin pack provides these checks:

* [Alerts](#network-cisco-callmanager-sxml-alerts)
* [Services](#network-cisco-callmanager-sxml-services)


## Host Templates

*Cisco Call Manager SXML* · Parent template: `generic-host`

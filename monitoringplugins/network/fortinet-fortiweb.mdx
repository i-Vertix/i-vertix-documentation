## Description

Monitors Fortinet FortiWeb web application firewalls through SNMP: system resources such as CPU, memory and log disk, proxy connections and services, interfaces and uptime.

The plugin pack provides these checks:

* [Interfaces](#network-fortinet-fortiweb-snmp-interfaces)
* [Proxy](#network-fortinet-fortiweb-snmp-proxy)
* [System](#network-fortinet-fortiweb-snmp-system)
* [Uptime](#os-linux-snmp-uptime)

## Discovery

### Service Discovery

The service discovery creates one service per discovered object, with these rules:

| Service template | Service name |
|------------------|--------------|
| [Interfaces](#network-fortinet-fortiweb-snmp-interfaces) | `Interface - <name>` |

See [Service Discovery](/monitoring/monitoring-resources/discovery/service-discovery) for how to run it.

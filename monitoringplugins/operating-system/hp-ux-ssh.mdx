## Description

Monitors HP-UX systems through SSH: storage and inodes usage.

The plugin pack provides these checks:

* [Inodes](#os-hpux-local-inodes)
* [Storage](#os-hpux-local-storage)

## Discovery

### Service Discovery

The service discovery creates one service per discovered object, with these rules:

| Service template | Service name |
|------------------|--------------|
| [Inodes](#os-hpux-local-inodes) | `Inodes - <name>` |
| [Storage](#os-hpux-local-storage) | `Storage - <name>` |

See [Service Discovery](/monitoring/monitoring-resources/discovery/service-discovery) for how to run it.

## Host Templates

### HP-UX-SSH

*HP UX SSH* · Parent template: `generic-host`

<details className="plugin-pack-details">
<summary>Macros (6)</summary>

<div className="plugin-pack-macros">

| Macro | Default value | Description |
|-------|---------------|-------------|
| `SSH-PORT` | `22` | Define the TCP port on which SSH is listening. |
| `EXTENDED-OPTIONS` | `--sudo` |  |
| `SSH-BACKEND` |  | Set the backend used (Default: 'sshcli') Can be: sshcli, plink, libssh |
| `SSH-PASSWORD` |  | Login with specified password. Cannot be used with sshcli backend |
| `SSH-PRIV-KEY` |  | Private key file for user authentication |
| `SSH-USERNAME` |  | Connect with specified username |

</div>

Macros without a default value are only defined in the check commands. Set them on the host where needed.

</details>

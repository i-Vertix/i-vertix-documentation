## Description

Monitors IBM AIX servers over SSH: disk space and inode usage, logical volume synchronization, processes, the error report (errpt) and the result of custom commands.

The plugin pack provides these checks:

* [Command Return](#os-aix-local-cmd-return)
* [Errpt](#os-aix-local-errpt)
* [Inodes](#os-aix-local-inodes)
* [Logical Volume Sync](#os-aix-local-lvsync)
* [Process](#os-aix-local-process)
* [Storage](#os-aix-local-storage)

## Discovery

### Service Discovery

The service discovery creates one service per discovered object, with these rules:

| Service template | Service name |
|------------------|--------------|
| [Inodes](#os-aix-local-inodes) | `Inodes - <name>` |
| [Storage](#os-aix-local-storage) | `Storage - <name>` |

See [Service Discovery](/monitoring/monitoring-resources/discovery/service-discovery) for how to run it.

| Macro | Default value | Description |
|-------|---------------|-------------|
| `SSH-BACKEND` | `sshcli` | Define the backend you want to use. It can be: `sshcli` (default for most plugins), `plink` and `libssh`. |
| `SSHCLI-OPTION` | `-o=StrictHostKeyChecking=no` | Specify SSH CLI options (example: --sshcli-option='-o=StrictHostKeyChecking=no -o=LogLevel=ERROR'). The default parameter is --sshcli-option='-o=LogLevel=ERROR' which hides the SSH banner. If you override this parameter, make sure to append '-o=LogLevel=ERROR' to your new value to maintain this behavior. This parameter can be used multiple times and multiple options can be specified in the same parameter. |
| `SSH-PASSWORD` | *(password)* | Define the password associated with the user name. Cannot be used with the `sshcli` backend. Warning: using a password is not recommended. Use `--ssh-priv-key` instead. |
| `SSHCLI-OPTION2` | `-o=LogLevel=ERROR` | hides the SSH banner |
| `SSH-USERNAME` |  | Define the user name to log in to the host. |
| `SSH-PRIV-KEY` |  | Define the private key file to use for user authentication. |
| `EXTRA-OPTS` |  | Additional options appended to the plugin command line (host level). |

</div>

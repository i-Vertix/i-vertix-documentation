## Description

Monitors Windows systems through the i-Vertix agent: CPU, memory, pagefile and disks, services, processes, event logs, certificates, files, sessions, scheduled tasks, pending updates and reboots, and uptime.

The plugin pack provides these checks:

* [Certificates](#ivertix-agent-os-windows-local-certificates)
* [Check Logfiles](#ivertix-agent-check_logfiles)
* [CPU](#ivertix-agent-check_cpu)
* [Disk C:](#ivertix-agent-check_drivesize-c)
* [Event log](#ivertix-agent-check_eventlog)
* [Files](#ivertix-agent-check_files)
* [Memory](#ivertix-agent-check_memory)
* [Pagefile](#ivertix-agent-check_pagefile)
* [Pending reboot](#ivertix-agent-os-windows-local-pending-reboot)
* [Pending updates](#ivertix-agent-os-windows-local-updates)
* [Performance Counter](#ivertix-agent-check_pdh) (`ivertix-agent-check_pdh`)
* [Performance Counter](#ivertix-agent-check_pdh-diff) (`ivertix-agent-check_pdh-diff`)
* [Ping](#ivertix-agent-check_ping)
* [Process](#ivertix-agent-check_process)
* [Remote ping](#ivertix-agent-remote-ping)
* [Remote TCP port](#ivertix-agent-remote-tcp-port)
* [Service DHCP Client](#ivertix-agent-check_service-dhcp-client)
* [Service DNS Client](#ivertix-agent-check_service-dns-client)
* [Service Plug and Play](#ivertix-agent-check_service-plug-and-play)
* [Service Server](#ivertix-agent-check_service-server)
* [Service TCP/IP NetBIOS Helper](#ivertix-agent-check_service-tcpip-netbios-helper)
* [Service Windows Event Log](#ivertix-agent-check_service-windows-eventlog)
* [Service Workstation](#ivertix-agent-check_service-workstation)

* [Uptime](#ivertix-agent-check_uptime)

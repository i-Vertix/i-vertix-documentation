## Description

Monitors IBM AS400 (iSeries) systems: disks, subsystems, job queues and individual system jobs, message queues such as QSYSOPR, page faults and overall system utilization.

The plugin pack provides these checks:

* [Command](#os-as400-connector-command)
* [Disks](#os-as400-connector-disks)
* [Job QALERT](#os-as400-connector-jobs-qalert)
* [Job QFILESYS1](#os-as400-connector-jobs-qfilesys1)
* [Job QJOBSCD](#os-as400-connector-jobs-qjobscd)
* [Job QLUR](#os-as400-connector-jobs-qlur)
* [Job QLUS](#os-as400-connector-jobs-qlus)
* [Job QQQTEMP1](#os-as400-connector-jobs-qqqtemp1)
* [Job QQQTEMP2](#os-as400-connector-jobs-qqqtemp2)
* [Job QSPLMAINT](#os-as400-connector-jobs-qsplmaint)
* [Job QSPPF00001](#os-as400-connector-jobs-qsppf00001)
* [Job QSPRC00001](#os-as400-connector-jobs-qsprc00001)
* [Job QSYSARB](#os-as400-connector-jobs-qsysarb)
* [Job QTCPCTL](#os-as400-connector-jobs-qtcpctl)
* [Job QTCPWRK](#os-as400-connector-jobs-qtcpwrk)
* [Job Queues](#os-as400-connector-job-queues)
* [Job QWCPJOBS](#os-as400-connector-jobs-qwcpjobs)
* [Job QWCTJOBS](#os-as400-connector-jobs-qwctjobs)
* [Job SCPF](#os-as400-connector-jobs-scpf)
* [Message queue](#os-as400-connector-message-queue)
* [Message queue - QSYSOPR](#os-as400-connector-message-queue-qsysopr.msgq)

### Service Discovery

| `WARNING-STATUS` | `'%{status} =~ /noReady\|busy\|hwFailureOk\|hwFailurePerf\|Protected\|rebuilding/i'` | Set warning threshold for status (Default: '%\{status\} =~ /noReady\|busy\|hwFailureOk\|hwFailurePerf\|Protected\|rebuilding/i'). Can used special variables like: %\{status\}, %\{name\} |
| `CRITICAL-STATUS` | `'%{status} =~ /^(noAccess\|otherDiskSubFailed\|failed\|notOperational\|noUnitControl)$/i'` | Set critical threshold for status (Default: '%\{status\} =~ /^(noAccess\|otherDiskSubFailed\|failed\|notOperational\|noUnitControl)$/i'). Can used special variables like: %\{status\}, %\{name\} |
| `WARNING-SPACE-USAGE-PRCT` | `90` | Warning threshold Disk space usage (%) |

| `INCLUDE-DISK-NAME` |  | Filter disks by name (can be a regexp) |

| `WARNING-SPACE-USAGE-FREE` |  | Warning threshold Disk space usage free (B) |
| `WARNING-RESERVED` |  | Warning threshold Disk space reserved (B) |

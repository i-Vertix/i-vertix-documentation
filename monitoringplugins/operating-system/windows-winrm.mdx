## Description

Monitors Windows systems through WinRM: CPU, memory, pagefile and disks, interfaces, services, processes, event log, files, certificates, sessions, scheduled tasks, pending updates and reboots, NTP time and uptime.

The plugin pack provides these checks:

* [Certificate validity](#os-windows-wsman-certificates)
* [CPU](#os-windows-wsman-cpu)
* [Disks](#os-windows-wsman-storages)
* [Eventlog](#os-windows-wsman-eventlog)
* [Files count](#os-windows-wsman-files-count)
* [Files date](#os-windows-wsman-files-date)
* [Files size](#os-windows-wsman-files-size)
* [Interfaces](#os-windows-wsman-interfaces)
* [Memory](#os-windows-wsman-memory)
* [NTP time](#os-windows-wsman-time)
* [Pagfile usage](#os-windows-wsman-pages)
* [Pending reboot](#os-windows-wsman-pending-reboot)
* [Pending updates](#os-windows-wsman-updates)
* [Processes](#os-windows-wsman-processes)
* [Service status - DHCP Client](#os-windows-wsman-services-dhcp-client)
* [Service status - DNS Client](#os-windows-wsman-services-dns-client)
* [Service status - Plug and Play](#os-windows-wsman-services-plug-and-play)
* [Service status - Server](#os-windows-wsman-services-server)
* [Service status - TCP/IP NetBIOS Helper](#os-windows-wsman-services-tcpip-netbios-helper)
* [Service status - Windows Event Log](#os-windows-wsman-services-windows-eventlog)
* [Service status - Workstation](#os-windows-wsman-services-workstation)
* [Sessions](#os-windows-wsman-sessions)
* [Task scheduler](#os-windows-wsman-taskscheduler)
* [Uptime](#os-windows-wsman-uptime)

## Discovery

### Host Discovery

The hosts of this plugin pack are found by these host discoveries:

* [Network Scan](/monitoring/monitoring-resources/discovery/host-discovery)

### Service Discovery

The service discovery creates one service per discovered object, with these rules:

<div className="plugin-pack-templates">

| Service template | Service name |
|------------------|--------------|
| [Interfaces](#os-windows-wsman-interfaces) | `Interface - <name>` |
| [Processes](#os-windows-wsman-processes) | `Process - <name>` |
| `os-windows-wsman-services` | `Service status - <name>` |
| [Disks](#os-windows-wsman-storages) | `Disk - <name>` |
| [Task scheduler](#os-windows-wsman-taskscheduler) | `Task scheduler - <taskname>` |

</div>

See [Service Discovery](/monitoring/monitoring-resources/discovery/service-discovery) for how to run it.

### Windows-Server-WinRM

*Windows Server (WinRM)* · Parent template: `generic-host`

<details className="plugin-pack-details">
<summary>Macros (8)</summary>

<div className="plugin-pack-macros">

| Macro | Default value | Description |
|-------|---------------|-------------|
| `WSMAN-PORT` | `5986` | Define the port to connect to (default: 5985). |
| `WSMAN-PATH` | `/wsman` | Define the path of the WSMAN URL if it has been customized (default: '/wsman'). |
| `WSMAN-SCHEME` | `https` | Define the transport scheme (default: 'http'). |
| `WSMAN-TIMEOUT` | `30` | Define the HTTP transport timeout in seconds (default: 30). |
| `WSMAN-AUTH-METHOD` | `basic` | Define the authentication method. Available methods: `noauth`, `basic` (default), `pass`, `digest`, `ntlm`, `gssnegotiate`. |
| `WSMAN-PASSWORD` | *(password)* | Define the password associated with the user name. |
| `WSMAN-USERNAME` |  | Define the username for authentication. |
| `WSMAN-PROXY-URL` |  | Define the URL of the HTTP proxy to use. |

</div>

Macros without a default value are only defined in the check commands. Set them on the host where needed.

</details>

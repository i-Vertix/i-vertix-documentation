## Description

Monitors Windows systems through SNMP: CPU, memory and swap usage, interfaces, selected Windows services, process count, NTP time offset and uptime.

The plugin pack provides these checks:

* [CPU](#os-windows-snmp-cpu)
* [Interfaces](#os-windows-snmp-interfaces)
* [Memory usage](#os-windows-snmp-memory)
* [NTP](#os-windows-snmp-time)
* [Process count](#os-windows-snmp-processcount)
* [Service DHCP Client](#os-windows-snmp-service-dhcp-client)
* [Service DNS Client](#os-windows-snmp-service-dns-client)
* [Service Plug and Play](#os-windows-snmp-service-plug-and-play)
* [Service Server](#os-windows-snmp-service-server)
* [Service TCP/IP NetBIOS Helper](#os-windows-snmp-service-tcpip-netbios-helper)
* [Service Windows Event Log](#os-windows-snmp-service-windows-event-log)
* [Service Workstation](#os-windows-snmp-service-workstation)
* [Swap usage](#os-windows-snmp-swap)
* [Uptime](#os-windows-snmp-uptime)

## Discovery

### Host Discovery

The hosts of this plugin pack are found by these host discoveries:

* [Network Topology Discovery](/monitoring/monitoring-resources/discovery/nedi)
* [Network Scan](/monitoring/monitoring-resources/discovery/host-discovery)

### Service Discovery

The service discovery creates one service per discovered object, with these rules:

| Service template | Service name |
|------------------|--------------|
| [Interfaces](#os-windows-snmp-interfaces) | `Interface - <name>` |
| [Process count](#os-windows-snmp-processcount) | `Process - <name>` |
| `os-windows-snmp-service` | `Service - <name>` |
| `os-windows-snmp-storage` | `Disk <name>` |

See [Service Discovery](/monitoring/monitoring-resources/discovery/service-discovery) for how to run it.

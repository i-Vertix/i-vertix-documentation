## Description

Monitors Huawei OceanStor storage through SNMP: controller CPU and memory, hardware status, LUN and storage pool usage, and uptime.

The plugin pack provides these checks:

* [Controllers](#storage-huawei-oceanstor-snmp-controllers)
* [Hardware](#storage-huawei-oceanstor-snmp-hardware)
* [Luns](#storage-huawei-oceanstor-snmp-luns)
* [Storage pools](#storage-huawei-oceanstor-snmp-storage-pools)
* [Uptime](#os-linux-snmp-uptime)

## Discovery

### Service Discovery

The service discovery creates one service per discovered object, with these rules:

| Service template | Service name |

See [Service Discovery](/monitoring/monitoring-resources/discovery/service-discovery) for how to run it.

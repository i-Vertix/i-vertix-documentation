## Description

Monitors Pure Storage FlashArray through its REST API: alerts, hardware status, array and volume space usage, data reduction and array read/write throughput and latency.

The plugin pack provides these checks:

* [Alerts](#storage-purestorage-flasharray-v2-alerts)
* [Arrays](#storage-purestorage-flasharray-v2-arrays)
* [Hardware](#storage-purestorage-flasharray-v2-hardware)
* [Volumes](#storage-purestorage-flasharray-v2-volumes)

## Discovery

### Service Discovery

The service discovery creates one service per discovered object, with these rules:

| Service template | Service name |
|------------------|--------------|
| [Arrays](#storage-purestorage-flasharray-v2-arrays) | `Array - <name>` |
| [Volumes](#storage-purestorage-flasharray-v2-volumes) | `Volume - <name>` |

See [Service Discovery](/monitoring/monitoring-resources/discovery/service-discovery) for how to run it.

## Description

Monitors Dell EMC XtremIO arrays through the REST API: cluster health, data protection groups, SSD endurance and IOPS, storage controllers, and the status and CPU of the XEnvs.

The plugin pack provides these checks:

* [Cluster health](#storage-emc-xtremio-restapi-cluster-health)
* [DPG - Data protection group](#storage-emc-xtremio-restapi-dgp)
* [SSDS endurance](#storage-emc-xtremio-restapi-ssds-endurance)
* [SSDS IOPS](#storage-emc-xtremio-restapi-ssds-iops)
* [Storage controllers](#storage-emc-xtremio-restapi-storage-controllers)
* [XENVS CPU](#storage-emc-xtremio-restapi-xenvs-cpu)
* [XENVS status](#storage-emc-xtremio-restapi-xenvs-state)

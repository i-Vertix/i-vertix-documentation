## Description

Monitors StorMagic SvSAN virtual SANs through SNMP: system status, mirrors, pools and uptime.

The plugin pack provides these checks:

* [Mirrors](#storage-stormagic-svsan-snmp-mirrors)
* [Pools](#storage-stormagic-svsan-snmp-pools)
* [System status](#storage-stormagic-svsan-snmp-system-status)
* [Uptime](#storage-stormagic-svsan-snmp-uptime)

## Discovery

### Service Discovery

The service discovery creates one service per discovered object, with these rules:

| Service template | Service name |
|------------------|--------------|
| [Mirrors](#storage-stormagic-svsan-snmp-mirrors) | `Mirror <mirror_name> (NSH: <mirror_nsh>)` |
| [Pools](#storage-stormagic-svsan-snmp-pools) | `Pool <pool_name>` |

See [Service Discovery](/monitoring/monitoring-resources/discovery/service-discovery) for how to run it.

## Description

Monitors Dell EMC Data Domain systems through SNMP: alerts, hardware status, file system usage and cleaning, MTrees, replication, processes, interfaces and uptime.

The plugin pack provides these checks:

* [Alerts](#storage-emc-datadomain-snmp-alerts)
* [Cleaning](#storage-emc-datadomain-snmp-cleaning)
* [Filesystem usage](#storage-emc-datadomain-snmp-filesystems)
* [Hardware status](#storage-emc-datadomain-snmp-hardware)
* [Interfaces](#storage-emc-datadomain-snmp-interfaces)
* [MTrees](#storage-emc-datadomain-snmp-mtrees)
* [Process](#storage-emc-datadomain-snmp-process)
* [Replication status](#storage-emc-datadomain-snmp-replications)
* [Uptime](#os-linux-snmp-uptime)

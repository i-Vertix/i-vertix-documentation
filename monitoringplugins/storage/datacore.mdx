## Description

Monitors DataCore storage through its API: alerts by severity, storage pool usage and over-subscription, and the overall status of the monitored components.

The plugin pack provides these checks:

* [Alerts](#storage-datacore-restapi-alerts)
* [Pool usage](#storage-datacore-restapi-pool-usage)
* [Status monitor](#storage-datacore-restapi-status-monitor)

## Discovery

### Service Discovery

The service discovery creates one service per discovered object, with these rules:

| Service template | Service name |
|------------------|--------------|
| [Pool usage](#storage-datacore-restapi-pool-usage) | `Pool usage - <Id>` |

See [Service Discovery](/monitoring/monitoring-resources/discovery/service-discovery) for how to run it.

| `WARNING-STATE` | `'%{state} =~ /Warning/i'` | Define which output from the api should be considered warning: warning_default = '%\{state\} =~ /Warning/i'. possible value for state : Undefined, Healthy, Attention, Warning, Critical |
| `CRITICAL-STATE` | `'%{state} =~ /Critical/i'` | Define which output from the api should be considered critical: warning_default = '%\{state\} =~ /Critical/i'. possible value for state : Undefined, Healthy, Attention, Warning, Critical |
| `FILTER-CAPTION` |  | Define which element should be monitored based on the extended caption. This option will be treated as a regular expression. By default all elements will be checked |

</div>

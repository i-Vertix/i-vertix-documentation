## Description

Monitors Hitachi Content Platform (HCP): space usage of nodes, tenants and volumes, and the temperature, fan and voltage sensors of the nodes.

The plugin pack provides these checks:

* [Nodes](#storage-hitachi-hcp-snmp-nodes)
* [Tenants](#storage-hitachi-hcp-snmp-tenants)
* [Volumes](#storage-hitachi-hcp-snmp-volumes)

## Discovery

### Service Discovery

The service discovery creates one service per discovered object, with these rules:

| Service template | Service name |
|------------------|--------------|
| [Nodes](#storage-hitachi-hcp-snmp-nodes) | `Node - <name>` |
| [Tenants](#storage-hitachi-hcp-snmp-tenants) | `Tenant - <name>` |
| [Volumes](#storage-hitachi-hcp-snmp-volumes) | `Volume - <name>` |

See [Service Discovery](/monitoring/monitoring-resources/discovery/service-discovery) for how to run it.

## Description

Monitors Pure Storage FlashBlade through its REST API: alerts, hardware status, and the space usage, data reduction and read/write throughput of the array and its file systems.

The plugin pack provides these checks:

* [Alerts](#storage-purestorage-flashblade-v2-alerts)
* [Arrays](#storage-purestorage-flashblade-v2-arrays)
* [Filesystems](#storage-purestorage-flashblade-v2-filesystems)
* [Hardware](#storage-purestorage-flashblade-v2-hardware)

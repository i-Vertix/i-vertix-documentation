## Description

Monitors VMware vSAN clusters through the VMware connector: cluster usage with backend IOPS, throughput and latency, datacenter alarms, licenses, snapshots, VM tools and vMotion operations.

The plugin pack provides these checks:

* [VMware Connector statistics](#apps-vmware-connector-stat-connectors)
* [VMware Datacenter Alarm](#apps-vmware-connector-alarm-datacenter)
* [VMware License usage](#apps-vmware-connector-licenses)
* [VMware Snapshot usage size](#apps-vmware-connector-datastore-snapshot)
* [VMware VM Snapshot age](#apps-vmware-connector-snapshot-vm)
* [VMware VM Tools status](#apps-vmware-connector-tools-vm)
* [VMware vMotion Operations](#apps-vmware-connector-vmoperation-cluster)
* [VMware vSAN Cluster usage](#apps-vmware-connector-vsan-cluster-usage)

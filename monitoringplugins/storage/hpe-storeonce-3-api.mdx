## Description

Monitors HPE StoreOnce 3 appliances through its API: cluster usage and deduplication ratio, federated catalyst store usage, NAS usage and service set usage.

The plugin pack provides these checks:

* [Cluster usage](#storage-hp-storeonce-3-restapi-cluster-usage)
* [Federated catalyst store usage](#storage-hp-storeonce-3-restapi-fcs-usage)
* [NAS usage](#storage-hp-storeonce-3-restapi-nas-usage)
* [Service set usage](#storage-hp-storeonce-3-restapi-serviceset-usage)

## Description

Monitors HPE Nimble storage through its REST API: array space usage and snapshot compression, hardware status, and volume usage with read/write throughput, IOPS and latency.

The plugin pack provides these checks:

* [Arrays](#storage-nimble-restapi-arrays)
* [Hardware](#storage-nimble-restapi-hardware)
* [Volumes](#storage-nimble-restapi-volumes)

### Hardware {/* #storage-nimble-restapi-hardware */}

</summary>

#### Macros

<div className="plugin-pack-macros">

| Macro | Default value | Description |
|-------|---------------|-------------|
| `COMPONENT` | `.*` | Which component to check (Default: '.*'). Can be: 'disk', 'fan', 'psu', 'temperature' |
| `FILTER` |  | Exclude some parts (comma seperated list) (Example: --filter=psu) Can also exclude specific instance: --filter=fan,A\:fan1 |
| `WARNING` |  | Set warning threshold for 'fan', 'temperature' (syntax: section,[instance,]status,regexp) Example: --warning='temperature,.*,30' --warning='fan,.*,1000' |
| `CRITICAL` |  | Set critical threshold for 'fan', 'temperature' (syntax: section,[instance,]status,regexp) Example: --critical='temperature,.*,40' |
| `THRESHOLD-OVERLOAD` |  | Set to overload default threshold values (syntax: section,[instance,]status,regexp) It used before default thresholds (order stays). Example: --threshold-overload='sensor,WARNING,missing' |

</div>

</details>

## Description

Monitors HPE Primera storage through its API: capacity, space reduction ratios, disk status and usage, nodes, volume usage and license status.

The plugin pack provides these checks:

* [Capacity](#storage-hp-primera-restapi-capacity)
* [Disk status](#storage-hp-primera-restapi-disk-status)
* [Disk usage](#storage-hp-primera-restapi-disk-usage)
* [License status](#storage-hp-primera-restapi-licenses)
* [Nodes status](#storage-hp-primera-restapi-nodes)
* [Volume usage](#storage-hp-primera-restapi-volume-usage)

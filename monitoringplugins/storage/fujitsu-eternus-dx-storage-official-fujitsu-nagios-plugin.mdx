## Description

Monitors Fujitsu Eternus DX storage over SSH using the official Fujitsu Nagios plugin: system, controller and disk enclosure status, temperatures, power, disks, RAID groups, thin provisioning pools, volumes, ports and remote copy sessions.

The plugin pack provides these checks:

* [CE exhaust temperature](#3th-check_fujitsu-eternus-dx-chkcetemp)
* [CE intake temperature](#3th-check_fujitsu-eternus-dx-chkceintaketemp)
* [Channel Adapter ports](#3th-check_fujitsu-eternus-dx-chkcaport)
* [CM busy-rate](#3th-check_fujitsu-eternus-dx-chkcmbusyrate)
* [Controller Enclosure status](#3th-check_fujitsu-eternus-dx-chkce)
* [Controller Modules status](#3th-check_fujitsu-eternus-dx-chkcm)
* [Disk busy-rate](#3th-check_fujitsu-eternus-dx-chkdiskbusyrate)
* [Disk Enclosure status](#3th-check_fujitsu-eternus-dx-chkde)
* [Physical disks](#3th-check_fujitsu-eternus-dx-chkdisks)
* [Power](#3th-check_fujitsu-eternus-dx-chkpower)
* [Raid groups](#3th-check_fujitsu-eternus-dx-chkraids)
* [Remote Copy sessions](#3th-check_fujitsu-eternus-dx-chkrecsessions)
* [Spare disks](#3th-check_fujitsu-eternus-dx-chksparedisks)
* [System status](#3th-check_fujitsu-eternus-dx-chksystem)
* [Thin Provisioning pools](#3th-check_fujitsu-eternus-dx-chkthinpropools)
* [Volume Read response time](#3th-check_fujitsu-eternus-dx-chkvolreadrestime)
* [Volume Write response time](#3th-check_fujitsu-eternus-dx-chkvolwriterestime)
* [Volumes](#3th-check_fujitsu-eternus-dx-chkvolumes)

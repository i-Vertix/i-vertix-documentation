## Description

Monitors IBM Storwize storage over SSH: component status, event log problems, storage pool usage, replication and virtual disk status.

The plugin pack provides these checks:

* [Components](#storage-ibm-storwize-ssh-components)
* [Eventlog](#storage-ibm-storwize-ssh-eventlog)
* [Pool usage](#storage-ibm-storwize-ssh-pool-usage)
* [Replication](#storage-ibm-storwize-ssh-replication)
* [Virtual Disk status](#storage-ibm-storwize-ssh-vdisk-status)

| `SSHCLI-OPTION` | `-o=StrictHostKeyChecking=no` | Specify SSH CLI options (example: --sshcli-option='-o=StrictHostKeyChecking=no -o=LogLevel=ERROR'). The default parameter is --sshcli-option='-o=LogLevel=ERROR' which hides the SSH banner. If you override this parameter, make sure to append '-o=LogLevel=ERROR' to your new value to maintain this behavior. | `SSH-PRIV-KEY` |  | Define the private key file to use for user authentication. |

<div className="plugin-pack-macros">

| Macro | Default value | Description |
|-------|---------------|-------------|
| `COMPONENTS` | `^((?!vdisk).)*$` | Which component to check (Default: '.*'). Can be: 'array', 'drive', 'enclosure', 'enclosurebattery', 'enclosurecanister', 'enclosurepsu', 'host', 'portfc', 'portsas', 'vdisk', 'node', 'quorum', 'mdisk', 'systemstats' |
| `FILTER` |  | Exclude some parts (comma seperated list) (Example: --filter=host --filter=enclosurecanister) Can also exclude specific instance: --filter=host,10 |
| `WARNING` |  | Set warning threshold for temperatures (syntax: type,regexp,threshold) Example: --warning='systemstats,cpu_pc,30' |
| `CRITICAL` |  | Set critical threshold for temperatures (syntax: type,regexp,threshold) Example: --critical='systemstats,cpu_pc,40' |
| `THRESHOLD-OVERLOAD` |  | Set to overload default threshold values (syntax: section,[instance,]status,regexp) It used before default thresholds (order stays). Example: --threshold-overload='host,.*,OK,degraded' |

</div>

</details>

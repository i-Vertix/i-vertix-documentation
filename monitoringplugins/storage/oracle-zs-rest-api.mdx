## Description

Monitors Oracle ZFS Storage Appliances through the REST API: hardware status and storage pool usage.

The plugin pack provides these checks:

* [Hardware](#storage-oracle-zs-restapi-hardware)
* [Pools](#storage-oracle-zs-restapi-pools)

#### Macros

<div className="plugin-pack-macros">

| Macro | Default value | Description |
|-------|---------------|-------------|
| `COMPONENT` |  | Which component to check (Default: '.*'). Can be: 'chassis', 'cpu', 'disk', 'fan', 'memory', 'psu', 'slot' |
| `FILTER` |  | Exclude some parts (comma seperated list) Can also exclude specific instance: --filter='disk,hdd 0' |
| `THRESHOLD-OVERLOAD` |  | Set to overload default threshold values (syntax: section,[instance,]status,regexp) It used before default thresholds (order stays). Example: --threshold-overload='disk,WARNING,faulted' |
| `NO-COMPONENT` |  | Define the expected status if no components are found (default: critical) |

</div>

</details>

#### Macros

<div className="plugin-pack-macros">

| Macro | Default value | Description |
|-------|---------------|-------------|
| `WARNING-USAGE-PRCT` | `90` | Threshold warning usage (%) |
| `CRITICAL-STATUS` | `'%{status} !~ /online\|exported/i'` | Define the conditions to match for the status to be CRITICAL (Default: '%\{status\} !~ /online\|exported/i'). You can use the following variables: %\{status\}, %\{display\} |
| `CRITICAL-USAGE-PRCT` | `95` | Threshold critical usage (%) |
| `FILTER-COUNTERS` |  | Only display some counters (regexp can be used). Example: --filter-counters='^usage$' |
| `FILTER-NAME` |  | Filter pool name (can be a regexp) |
| `UNKNOWN-STATUS` |  | Set unknon threshold for status (Default: ''). Can used special variables like: %\{status\}, %\{display\} |
| `WARNING-STATUS` |  | Set warning threshold for status (Default: ''). Can used special variables like: %\{status\}, %\{display\} |
| `WARNING-USAGE` |  | Threshold warning usage (B) |
| `WARNING-USAGE-FREE` |  | Threshold warning usage free (B) |
| `CRITICAL-USAGE` |  | Threshold critical usage (B) |
| `CRITICAL-USAGE-FREE` |  | Threshold critical usage free (B) |
| `EXTRA-OPTS` |  | Additional options appended to the plugin command line (host level). |

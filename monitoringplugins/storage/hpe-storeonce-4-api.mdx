## Description

Monitors HPE StoreOnce 4 appliances through its API: appliances and their disk usage and deduplication ratio, hardware storage and stores.

The plugin pack provides these checks:

* [Appliances](#storage-hp-storeonce-4-restapi-appliances)
* [Hardware storage](#storage-hp-storeonce-4-restapi-hardware-storage)
* [Stores](#storage-hp-storeonce-4-restapi-stores)

## Discovery

### Hardware storage {/* #storage-hp-storeonce-4-restapi-hardware-storage */}

</summary>

#### Macros

<div className="plugin-pack-macros">

| Macro | Default value | Description |
|-------|---------------|-------------|
| `COMPONENT` | `.*` | Which component to check. Can be: 'drive', 'driveencl', 'fan', 'iomodule', 'pool', 'psu', 'temperature' |
| `FILTER` |  | Exclude some parts (comma seperated list) (Example: --filter=psu) Can also exclude specific instance: --filter=fan,fan slot 1 |
| `THRESHOLD-OVERLOAD` |  | Set to overload default threshold values (syntax: section,status,regexp) It used before default thresholds (order stays). Example: --threshold-overload='fan,WARNING,missing' |
| `WARNING` |  | Set warning threshold for 'fan.speed' (syntax: section,[instance,]status,regexp) Example: --warning='fan.speed,.*,10000' |
| `CRITICAL` |  | Set critical threshold for 'fan.speed' (syntax: section,[instance,]status,regexp) Example: --critical='fan.speed,.*,11000' |
| `NO-COMPONENT` |  | Define the expected status if no components are found (default: critical) |

</div>

</details>

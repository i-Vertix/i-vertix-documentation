## Description

Monitors Dell Compellent storage arrays through SNMP: global and hardware status, interfaces, NTP time offset and uptime.

The plugin pack provides these checks:

* [Global status](#storage-dell-compellent-snmp-global-status)
* [Hardware status](#storage-dell-compellent-snmp-hardware)
* [Interfaces](#storage-dell-compellent-snmp-interfaces)
* [NTP](#storage-dell-compellent-snmp-time)
* [Uptime](#storage-dell-compellent-snmp-uptime)

### Hardware status {/* #storage-dell-compellent-snmp-hardware */}

</summary>

#### Macros

<div className="plugin-pack-macros">

| Macro | Default value | Description |
|-------|---------------|-------------|
| `COMPONENT` |  | Which component to check (Default: '.*'). Can be: 'ctrl', 'disk', 'encl', 'ctrlfan', 'ctrlpower', 'ctrlvoltage', 'ctrltemp', 'enclfan', 'enclpower', 'encliomod', 'encltemp', 'volume', 'cache', 'server', 'sc' |
| `FILTER` |  | Exclude some parts (comma seperated list) (Example: --filter=ctrlfan --filter=enclpower) Can also exclude specific instance: --filter=ctrlfan,1 |
| `WARNING` |  | Set warning threshold for 'ctrltemp', 'ctrlfan', 'ctrlvoltage', 'encltemp' (syntax: type,regexp,threshold) Example: --warning='ctrltemp,1,30' |
| `CRITICAL` |  | Set critical threshold for 'ctrltemp', 'ctrlfan', 'ctrlvoltage', 'encltemp' (syntax: type,regexp,threshold) Example: --critical='ctrltemp,1,50' |
| `THRESHOLD-OVERLOAD` |  | Set to overload default threshold values (syntax: section,[instance,]status,regexp) It used before default thresholds (order stays). Example: --threshold-overload='ctrl,CRITICAL,^(?!(up)$)' |

</div>

</details>

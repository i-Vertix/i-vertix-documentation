## Description

Monitors Lenovo Iomega ix2 NAS devices through SNMP: CPU, memory, storage, hardware status, interfaces and uptime.

The plugin pack provides these checks:

* [CPU](#storage-lenovo-iomega-snmp-cpu)
* [Hardware](#storage-lenovo-iomega-snmp-hardware)
* [Interfaces](#storage-lenovo-iomega-snmp-interfaces)
* [Memory](#storage-lenovo-iomega-snmp-memory)
* [Storage](#storage-lenovo-iomega-snmp-storage)
* [Uptime](#os-linux-snmp-uptime)

#### Macros

<div className="plugin-pack-macros">

| Macro | Default value | Description |
|-------|---------------|-------------|
| `COMPONENT` | `.*` | Which component to check (Default: '.*'). Can be: 'raid', 'disk', 'voltage', 'temperature', 'fan' |
| `FILTER` |  | Exclude some parts (comma seperated list) (Example: --filter=fan) Can also exclude specific instance: --filter=fan,1 |
| `THRESHOLD-OVERLOAD` |  | Set to overload default threshold values (syntax: section,[instance,]status,regexp) It used before default thresholds (order stays). Example: --threshold-overload='disk,WARNING,missing' |
| `WARNING` |  | Set warning threshold for 'temperature', 'voltage', 'fan' (syntax: type,regexp,threshold) Example: --warning='temperature,.*,40' |
| `CRITICAL` |  | Set critical threshold for 'temperature', 'voltage', 'fan' (syntax: type,regexp,threshold) Example: --critical='temperature,.*,50' |

</div>

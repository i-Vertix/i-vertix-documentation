## Description

Monitors HPE 3PAR storage over SSH: capacity, disk and volume usage, nodes, cages, power supplies, adaptive flash cache, hardware status, NTP time and uptime.

The plugin pack provides these checks:

* [Adaptive flash cache](#storage-hp-3par-ssh-afc)
* [Cages](#storage-hp-3par-ssh-cages)
* [Capacity](#storage-hp-3par-ssh-capacity)
* [Disk usage](#storage-hp-3par-ssh-disk-usage)
* [Hardware status](#storage-hp-3par-ssh-components)
* [Nodes](#storage-hp-3par-ssh-nodes)
* [NTP time](#storage-hp-3par-ssh-time)
* [PSU](#storage-hp-3par-ssh-psu)
* [Uptime](#storage-hp-3par-ssh-uptime)
* [Volume usage](#storage-hp-3par-ssh-volume-usage)

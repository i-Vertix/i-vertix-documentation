## Description

Monitors Dell MD3000 storage arrays and reports their health status.

The plugin pack provides these checks:

* [Health Status](#storage-dell-md3000-cli-health-status)


## Host Templates

### Dell-MD3000

*Dell MD3000* · Parent template: `generic-host`

<details className="plugin-pack-details">

<div className="plugin-pack-macros">

| Macro | Default value | Description |
|-------|---------------|-------------|

## Changelog

Changes of the plugin pack per release, compared with the previous release.

<details className="plugin-pack-details" open>
<summary>20240808 - 20240912</summary>

- Service template [`storage-dell-md3000-cli-health-status`](#storage-dell-md3000-cli-health-status)
    - Macro `STORAGE-COMMAND`: default changed from `'show storageArray healthstatus;'` to `show storageArray healthstatus;`
- Command `storage-dell-md3000-cli-health-status`
    - Option `--hostname` changed from `--hostname=$_HOSTHOSTNAME$` to `--hostname=$HOSTADDRESS$`
    - Option `--password` changed from `--password=$_HOSTPASSWORD$` to `--password='$_HOSTPASSWORD$'`
    - Option `--storage-command` changed from `--storage-command=$_SERVICESTORAGE-COMMAND$` to `--storage-command='$_SERVICESTORAGE-COMMAND$'`
    - Option `--extra-option=$_HOSTEXTRA-OPTION$` removed
    - Macro `HOSTNAME` removed

</details>

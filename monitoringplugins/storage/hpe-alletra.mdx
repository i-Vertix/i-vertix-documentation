## Description

Monitors HPE Alletra storage through its API: capacity and provisioning, disk status and usage, volume status and usage, and license status.

The plugin pack provides these checks:

* [Capacity](#storage-hp-alletra-restapi-capacity)
* [Disk status](#storage-hp-alletra-restapi-disk-status)
* [Disk usage](#storage-hp-alletra-restapi-disk-usage)
* [License status](#storage-hp-alletra-restapi-licenses)
* [Volume status](#storage-hp-alletra-restapi-volume-status)
* [Volume usage](#storage-hp-alletra-restapi-volume-usage)

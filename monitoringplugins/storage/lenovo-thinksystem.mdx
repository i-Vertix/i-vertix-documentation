## Description

Monitors Lenovo ThinkSystem storage through its API: hardware status, storage controllers, systems, pools and volumes, including space usage, IOPS and throughput.

The plugin pack provides these checks:

* [Hardware status](#storage-netapp-santricity-restapi-hardware)
* [Storage controller status](#storage-netapp-santricity-restapi-storage-controllers)
* [Storage pools](#storage-netapp-santricity-restapi-storage-pools)
* [Storage systems](#storage-netapp-santricity-restapi-storage-systems)
* [Storage volumes](#storage-netapp-santricity-restapi-storage-volumes)

#### Macros

<div className="plugin-pack-macros">

| Macro | Default value | Description |
|-------|---------------|-------------|
| `COMPONENT` |  | Which component to check (Default: '.*'). Can be: 'storage', 'ctrl', 'battery', 'board', 'cbd', 'cmd', 'drive', 'psu', 'fan', 'thsensor' |
| `FILTER` |  | Exclude some parts (comma seperated list) Can also exclude specific instance: --filter='drive,010000005000C500C244251B0000000000000000' |
| `WARNING` |  | Set warning threshold for 'temperature' (syntax: type,regexp,threshold) Example: --warning='drive.temperature,.*,40' |
| `CRITICAL` |  | Set critical threshold for 'drive.temperature' (syntax: type,regexp,threshold) Example: --critical='drive.temperature,.*,50' |
| `THRESHOLD-OVERLOAD` |  | Set to overload default threshold values (syntax: section,[instance,]status,regexp) It used before default thresholds (order stays). Example: --threshold-overload='drive,OK,preFailCopy' |

</div>

</details>

## Description

Monitors Dell ME4 storage through its API: hardware status, interfaces, and controller and volume statistics such as throughput, IOPS, cache and CPU usage.

The plugin pack provides these checks:

* [Controller statistics](#storage-dell-me4-restapi-controller-statistics)
* [Hardware](#storage-dell-me4-restapi-hardware)
* [Interfaces](#storage-dell-me4-restapi-interfaces)
* [Volume statistics](#storage-dell-me4-restapi-volume-statistics)

## Discovery

### Service Discovery

The service discovery creates one service per discovered object, with these rules:

| Service template | Service name |
|------------------|--------------|
| [Controller statistics](#storage-dell-me4-restapi-controller-statistics) | `Controller statistics - <name>` |
| [Volume statistics](#storage-dell-me4-restapi-volume-statistics) | `Volume statistics - <name>` |

See [Service Discovery](/monitoring/monitoring-resources/discovery/service-discovery) for how to run it.

| Macro | Default value | Description |

| `COMPONENT` | `.*` | Which component to check (Default: '.*'). Can be: 'controller', 'disk', 'fan', 'fru', 'psu', 'sensor', 'volume' |
| `FILTER` |  | Exclude some parts (comma seperated list) Can also exclude specific instance: --filter='sensor,Overall Sensor' |
| `WARNING` |  | Set warning threshold for 'temperature' (syntax: type,regexp,threshold) Example: --warning='temperature,.*,40' |
| `CRITICAL` |  | Set critical threshold for 'temperature' (syntax: type,regexp,threshold) Example: --critical='temperature,.*,50' |
| `THRESHOLD-OVERLOAD` |  | Set to overload default threshold values (syntax: section,[instance,]status,regexp) It used before default thresholds (order stays). Example: --threshold-overload='controller,OK,Operational but not redundant' |
| `NO-COMPONENT` |  | Define the expected status if no components are found (default: critical) |

</div>

## Description

Monitors NetApp ONTAP through its REST API: cluster and hardware status, aggregates, volumes, LUNs, quotas and SnapMirror relationships, including space usage, I/O and latency.

The plugin pack provides these checks:

* [Aggregates](#storage-netapp-ontap-restapi-aggregates)
* [Cluster status](#storage-netapp-ontap-restapi-cluster)
* [Hardware status](#storage-netapp-ontap-restapi-hardware)
* [LUNs](#storage-netapp-ontap-restapi-luns)
* [Quotas](#storage-netapp-ontap-restapi-quotas)
* [Snapmirrors](#storage-netapp-ontap-restapi-snapmirrors)
* [Volumes](#storage-netapp-ontap-restapi-volumes)

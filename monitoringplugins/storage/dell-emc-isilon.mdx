## Description

Monitors Dell EMC Isilon clusters through SNMP: cluster usage, hardware status and uptime.

The plugin pack provides these checks:

* [Cluster usage](#storage-emc-isilon-snmp-cluster-usage)
* [Hardware status](#storage-emc-isilon-snmp-hardware)
* [Uptime](#os-linux-snmp-uptime)

*Dell EMC Isilon* · Parent template: `generic-host`

<div className="plugin-pack-macros">

| Macro | Default value | Description |

| `SNMPVERSION` |  | SNMP version |

| `SNMPUSERNAME` |  | SNMP v3 only: User name (`securityName`). |
| `SNMPAUTH-PASSPHRASE` |  | SNMP v3 only: Pass phrase hashed using the authentication protocol defined in the --authprotocol option. |
| `SNMPAUTH-PROTOCOL` |  | SNMP v3 only: Authentication protocol: MD5\|SHA. Since net-snmp 5.9.1: SHA224\|SHA256\|SHA384\|SHA512. |

### Hardware status {/* #storage-emc-isilon-snmp-hardware */}

</summary>

#### Macros

<div className="plugin-pack-macros">

| Macro | Default value | Description |
|-------|---------------|-------------|
| `CRITICAL` | `power,.*,180:240` | Set critical threshold (syntax: type,instance,threshold) Example: --critical='temperature,1.1,25' --critical='battery,.*,20:' |
| `COMPONENT` |  | Which component to check (Default: '.*'). Can be: 'fan', 'disk', 'temperature', 'power' |
| `FILTER` |  | Exclude some parts (comma seperated list) (Example: --filter=fan --filter=power) Can also exclude specific instance: --filter=power,3.3 |
| `WARNING` |  | Set warning threshold (syntax: type,instance,threshold) Example: --warning='temperature,.*,20' |
| `THRESHOLD-OVERLOAD` |  | Set to overload default threshold values (syntax: section,[instance,]status,regexp) It used before default thresholds (order stays). Example: --threshold-overload='fan,CRITICAL,^(?!(ok)$)' |
| `NO-COMPONENT` |  | Define the expected status if no components are found (default: critical) |

</div>

</details>

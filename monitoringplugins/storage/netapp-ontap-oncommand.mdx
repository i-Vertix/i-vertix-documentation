## Description

Monitors NetApp ONTAP through the OnCommand API: cluster status, usage and I/O, aggregates, volumes, LUNs, qtrees, SnapMirror, disks, FC ports and node hardware and failover.

The plugin pack provides these checks:

* [Aggregate raid status](#storage-netapp-ontap-oncommandapi-aggregate-raid-status)
* [Aggregate status](#storage-netapp-ontap-oncommandapi-aggregate-status)
* [Aggregate usage](#storage-netapp-ontap-oncommandapi-aggregate-usage)
* [Cluster I/O](#storage-netapp-ontap-oncommandapi-cluster-io)
* [Cluster status](#storage-netapp-ontap-oncommandapi-cluster-status)
* [Cluster usage](#storage-netapp-ontap-oncommandapi-cluster-usage)
* [Disk failed](#storage-netapp-ontap-oncommandapi-disk-failed)
* [Disk spare](#storage-netapp-ontap-oncommandapi-disk-spare)
* [FC port status](#storage-netapp-ontap-oncommandapi-fc-port-status)
* [LUN alignment](#storage-netapp-ontap-oncommandapi-lun-alignment)
* [LUN online](#storage-netapp-ontap-oncommandapi-lun-online)
* [LUN usage](#storage-netapp-ontap-oncommandapi-lun-usage)
* [Node failover status](#storage-netapp-ontap-oncommandapi-node-failover-status)
* [Node hardware status](#storage-netapp-ontap-oncommandapi-node-hardware-status)
* [Qtree status](#storage-netapp-ontap-oncommandapi-qtree-status)
* [Snapmirror status](#storage-netapp-ontap-oncommandapi-snapmirror-status)

## Description

Monitors Quantum DXI appliances over SSH: system and health status, storage array, HBA and network status, disk usage, memory, deduplication and compaction, reclamation and throughput.

The plugin pack provides these checks:

* [Compaction](#storage-quantum-dxi-ssh-compaction)
* [Deduplication NAS](#storage-quantum-dxi-ssh-dedupnas)
* [Deduplication VTL](#storage-quantum-dxi-ssh-dedupvtl)
* [Disk usage](#storage-quantum-dxi-ssh-disk-usage)
* [HBA status](#storage-quantum-dxi-ssh-hostbus-adapter-status)
* [Health status](#storage-quantum-dxi-ssh-health)
* [Memory](#storage-quantum-dxi-ssh-memory)
* [Network status](#storage-quantum-dxi-ssh-network)
* [Reclamation](#storage-quantum-dxi-ssh-reclamation)
* [Reduction](#storage-quantum-dxi-ssh-reduction)
* [Storage Array status](#storage-quantum-dxi-ssh-storage-array-status)
* [System status](#storage-quantum-dxi-ssh-system-status)
* [Throughput](#storage-quantum-dxi-ssh-throughput)

### Quantum-DXI-Series

*Quantum DXI Series* · Parent template: `generic-host`

<details className="plugin-pack-details">
<summary>Macros (5)</summary>

<div className="plugin-pack-macros">

| Macro | Default value | Description |
|-------|---------------|-------------|
| `SSH-BACKEND` | `sshcli` | Define the backend you want to use. It can be: `sshcli` (default for most plugins), `plink` and `libssh`. |
| `SSH-PASSWORD` | *(password)* | Define the password associated with the user name. Cannot be used with the `sshcli` backend. Warning: using a password is not recommended. Use `--ssh-priv-key` instead. |
| `SSH-USERNAME` |  | Define the user name to log in to the host. |
| `SSH-PRIV-KEY` |  | Define the private key file to use for user authentication. |
| `SSHCLI-OPTION` |  | Specify SSH CLI options (example: --sshcli-option='-o=StrictHostKeyChecking=no -o=LogLevel=ERROR'). The default parameter is --sshcli-option='-o=LogLevel=ERROR' which hides the SSH banner. If you override this parameter, make sure to append '-o=LogLevel=ERROR' to your new value to maintain this behavior. This parameter can be used multiple times and multiple options can be specified in the same parameter. |

</div>

Macros without a default value are only defined in the check commands. Set them on the host where needed.

</details>

## Description

Monitors Netgear ReadyNAS devices through SNMP: CPU, load, memory, storage, hardware status, interfaces and uptime.

The plugin pack provides these checks:

* [CPU](#storage-netgear-readynas-snmp-cpu)
* [Hardware status](#storage-netgear-readynas-snmp-hardware)
* [Interfaces](#storage-netgear-readynas-snmp-interfaces)
* [Load](#storage-netgear-readynas-snmp-load)
* [Memory](#storage-netgear-readynas-snmp-memory)
* [Storage](#storage-netgear-readynas-snmp-storage)
* [Uptime](#os-linux-snmp-uptime)

</summary>

#### Macros

<div className="plugin-pack-macros">

| Macro | Default value | Description |
|-------|---------------|-------------|
| `COMPONENT` | `.*` | Which component to check (Default: '.*'). Can be: 'psu', 'fan', 'disk', 'volume', 'temperature' |
| `FILTER` |  | Exclude some parts (comma seperated list) (Example: --filter=psu) Can also exclude specific instance: --filter=psu,1 |
| `WARNING` |  | Set warning threshold for temperatures, fan (syntax: type,instance,threshold) Example: --warning='xxxxx,.*,30' |
| `CRITICAL` |  | Set critical threshold for temperatures, fan (syntax: type,instance,threshold) Example: --critical='xxxxx,.*,40' |
| `THRESHOLD_OVERLOAD` |  | Set to overload default threshold values (syntax: section,[instance,]status,regexp) It used before default thresholds (order stays). Example: --threshold-overload='psu,CRITICAL,^(?!(on)$)' |

</div>

</details>

## Description

Monitors Dell PowerStore through its REST API: alerts, clusters, hardware status and storage usage.

The plugin pack provides these checks:

* [Alerts](#storage-dell-powerstore-restapi-alerts)
* [Clusters](#storage-dell-powerstore-restapi-clusters)
* [Hardware status](#storage-dell-powerstore-restapi-hardware)
* [Storage](#storage-dell-powerstore-restapi-memory)

| Macro | Default value | Description |
|-------|---------------|-------------|

| `FILTER` |  | Exclude some parts (comma seperated list) Can also exclude specific instance: --filter='disk,26018c5b69264a868e49119eec95b0a9' |
| `THRESHOLD-OVERLOAD` |  | Set to overload default threshold values (syntax: section,[instance,]status,regexp) It used before default thresholds (order stays). Example: --threshold-overload='disk,CRITICAL,Uninitialized' |
| `ABSENT-PROBLEM` |  | Return an error if a component is not 'present' (default is skipping). It can be set globally or for a specific instance: --absent-problem='component_name' or --absent-problem='component_name,instance_value' |
| `NO-COMPONENT` |  | Define the expected status if no components are found (default: critical) |

</div>

</details>

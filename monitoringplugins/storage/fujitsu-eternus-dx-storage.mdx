## Description

Monitors Fujitsu Eternus DX storage over SSH: CPU, physical disks, power supplies, RAID groups, and port and volume statistics such as IOPS, throughput, response time and cache hits.

The plugin pack provides these checks:

* [CPU](#storage-fujitsu-eternus-dx-ssh-cpu)
* [Physical disks](#storage-fujitsu-eternus-dx-ssh-physicaldisk)
* [Port stats](#storage-fujitsu-eternus-dx-ssh-port-stats)
* [PSU](#storage-fujitsu-eternus-dx-ssh-psu)
* [Raid Groups](#storage-fujitsu-eternus-dx-ssh-raid-groups)
* [Volume stats](#storage-fujitsu-eternus-dx-ssh-volume-stats)

| Macro | Default value | Description |
|-------|---------------|-------------|
| `SSH-PORT` | `22` | Define the TCP port on which SSH is listening. |
| `SSH-BACKEND` | `sshcli` | Define the backend you want to use. It can be: `sshcli` (default for most plugins), `plink` and `libssh`. |
| `SSH-PASSWORD` |  | Define the password associated with the user name. Cannot be used with the `sshcli` backend. Warning: using a password is not recommended. Use `--ssh-priv-key` instead. |
| `SSH-PRIV-KEY` |  | Define the private key file to use for user authentication. |
| `SSH-USERNAME` |  | Define the user name to log in to the host. |
| `SSHCLI-OPTION` |  | Specify SSH CLI options (example: --sshcli-option='-o=StrictHostKeyChecking=no -o=LogLevel=ERROR'). The default parameter is --sshcli-option='-o=LogLevel=ERROR' which hides the SSH banner. If you override this parameter, make sure to append '-o=LogLevel=ERROR' to your new value to maintain this behavior. This parameter can be used multiple times and multiple options can be specified in the same parameter. |

</div>

Macros without a default value are only defined in the check commands. Set them on the host where needed.

</details>

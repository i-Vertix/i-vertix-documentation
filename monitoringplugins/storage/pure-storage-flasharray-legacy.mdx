## Description

Monitors Pure Storage FlashArray (legacy) through its API: alarms, array and volume usage and data reduction, hardware status and protection group replication.

The plugin pack provides these checks:

* [Alarms](#storage-purestorage-flasharray-legacy-restapi-alarms)
* [Arrays](#storage-purestorage-flasharray-legacy-restapi-arrays)
* [Hardware](#storage-purestorage-flasharray-legacy-restapi-hardware)
* [Protection Group replication](#storage-purestorage-flasharray-legacy-restapi-pgroup-replication)
* [Volume usage](#storage-purestorage-flasharray-legacy-restapi-volume-usage)

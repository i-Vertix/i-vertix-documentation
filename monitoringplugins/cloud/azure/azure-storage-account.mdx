## Description

### Azure Storage Account monitoring
protocols used: Rest API (https)

- Account used capacity
- Blob capacity
- Blob container count
- Blob count
- File capacity
- File count
- File share count
- File share quota
- Health
- Queue capacity
- Queue count
- Queue message count
- Table capacity
- Table count
- Table entity count
- Transactions availability
- Transactions count
- Transactions latency
- Transactions throughput

### Discovery modes

- File shares

## Prerequisites

The plugin pack retrieves the metrics through the Azure Rest API. Before you can monitor the resources, you need an
Azure application with the **Monitoring Reader** role and its credentials (*Subscription ID*, *Tenant ID*, *Client ID* and *Client Secret*).

See [Azure Prerequisites](/monitoringplugins/cloud/azure/azure-prerequisites) for a step-by-step guide.

## Description

Monitors Azure virtual machines and groups of virtual machines through Azure Monitor: health and power state, CPU, memory, disk I/O, network traffic and the VM size.

The plugin pack provides these checks:

* [CPU usage](#cloud-azure-compute-virtualmachine-cpu)
* [Disk IO](#cloud-azure-compute-virtualmachine-diskio)
* [Health status](#cloud-azure-compute-virtualmachine-health)
* [Memory usage](#cloud-azure-compute-virtualmachine-memory)
* [Network usage](#cloud-azure-compute-virtualmachine-network)
* [VM Size](#cloud-azure-compute-virtualmachine-vm-sizes)

## Prerequisites

The plugin pack retrieves the metrics through the Azure Rest API. Before you can monitor the resources, you need an
Azure application with the **Monitoring Reader** role and its credentials (*Subscription ID*, *Tenant ID*, *Client ID* and *Client Secret*).

See [Azure Prerequisites](/monitoringplugins/cloud/azure/azure-prerequisites) for a step-by-step guide.

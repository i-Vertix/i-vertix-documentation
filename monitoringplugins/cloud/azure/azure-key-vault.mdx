## Description

### Azure-Key-Vault monitoring

protocols used: HTTPS (Rest API)

* Service API latency
* Service API requests
* Vault availability
* Vault capacity

## Prerequisites

The plugin pack retrieves the metrics through the Azure Rest API. Before you can monitor the resources, you need an
Azure application with the **Monitoring Reader** role and its credentials (*Subscription ID*, *Tenant ID*, *Client ID* and *Client Secret*).

See [Azure Prerequisites](/monitoringplugins/cloud/azure/azure-prerequisites) for a step-by-step guide.

#### Macros

<div className="plugin-pack-macros">

| Macro | Default value | Description |
|-------|---------------|-------------|
| `AGGREGATION` | `average` | Aggregation of the Azure metric values. Can be 'minimum', 'maximum', 'average', 'total' or 'count'. |

| `EXTRAOPTS` |  | Additional plugin options for this service. |
| `WARNING-SERVICEAPI-HITS` |  | Warning threshold for the number of service API requests to the vault. |
| `WARNING-SERVICEAPI-LATENCY` |  | Warning threshold for the latency of the service API requests in milliseconds. |
| `WARNING-SERVICEAPI-RESULTS` |  | Warning threshold for the number of service API results of the vault. |
| `CRITICAL-SERVICEAPI-HITS` |  | Critical threshold for the number of service API requests to the vault. |
| `CRITICAL-SERVICEAPI-LATENCY` |  | Critical threshold for the latency of the service API requests in milliseconds. |

## Description

Monitors Azure Firewall and Web Application Firewall instances: resource health, application and network rule hits, data processed and throughput.

The plugin pack provides these checks:

* [Health](#cloud-azure-network-firewall-health)
* [Hits](#cloud-azure-network-firewall-hits)
* [Throughput](#cloud-azure-network-firewall-throughput)

## Prerequisites

The plugin pack retrieves the metrics through the Azure Rest API. Before you can monitor the resources, you need an
Azure application with the **Monitoring Reader** role and its credentials (*Subscription ID*, *Tenant ID*, *Client ID* and *Client Secret*).

See [Azure Prerequisites](/monitoringplugins/cloud/azure/azure-prerequisites) for a step-by-step guide.

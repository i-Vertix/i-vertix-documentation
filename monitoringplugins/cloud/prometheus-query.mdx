## Description

Monitors Prometheus servers through the Prometheus API: scrape target status and the results of custom PromQL queries.

The plugin pack provides these checks:

* [Custom query](#cloud-prometheus-restapi-expression)
* [Target status](#cloud-prometheus-restapi-target-status)

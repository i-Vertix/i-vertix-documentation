## Description

Monitors Google Compute Engine instances through the Google API: CPU, disk I/O and network usage.

The plugin pack provides these checks:

* [CPU](#cloud-google-gcp-compute-computeengine-cpu)
* [Disk IO](#cloud-google-gcp-compute-computeengine-diskio)
* [Network](#cloud-google-gcp-compute-computeengine-network)


## Host Templates

| `KEY-FILE` |  | Set GCP key file path. |
| `DIMENSION-NAME` |  | Set dimension name (default: 'metric.labels.instance_name'). |
| `DIMENSION-OPERATOR` |  | Set dimension operator (default: 'equals'. Can also be: 'regexp', 'starts'). |
| `DIMENSION-VALUE` |  | Set dimension value (required). |

</div>

Macros without a default value are only defined in the check commands. Set them on the host where needed.

#### Macros

| `AGGREGATION` | `average` | Set monitor aggregation (Can be multiple, Can be: 'minimum', 'maximum', 'average', 'total') |

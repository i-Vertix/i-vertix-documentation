## Description

Monitors Nutanix Prism clusters through SNMP: usage and I/O latency of clusters, storage containers, storage pools, disks and hypervisors, VM counts and uptime.

The plugin pack provides these checks:

* [Cluster usage](#cloud-nutanix-cluster-usage)
* [Container usage](#cloud-nutanix-container-usage)
* [Disk usage](#cloud-nutanix-disk-usage)
* [Hypervisor usage](#cloud-nutanix-hypervisor-usage)
* [Storage Pool usage](#cloud-nutanix-storage-pool-usage)
* [Uptime](#os-linux-snmp-uptime)
* [VM usage](#cloud-nutanix-vm-usage)

## Discovery

### Service Discovery

The service discovery creates one service per discovered object, with these rules:

| Service template | Service name |
|------------------|--------------|
| [Container usage](#cloud-nutanix-container-usage) | `Container usage - <name>` |
| [Disk usage](#cloud-nutanix-disk-usage) | `Disk usage - <disk_id>` |
| [Hypervisor usage](#cloud-nutanix-hypervisor-usage) | `Hypervisor usage - <name>` |
| [Storage Pool usage](#cloud-nutanix-storage-pool-usage) | `Storage Pool usage - <name>` |
| [VM usage](#cloud-nutanix-vm-usage) | `VM usage - <name>` |

See [Service Discovery](/monitoring/monitoring-resources/discovery/service-discovery) for how to run it.

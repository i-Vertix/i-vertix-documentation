## Description

Monitors AWS Classic Load Balancers through Amazon CloudWatch: HTTP response codes, latency, request counts, surge queue and spillover, and the health of the registered instances.

The plugin pack provides these checks:

* [HTTP codes](#cloud-aws-elb-classic-loadbalancer-http-codes)
* [Performances Latency](#cloud-aws-elb-classic-loadbalancer-performances-latency)
* [Performances requests count](#cloud-aws-elb-classic-loadbalancer-performances-requests)
* [Queues SpilloverCount](#cloud-aws-elb-classic-loadbalancer-queues-spillovercount)
* [Queues SurgeQueueLength](#cloud-aws-elb-classic-loadbalancer-queues-surgequeuelenght)
* [Targets Health](#cloud-aws-elb-classic-loadbalancer-targets-health)

## Prerequisites

The plugin pack retrieves the metrics through the AWS API (Amazon CloudWatch). Before you can monitor the resources, you need an
AWS user with the required read permissions and its credentials (*Access Key ID* and *Secret Access Key*), and the *region* of the resources.

See [AWS Prerequisites](/monitoringplugins/cloud/aws/aws-prerequisites) for a step-by-step guide and the required permissions.

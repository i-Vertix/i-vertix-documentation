## Description

### AWS SES (Simple Email Service) monitoring
Protocols used: Rest API

- Emails

## Prerequisites

The plugin pack retrieves the metrics through the AWS API (Amazon CloudWatch). Before you can monitor the resources, you need an
AWS user with the required read permissions and its credentials (*Access Key ID* and *Secret Access Key*), and the *region* of the resources.

See [AWS Prerequisites](/monitoringplugins/cloud/aws/aws-prerequisites) for a step-by-step guide and the required permissions.

#### Macros

<div className="plugin-pack-macros">

| Macro | Default value | Description |
|-------|---------------|-------------|
| `WARNING-EMAILS-SENT` |  | Threshold warning emails sent |
| `WARNING-EMAILS-DELIVERED` |  | Threshold warning emails delivered |
| `WARNING-EMAILS-SPAM` |  | Threshold warning emails spam |
| `WARNING-EMAILS-REJECTED` |  | Threshold warning emails rejected |
| `CRITICAL-EMAILS-SENT` |  | Threshold critical emails sent |
| `CRITICAL-EMAILS-DELIVERED` |  | Threshold critical emails delivered |
| `CRITICAL-EMAILS-SPAM` |  | Threshold critical emails spam |
| `CRITICAL-EMAILS-REJECTED` |  | Threshold critical emails rejected |
| `DIMENSION` |  | Set SES dimensions (can be defined multiple times). Syntax: --dimension='DimensionName1=Value1' --dimension='DimensionName2=Value2' |

</div>

#### Metrics

<div className="plugin-pack-macros">

| Metric | Unit | Description | Threshold macros |
|--------|------|-------------|------------------|
| `ses.emails.sent.count` |  | number of sent emails | `WARNING-EMAILS-SENT`, `CRITICAL-EMAILS-SENT` |
| `ses.emails.delivered.count` |  | number of emails successfully delivered | `WARNING-EMAILS-DELIVERED`, `CRITICAL-EMAILS-DELIVERED` |
| `ses.emails.rejected.rate` |  | rate of rejected sent emails | `WARNING-EMAILS-REJECTED`, `CRITICAL-EMAILS-REJECTED` |
| `ses.emails.spam.rate` |  | rate of sent emails marked as spam | `WARNING-EMAILS-SPAM`, `CRITICAL-EMAILS-SPAM` |

</div>

## Description

### AWS EC2 instance monitoring
protocols used: awscli, Rest API

- CPU usage
- Disk IO
- Network
- Instance status

## Prerequisites

The plugin pack retrieves the metrics through the AWS API (Amazon CloudWatch). Before you can monitor the resources, you need an
AWS user with the required read permissions and its credentials (*Access Key ID* and *Secret Access Key*), and the *region* of the resources.

See [AWS Prerequisites](/monitoringplugins/cloud/aws/aws-prerequisites) for a step-by-step guide and the required permissions.

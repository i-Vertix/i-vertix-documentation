## Prerequisites

The plugin pack retrieves the metrics through the AWS API (Amazon CloudWatch). Before you can monitor the resources, you need an
AWS user with the required read permissions and its credentials (*Access Key ID* and *Secret Access Key*), and the *region* of the resources.

See [AWS Prerequisites](/monitoringplugins/cloud/aws/aws-prerequisites) for a step-by-step guide and the required permissions.

#### Macros

<div className="plugin-pack-macros">

| Macro | Default value | Description |
|-------|---------------|-------------|
| `EXTRA-OPTS` | `--verbose` | Additional options appended to the plugin command line (host level). |
| `TIMEFRAME` | `300` | Set timeframe in seconds |
| `WARNING-PACKETS-DROP-BLACKHOLE` | `500` | Threshold warning packets drop blackhole |
| `CRITICAL-PACKETS-DROP-BLACKHOLE` | `1000` | Threshold critical packets drop blackhole |
| `FILTER-GATEWAY` |  | Filter on a specific TransitGateway ID. This filter is based on the "TransitGatewayId" attribute of the gateway |
| `FILTER-METRIC` |  | Filter on a specific metric. Can be: BytesIn, BytesOut, PacketsIn, PacketsOut, PacketDropCountBlackhole, PacketDropCountNoRoute |
| `WARNING-BYTES-IN` |  | Threshold warning bytes in |
| `WARNING-BYTES-OUT` |  | Threshold warning bytes out |
| `WARNING-PACKETS-IN` |  | Threshold warning packets in |
| `WARNING-PACKETS-OUT` |  | Threshold warning packets out |
| `WARNING-PACKETS-DROP-NOROUTE` |  | Threshold warning packets drop no route |
| `CRITICAL-BYTES-IN` |  | Threshold critical bytes in |
| `CRITICAL-BYTES-OUT` |  | Threshold critical bytes out |
| `CRITICAL-PACKETS-IN` |  | Threshold critical packets in |
| `CRITICAL-PACKETS-OUT` |  | Threshold critical packets out |
| `CRITICAL-PACKETS-DROP-NOROUTE` |  | Threshold critical packets drop no route |
| `STATISTIC` |  | Set cloudwatch statistics (Can be: 'minimum', 'maximum', 'average', 'sum') |

</div>

#### Metrics

<div className="plugin-pack-macros">

| Metric | Unit | Description | Threshold macros |
|--------|------|-------------|------------------|
| `gateway.traffic.in.bytes` | `B` | Bytes In | `WARNING-BYTES-IN`, `CRITICAL-BYTES-IN` |
| `gateway.traffic.out.bytes` | `B` | Bytes Out | `WARNING-BYTES-OUT`, `CRITICAL-BYTES-OUT` |
| `gateway.packets.in.count` |  | Packets Received (In) | `WARNING-PACKETS-IN`, `CRITICAL-PACKETS-IN` |
| `gateway.packets.out.count` |  | Packets Sent (Out) | `WARNING-PACKETS-OUT`, `CRITICAL-PACKETS-OUT` |
| `gateway.packets.blackholedropped.count` |  | Packets Drop Blackhole | `WARNING-PACKETS-DROP-BLACKHOLE`, `CRITICAL-PACKETS-DROP-BLACKHOLE` |
| `gateway.packets.noroutedropped.count` |  | Packets Drop No Route | `WARNING-PACKETS-DROP-NOROUTE`, `CRITICAL-PACKETS-DROP-NOROUTE` |

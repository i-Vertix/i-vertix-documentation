## Description

Monitors AWS Network Load Balancers through Amazon CloudWatch: the number of healthy and unhealthy targets per target group.

The plugin pack provides these checks:

* [Targets health](#cloud-aws-elb-network-targets-health)

## Prerequisites

The plugin pack retrieves the metrics through the AWS API (Amazon CloudWatch). Before you can monitor the resources, you need an
AWS user with the required read permissions and its credentials (*Access Key ID* and *Secret Access Key*), and the *region* of the resources.

See [AWS Prerequisites](/monitoringplugins/cloud/aws/aws-prerequisites) for a step-by-step guide and the required permissions.

#### Macros

<div className="plugin-pack-macros">

| Macro | Default value | Description |
|-------|---------------|-------------|
| `STATISTIC` | `average` | Default statistic: 'average' / Most useful statistics: 'average', 'minimum', 'maximum' |
| `CRITICAL-UNHEALTHYHOSTCOUNT` | `0` | Threshold critical unhealthy host count |
| `PERIOD` | `60` | Set period in seconds. |
| `TIMEFRAME` | `300` | Set timeframe in seconds. |
| `FILTER-METRIC` |  | Filter metrics (Can be: 'HealthyHostCount', 'UnHealthyHostCount') (Can be a regexp) |
| `WARNING-HEALTHYHOSTCOUNT` |  | Threshold warning healthy host count |
| `WARNING-UNHEALTHYHOSTCOUNT` |  | Threshold warning unhealthy host count |
| `CRITICAL-HEALTHYHOSTCOUNT` |  | Threshold critical healthy host count |
| `AVAILABILITY-ZONE` |  | Add Availability Zone dimension |
| `TARGET-GROUP` |  | Add target group dimension |

</div>

## Description

Monitors Amazon CloudWatch alarms and any CloudWatch metric of the AWS services, such as EC2, EBS, ELB, RDS, S3 or Lambda, with freely selectable namespaces, dimensions and thresholds.

The plugin pack provides these checks:

* [Cloudwatch Alarm](#cloud-aws-cloudwatch-get-alarms)
* [Cloudwatch Metrics](#cloud-aws-cloudwatch-get-metrics)

## Prerequisites

The plugin pack retrieves the metrics through the AWS API (Amazon CloudWatch). Before you can monitor the resources, you need an
AWS user with the required read permissions and its credentials (*Access Key ID* and *Secret Access Key*), and the *region* of the resources.

See [AWS Prerequisites](/monitoringplugins/cloud/aws/aws-prerequisites) for a step-by-step guide and the required permissions.

<summary>

### Cloudwatch Alarm {/* #cloud-aws-cloudwatch-get-alarms */}

</summary>

#### Macros

<div className="plugin-pack-macros">

| Macro | Default value | Description |
|-------|---------------|-------------|
| `WARNING-STATUS` | `'%{state_value} =~ /INSUFFICIENT_DATA/i'` | Set warning threshold for status (Default: '%\{state_value\} =~ /INSUFFICIENT_DATA/i') Can used special variables like: %\{alarm_name\}, %\{state_value\}, %\{metric_name\}, %\{last_update\} |
| `CRITICAL-STATUS` | `'%{state_value} =~ /ALARM/i'` | Set critical threshold for status (Default: '%\{state_value\} =~ /ALARM/i'). Can used special variables like: %\{alarm_name\}, %\{state_value\}, %\{metric_name\}, %\{last_update\} |
| `FILTER-ALARM-NAME` |  | Filter by alarm name (can be a regexp) |

</div>

</details>

<details className="plugin-pack-details">
<summary>

### Cloudwatch Metrics {/* #cloud-aws-cloudwatch-get-metrics */}

</summary>

#### Macros

<div className="plugin-pack-macros">

| Macro | Default value | Description |
|-------|---------------|-------------|
| `PERIOD` | `60` | Set period in seconds |

| `STATISTIC` | `average` | Set cloudwatch statistics (Can be: 'minimum', 'maximum', 'average', 'sum') |
| `DIMENSION1` |  | Set cloudwatch dimension (Required) |
| `METRIC` |  | Set cloudwatch metrics (Required) |
| `WARNING-METRIC` |  | Threshold warning metric |
| `CRITICAL-METRIC` |  | Threshold critical metric |
| `DIMENSION2` |  | Set second cloudwatch dimension |

</div>

</details>

## Description

Monitors Amazon SNS topics through Amazon CloudWatch: notifications published, delivered, failed and filtered out.

The plugin pack provides these checks:

* [Notifications](#cloud-aws-sns-notifications)

## Prerequisites

The plugin pack retrieves the metrics through the AWS API (Amazon CloudWatch). Before you can monitor the resources, you need an
AWS user with the required read permissions and its credentials (*Access Key ID* and *Secret Access Key*), and the *region* of the resources.

See [AWS Prerequisites](/monitoringplugins/cloud/aws/aws-prerequisites) for a step-by-step guide and the required permissions.

#### Macros

<div className="plugin-pack-macros">

| Macro | Default value | Description |
|-------|---------------|-------------|
| `TOPIC-NAME` |  | Filter on a specific SNS topic (Can be multiple, one instance per --topic-name option). Example: --topic-name="my_sns_topic_1" --topic-name="my_sns_topic_2" |
| `FILTER-METRIC` |  | Filter metrics (Can be: 'NumberOfMessagesPublished', 'NumberOfNotificationsDelivered', 'NumberOfNotificationsFailed', 'NumberOfNotificationsFilteredOut'). (Can be a regexp) |
| `WARNING-NOTIFICATIONS-PUBLISHED` |  | Threshold warning notifications published |
| `WARNING-NOTIFICATIONS-DELIVERED` |  | Threshold warning notifications delivered |
| `WARNING-NOTIFICATIONS-FAILED` |  | Threshold warning notifications failed |
| `WARNING-NOTIFICATIONS-FILTERED` |  | Threshold warning notifications filtered |
| `CRITICAL-NOTIFICATIONS-PUBLISHED` |  | Threshold critical notifications published |
| `CRITICAL-NOTIFICATIONS-DELIVERED` |  | Threshold critical notifications delivered |
| `CRITICAL-NOTIFICATIONS-FAILED` |  | Threshold critical notifications failed |
| `CRITICAL-NOTIFICATIONS-FILTERED` |  | Threshold critical notifications filtered |

</div>

#### Metrics

<div className="plugin-pack-macros">

| Metric | Unit | Description | Threshold macros |
|--------|------|-------------|------------------|
| `sns.notifications.published.count` |  | number of notifications published | `WARNING-NOTIFICATIONS-PUBLISHED`, `CRITICAL-NOTIFICATIONS-PUBLISHED` |
| `sns.notifications.delivered.count` |  | number of notifications delivered | `WARNING-NOTIFICATIONS-DELIVERED`, `CRITICAL-NOTIFICATIONS-DELIVERED` |
| `sns.notifications.failed.count` |  | number of notifications failed | `WARNING-NOTIFICATIONS-FAILED`, `CRITICAL-NOTIFICATIONS-FAILED` |
| `sns.notifications.filtered.count` |  | number of notifications filtered | `WARNING-NOTIFICATIONS-FILTERED`, `CRITICAL-NOTIFICATIONS-FILTERED` |

</div>

</details>

## Description

Monitors Kubernetes clusters through the Kubernetes API: nodes, pods, deployments, daemonsets, statefulsets, replicasets, cronjobs, persistent volumes, resource quotas and cluster events.

The plugin pack provides these checks:

* [Cluster events](#cloud-kubernetes-api-cluster-events)
* [Cronjob status](#cloud-kubernetes-api-cronjob-status)
* [Daemonset status](#cloud-kubernetes-api-daemonset-status)
* [Deployment status](#cloud-kubernetes-api-deployment-status)
* [Node status](#cloud-kubernetes-api-node-status)
* [Node usage](#cloud-kubernetes-api-node-usage)
* [Persistent Volume status](#cloud-kubernetes-api-persistentvolume-status)
* [Pod status](#cloud-kubernetes-api-pod-status)
* [Pod usage](#cloud-kubernetes-api-pod-usage)
* [Replicaset status](#cloud-kubernetes-api-replicaset-status)
* [Replication Controller status](#cloud-kubernetes-api-replicationcontroller-status)
* [Resource quota status](#cloud-kubernetes-api-resourcequota-status)
* [Statefulset status](#cloud-kubernetes-api-statefulset-status)

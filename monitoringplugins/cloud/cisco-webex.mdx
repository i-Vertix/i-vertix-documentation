## Description

Monitors Cisco Webex through the Webex API: the status of devices, the health of workspaces and the cache generation.

The plugin pack provides these checks:

* [Cache generation](#cloud-cisco-webex-restapi-cache)
* [Device status](#cloud-cisco-webex-restapi-personal-device-status) (`cloud-cisco-webex-restapi-personal-device-status`)
* [Device status](#cloud-cisco-webex-restapi-workspace-device-status) (`cloud-cisco-webex-restapi-workspace-device-status`)
* [Workspace health](#cloud-cisco-webex-restapi-workspace-health)

## Discovery

### Host Discovery

The hosts of this plugin pack are found by these host discoveries:

* [Cisco Webex](/monitoring/monitoring-resources/discovery/common-discovery#cisco-webex)

### Service Discovery

The service discovery creates one service per discovered object, with these rules:

| Service template | Service name |
|------------------|--------------|
| [Device status](#cloud-cisco-webex-restapi-workspace-device-status) | `<display_name> - <product> - <serial> - device status` |
| [Device status](#cloud-cisco-webex-restapi-workspace-device-status) | `<display_name> - <product> - <serial> - device status` |

See [Service Discovery](/monitoring/monitoring-resources/discovery/service-discovery) for how to run it.

## Description

Monitors OpenShift clusters through the OpenShift API: cluster operators, cluster version, projects and routes.

The plugin pack provides these checks:

* [Cluster operators](#cloud-openshift-api-clusteroperators)
* [Cluster version](#cloud-openshift-api-clusterversion)
* [Projects](#cloud-openshift-api-projects)
* [Routes](#cloud-openshift-api-routes)

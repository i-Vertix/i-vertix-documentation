## Description

Monitors VMware VeloCloud SD-WAN through the VeloCloud API: edge and link status, link usage, edge quality of experience, and traffic per application and category.

The plugin pack provides these checks:

* [Application usage](#cloud-vmware-velocloud-restapi-application-usage)
* [Category usage](#cloud-vmware-velocloud-restapi-category-usage)
* [Edge QoE](#cloud-vmware-velocloud-restapi-edge-qoe)
* [Edge status](#cloud-vmware-velocloud-restapi-edge-status)
* [Link status](#cloud-vmware-velocloud-restapi-link-status)
* [Link usage](#cloud-vmware-velocloud-restapi-link-usage)

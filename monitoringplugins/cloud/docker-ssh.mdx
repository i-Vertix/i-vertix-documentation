## Description

Monitors Docker containers through SSH: container status, CPU and memory usage, disk throughput and network traffic.

The plugin pack provides these checks:

* [Docker Container status](#cloud-docker-local-container-status)
* [Docker Container usage](#cloud-docker-local-container-usage)

|-------|---------------|-------------|
| `SSH-BACKEND` | `sshcli` | Define the backend you want to use. It can be: `sshcli` (default for most plugins), `plink` and `libssh`. *(not used by the check command)* |
| `SSH-PASSWORD` | *(password)* | Define the password associated with the user name. Cannot be used with the `sshcli` backend. Warning: using a password is not recommended. Use `--ssh-priv-key` instead. *(not used by the check command)* |

| `WARNING-WRITE-THROUGHPUT` |  | Warning threshold Write throughput (b/s) |
| `WARNING-TRAFFIC-IN` |  | Warning threshold Traffic in |
| `WARNING-TRAFFIC-OUT` |  | Warning threshold Traffic out |
| `CRITICAL-READ-THROUGHPUT` |  | Critical threshold Memory utilization (%) |
| `CRITICAL-WRITE-THROUGHPUT` |  | Critical threshold Write throughput (b/s) |
| `CRITICAL-TRAFFIC-IN` |  | Critical threshold Traffic in |
| `CRITICAL-TRAFFIC-OUT` |  | Critical threshold Traffic out |

#### Metrics

<div className="plugin-pack-macros">

|--------|------|-------------|------------------|

| `container.memory.usage.bytes` | `B` |  | `WARNING-MEMORY`, `CRITICAL-MEMORY` |
| `container.disk.throughput.read.bytespersecond` | `B/s` | disk read throughput:  /s | `WARNING-READ-THROUGHPUT`, `CRITICAL-READ-THROUGHPUT` |

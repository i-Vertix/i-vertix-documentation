## Description

Monitors Microsoft Office 365 through the Microsoft Graph API: Exchange mail activity and mailbox usage, OneDrive, SharePoint and Teams usage and activity, Azure AD directory size and management service status.

The plugin pack provides these checks:

* [Azure AD - Directory size usage](#cloud-microsoft-office365-azuread-directory-size-usage)
* [O365 Exchange eMail activity](#cloud-microsoft-office365-exchange-email-activity)
* [O365 Exchange Mailbox usage](#cloud-microsoft-office365-exchange-mailbox-usage)
* [O365 Management Application credentials](#cloud-microsoft-office365-management-app-credentials)
* [O365 Management Service status](#cloud-microsoft-office365-management-service-status)
* [O365 Management subscriptions](#cloud-microsoft-office365-management-subscriptions)
* [O365 Onedrive Site usage](#cloud-microsoft-office365-onedrive-site-usage)
* [O365 Onedrive Users activity](#cloud-microsoft-office365-onedrive-users-activity)
* [O365 Sharepoint Site usage](#cloud-microsoft-office365-sharepoint-site-usage)
* [O365 Sharepoint User activity](#cloud-microsoft-office365-sharepoint-user-activity)
* [O365 Teams Device usage](#cloud-microsoft-office365-teams-device-usage)
* [O365 Teams User activities](#cloud-microsoft-office365-teams-user-activities)

| `WARNING-STATUS` | `'%{used} > %{issue_warning_quota}'` | Set warning threshold for status (Default: '%\{used\} > %\{issue_warning_quota\}'). Can used special variables like: %\{used\}, %\{issue_warning_quota\}, %\{prohibit_send_quota\}, %\{prohibit_send_receive_quota\} |

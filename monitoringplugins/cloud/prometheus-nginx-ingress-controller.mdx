## Description

Monitors NGINX ingress controllers through Prometheus: connections and request rates, including response codes per namespace.

The plugin pack provides these checks:

* [nginx ingresscontroller connections](#cloud-prometheus-direct-nginxingresscontroller-connections)
* [nginx ingresscontroller requests](#cloud-prometheus-direct-nginxingresscontroller-requests)

## Description

Monitors Docker through the Docker REST API: CPU, memory, disk I/O and network usage of containers, the container states of a node and the tasks and replicas of Swarm services.

The plugin pack provides these checks:

* [Docker Container usage](#cloud-docker-restapi-container-usage)
* [Docker Node status](#cloud-docker-restapi-node-status)
* [Docker Service status](#cloud-docker-restapi-service-status)

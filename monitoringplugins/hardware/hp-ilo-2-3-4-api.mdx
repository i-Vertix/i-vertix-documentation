## Description

Monitors HP ProLiant servers with iLO 2, 3 or 4 through the iLO XML API: the status of the hardware components.

The plugin pack provides these checks:

* [Hardware status](#hardware-server-hp-ilo-xmlapi-hardware)

## Discovery

### Host Discovery

The hosts of this plugin pack are found by these host discoveries:

* [Network Scan](/monitoring/monitoring-resources/discovery/host-discovery)

#### Macros

<div className="plugin-pack-macros">

| Macro | Default value | Description |
|-------|---------------|-------------|
| `THRESHOLD-OVERLOAD` | `'nic,OK,other'` | Set to overload default threshold values (syntax: section,[instance,]status,regexp) It used before default thresholds (order stays). Example: --threshold-overload='fan,OK,degraded' |
| `COMPONENT` |  | Which component to check (Default: '.*'). Can be: 'fan', 'temperature', 'vrm', 'psu', 'cpu', 'memory', 'nic', 'battery', 'ctrl', 'driveencl', 'pdrive', 'ldrive', 'bios' |
| `FILTER` |  | Exclude some parts (comma seperated list) (Example: --filter=temperature --filter=fan) Can also exclude specific instance: --filter= |
| `WARNING` |  | Set warning threshold for 'temperature', 'fan' (syntax: type,regexp,threshold) Example: --warning='temperature,.*,30' |
| `CRITICAL` |  | Set critical threshold for 'temperature', 'fan' (syntax: type,regexp,threshold) Example: --critical='temperature,.*,50' |

</div>

</details>

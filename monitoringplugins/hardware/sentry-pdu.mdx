## Description

Monitors Sentry PDUs through SNMP: infeeds, tower status, system power, connected sensors and the uptime.

The plugin pack provides these checks:

* [Infeeds](#hardware-pdu-sentry-snmp-infeeds)
* [Sensors](#hardware-pdu-sentry-snmp-sensors)
* [System Power](#hardware-pdu-sentry-snmp-system-power)
* [Tower Status](#hardware-pdu-sentry-snmp-tower-status)
* [Uptime](#hardware-pdu-sentry-snmp-uptime)

## Discovery

## Description

Monitors Avaya Application Enablement Services servers through SNMP: CPU, load, memory and swap usage, storage, services and network interfaces.

The plugin pack provides these checks:

* [CPU](#hardware-telephony-avaya-aes-snmp-cpu)
* [Interfaces](#hardware-telephony-avaya-aes-snmp-interfaces)
* [Load](#hardware-telephony-avaya-aes-snmp-load)
* [Memory - Swap](#hardware-telephony-avaya-aes-snmp-memory)
* [Services](#hardware-telephony-avaya-aes-snmp-services)
* [Storage](#hardware-telephony-avaya-aes-snmp-storage)
* [Uptime](#os-linux-snmp-uptime)

## Discovery

### Service Discovery

The service discovery creates one service per discovered object, with these rules:

| Service template | Service name |
|------------------|--------------|
| [Interfaces](#hardware-telephony-avaya-aes-snmp-interfaces) | `Interface - <name>` |
| [Storage](#hardware-telephony-avaya-aes-snmp-storage) | `Storage - <name>` |

See [Service Discovery](/monitoring/monitoring-resources/discovery/service-discovery) for how to run it.

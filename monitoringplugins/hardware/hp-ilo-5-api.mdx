## Description

Monitors HP ProLiant and HPE servers with iLO 5 through the iLO REST API: the status of the hardware components.

The plugin pack provides these checks:

* [Hardware status](#hardware-server-hp-ilo-restapi-hardware)

## Discovery

### Host Discovery

The hosts of this plugin pack are found by these host discoveries:

* [Network Scan](/monitoring/monitoring-resources/discovery/host-discovery)

#### Macros

<div className="plugin-pack-macros">

| Macro | Default value | Description |
|-------|---------------|-------------|
| `COMPONENT` |  | Which component to check (Default: '.*'). Can be: 'chassis', 'device', 'fan', 'psu', 'temperature' |
| `FILTER` |  | Exclude some parts (comma seperated list) Can also exclude specific instance: --filter='fan,1.2' |
| `WARNING` |  | Set warning threshold for 'temperature', 'fan', 'psu' (syntax: type,regexp,threshold) Example: --warning='temperature,.*,30' |
| `CRITICAL` |  | Set critical threshold for 'temperature', 'fan', 'psu' (syntax: type,regexp,threshold) Example: --critical='temperature,.*,50' |
| `NO-COMPONENT` |  | Define the expected status if no components are found (default: critical) |
| `THRESHOLD-OVERLOAD` |  | Use this option to override the status returned by the plugin when the status label matches a regular expression (syntax: section,[instance,]status,regexp). Example: --threshold-overload='chassis.state,WARNING,inTest' |

</div>

</details>

## Description

Monitors APC automatic transfer switches (ATS) through SNMP: device status, input lines, output lines and banks, and uptime.

The plugin pack provides these checks:

* [Device status](#hardware-ats-apc-snmp-device-status)
* [Input lines](#hardware-ats-apc-snmp-input-lines)
* [Output banks](#hardware-ats-apc-snmp-output-banks)
* [Output lines](#hardware-ats-apc-snmp-output-lines)
* [Uptime](#hardware-ats-apc-snmp-uptime)

| Macro | Default value | Description |

| `EXTRA-OPTS` |  | Additional options appended to the plugin command line (host level). |
| `SNMPAUTH-PASSPHRASE` |  | SNMP v3 only: Pass phrase hashed using the authentication protocol defined in the --authprotocol option. |

| `SNMPPRIV-PROTOCOL` |  | SNMP v3 only: Privacy protocol (`privProtocol`) used to encrypt messages. Supported protocols are: DES\|AES and since net-snmp 5.9.1: AES192\|AES192C\|AES256\|AES256C. |
| `SNMPUSERNAME` |  | SNMP v3 only: User name (`securityName`). |
| `SNMPVERSION` |  | Version of the SNMP protocol. 1 for SNMP v1 (default), 2 for SNMP v2c, 3 for SNMP v3. |
| `SNMPTIMEOUT` |  | Time to wait before sending the request again if no reply has been received, in seconds (default: 1). See also --snmp-retries. |

</div>

<div className="plugin-pack-macros">

| Macro | Default value | Description |
|-------|---------------|-------------|
| `COMPONENT` |  | Which component to check (Default: '.*'). Can be: 'entity' |
| `FILTER` |  | Exclude some parts (comma seperated list) (Example: --filter=entity) Can also exclude specific instance: --filter=entity,CommStatus |
| `THRESHOLD-OVERLOAD` |  | Set to overload default threshold values (syntax: section,[instance,]status,regexp) It used before default thresholds (order stays). Example: --threshold-overload='entity,SourceBStatus,WARNING,fail' |
| `NO-COMPONENT` |  | Define the expected status if no components are found (default: critical) |

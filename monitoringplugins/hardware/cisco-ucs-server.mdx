## Description

Monitors Cisco UCS servers through SNMP: equipment status, faults, audit logs, management entities and service profiles.

The plugin pack provides these checks:

* [Audit logs](#hardware-server-cisco-ucs-snmp-audit-logs)
* [Equipment](#hardware-server-cisco-ucs-snmp-equipment)
* [Faults](#hardware-server-cisco-ucs-snmp-faults)
* [Management entities](#hardware-server-cisco-ucs-snmp-mgmt-entities)
* [Service Profiles](#hardware-server-cisco-ucs-snmp-service-profile)
* [Uptime](#os-linux-snmp-uptime)

### Equipment {/* #hardware-server-cisco-ucs-snmp-equipment */}

</summary>

#### Macros

<div className="plugin-pack-macros">

| Macro | Default value | Description |
|-------|---------------|-------------|
| `COMPONENT` | `.*` | Which component to check (Default: '.*'). Can be: 'fan', 'psu', 'chassis', 'iocard', 'blade', 'fex', 'cpu', 'memory', 'localdisk' |
| `FILTER` |  | Exclude some parts (comma seperated list) (Example: --filter=fan --filter=psu) Can also exclude specific instance: --filter=fan,/sys/chassis-7/fan-module-1-7/fan-1 |
| `THRESHOLD-OVERLOAD` |  | Set to overload default threshold values (syntax: section,[instance,]status,regexp) It used before default thresholds (order stays). Example: --threshold-overload='fan.operability,OK,poweredOff\|removed' |
| `ABSENT-PROBLEM` |  | Return an error if a component is not 'present' (default is skipping). It can be set globally or for a specific instance: --absent-problem='component_name' or --absent-problem='component_name,instance_value' |
| `NO-COMPONENT` |  | Define the expected status if no components are found (default: critical) |

</div>

</details>

## Description

Monitors Axentia e-paper displays through the Axentia REST API: server status, the health of the displays and their operational status.

The plugin pack provides these checks:

* [Display health](#hardware-devices-axentia-epaper-restapi-health)
* [Operational display status](#hardware-devices-axentia-epaper-restapi-operational-display-status)
* [Server status](#hardware-devices-axentia-epaper-restapi-server-status)

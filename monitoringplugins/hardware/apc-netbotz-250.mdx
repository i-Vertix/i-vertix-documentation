## Description

Monitors APC NetBotz 250 environment monitoring devices through SNMP: the connected sensors and the uptime.

The plugin pack provides these checks:

* [Sensors](#hardware-sensors-apc-snmp-sensors)
* [Uptime](#os-linux-snmp-uptime)

#### Macros

<div className="plugin-pack-macros">

| Macro | Default value | Description |
|-------|---------------|-------------|
| `COMPONENT` | `.*` | Which component to check (Default: '.*'). Can be: 'temperature', 'humidity', 'fluid'. |
| `FILTER` |  | Exclude some parts (comma seperated list) (Ex.: --filter=temperature --filter=humidity). Can also exclude specific instance: --filter=temperature,1 |
| `WARNING` |  | Set warning threshold for 'temperature', 'humidity' (syntax: type,regexp,threshold). Ex.: --warning='temperature,.*,30' |
| `CRITICAL` |  | Set critical threshold for 'temperature', 'humidity' (syntax: type,regexp,threshold). Ex.: --warning='temperature,.*,50' |
| `THRESHOLD-OVERLOAD` |  | Set to overload default threshold values (syntax: section,[instance,]status,regexp) It used before default thresholds (order stays). Ex.: --threshold-overload='temperature,CRITICAL,^(?!(warning)$)' |
| `NO-COMPONENT` |  | Define the expected status if no components are found (default: critical) |

</div>

</details>

## Description

Monitors APC UPS devices through SNMP: battery charge, runtime and temperature, input and output lines, sensors, time synchronization and uptime.

The plugin pack provides these checks:

* [Battery status](#hardware-ups-apc-snmp-battery-status)
* [Input lines](#hardware-ups-apc-snmp-input-lines)
* [NTP-time](#hardware-ups-apc-snmp-time)
* [Output lines](#hardware-ups-apc-snmp-output-lines)
* [Sensors](#hardware-ups-apc-snmp-sensors)
* [Uptime](#hardware-ups-apc-snmp-uptime)

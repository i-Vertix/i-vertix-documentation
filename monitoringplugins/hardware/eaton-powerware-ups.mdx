## Description

Monitors Eaton Powerware UPS devices through SNMP: alarms, battery status, environment, input and output lines and the output source.

The plugin pack provides these checks:

* [Alarms](#hardware-ups-powerware-snmp-alarms)
* [Battery Status](#hardware-ups-powerware-snmp-battery-status)
* [Environment](#hardware-ups-powerware-snmp-enironment)
* [Input Lines](#hardware-ups-powerware-snmp-input-lines)
* [Output Lines](#hardware-ups-powerware-snmp-output-lines)
* [Output Source](#hardware-ups-powerware-snmp-output-source)
* [Uptime](#os-linux-snmp-uptime)

### Battery Status {/* #hardware-ups-powerware-snmp-battery-status */}

</summary>

#### Macros

<div className="plugin-pack-macros">

| Macro | Default value | Description |
|-------|---------------|-------------|
| `UNKNOWN-STATUS` | `'%{status} =~ /unknown/i'` | Set unknown threshold for status (Default: '%\{status\} =~ /unknown/i'). Can used special variables like: %\{status\} |
| `WARNING-STATUS` | `'%{status} =~ /batteryDischarging/i'` | Set warning threshold for status (Default: '%\{status\} =~ /batteryDischarging/i'). Can used special variables like: %\{status\} |
| `WARNING-CHARGE-REMAINING` | `40:` | Threshold warning charge remaining (%) |
| `CRITICAL-CHARGE-REMAINING` | `20:` | Threshold critical charge remaining (%) |
| `FILTER-COUNTERS` |  | Only display some counters (regexp can be used). Example: --filter-counters='status\|current' |
| `WARNING-CHARGE-MINUTES` |  | Threshold warning charge remaining (min) |
| `WARNING-CURRENT` |  | Threshold warning current (A) |
| `WARNING-VOLTAGE` |  | Threshold warning voltage (V) |
| `CRITICAL-STATUS` |  | Set critical threshold for status (Default: ''). Can used special variables like: %\{status\} |
| `CRITICAL-CHARGE-MINUTES` |  | Threshold critical charge remaining (min) |
| `CRITICAL-CURRENT` |  | Threshold critical current (A) |
| `CRITICAL-VOLTAGE` |  | Threshold critical voltage (V) |

</div>

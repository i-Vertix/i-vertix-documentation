## Description

Monitors MessPC Ethernetbox devices through SNMP: the connected sensors (temperature, humidity, smoke, contact, brightness, voltage) and the uptime.

The plugin pack provides these checks:

* [Sensors](#hardware-sensors-messpc-ethernetbox-snmp-sensors)
* [Uptime](#hardware-sensors-messpc-ethernetbox-snmp-uptime)

| `CRITICAL-HUMIDITY` | `30:65` | Critical threshold for humidity in % |
| `CRITICAL-SMOKE` | `1` | Critical threshold for smoke. Can be 0 or 1 |

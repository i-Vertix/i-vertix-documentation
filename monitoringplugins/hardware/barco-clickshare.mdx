## Description

Monitors Barco ClickShare devices through the device API: overall device status, process status, CPU, PCIe and SIO temperatures and the CPU fan speed.

The plugin pack provides these checks:

* [Device status](#hardware-devices-barco-cs-restapi-device)

#### Macros

<div className="plugin-pack-macros">

| Macro | Default value | Description |
|-------|---------------|-------------|
| `WARNING-DEVICE-STATUS` | `'%{status} =~ /warning/'` | Set warning threshold (default: '%\{status\} =~ /warning/'). You can use the following variables: %\{status\} |
| `CRITICAL-DEVICE-STATUS` | `'%{status} =~ /error/'` | Set critical threshold (default: '%\{status\} =~ /error/'). You can use the following variables: %\{status\} |
| `WARNING-PROCESS-STATUS` |  | Set warning threshold. You can use the following variables: %\{name\}, %\{status\} |
| `WARNING-CPU-TEMPERATURE` |  | Warning threshold CPU temperature |
| `WARNING-PCIE-TEMPERATURE` |  | Warning threshold PCIE temperature |
| `WARNING-SIO-TEMPERATURE` |  | Warning threshold SIO temperature |
| `WARNING-CPU-FANSPEED` |  | Warning threshold CPU fanspeed (rpm) |
| `CRITICAL-PROCESS-STATUS` |  | Set critical threshold. You can use the following variables: %\{name\}, %\{status\} |
| `CRITICAL-CPU-TEMPERATURE` |  | Critical threshold CPU temperature |
| `CRITICAL-PCIE-TEMPERATURE` |  | Critical threshold PCIE temperature |
| `CRITICAL-SIO-TEMPERATURE` |  | Critical threshold SIO temperature |
| `CRITICAL-CPU-FANSPEED` |  | Critical threshold CPU fanspeed (rpm) |

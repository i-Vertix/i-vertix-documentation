## Description

Monitors Cyberpower PDUs through SNMP: the load of banks and phases (current, power, voltage) and the current and status of the outlets.

The plugin pack provides these checks:

* [CyberPower PDU Load](#hardware-pdu-cyberpower-snmp-load)
* [PDU Outlets](#hardware-pdu-cyberpower-snmp-outlets)
* [Uptime](#os-linux-snmp-uptime)

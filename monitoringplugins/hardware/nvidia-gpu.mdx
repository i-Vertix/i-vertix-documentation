## Description

Monitors NVIDIA GPUs over SSH: GPU, memory, encoder and decoder utilization, BAR1 and framebuffer memory usage and temperature.

The plugin pack provides these checks:

* [NVIDIA GPU statistics](#hardware-devices-nvidia-gpu-smi-stats)

## Description

Monitors XPPC Phoenixtec UPS devices through SNMP: battery status (charge, temperature) and the input and output lines.

The plugin pack provides these checks:

* [Battery Status](#hardware-ups-phoenixtec-snmp-battery-status)
* [Input Lines](#hardware-ups-phoenixtec-snmp-input-lines)
* [Output Lines](#hardware-ups-phoenixtec-snmp-output-lines)
* [Uptime](#os-linux-snmp-uptime)

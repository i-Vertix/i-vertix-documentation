## Description

Monitors Socomec Netvision UPS devices through SNMP: alarms, battery status (charge, temperature) and the input and output lines.

The plugin pack provides these checks:

* [Alarms](#hardware-ups-socomec-snmp-alarms)
* [Battery status](#hardware-ups-socomec-snmp-battery)
* [Input lines](#hardware-ups-socomec-snmp-input-lines)
* [Output lines](#hardware-ups-socomec-snmp-output-lines)
* [Uptime](#os-linux-snmp-uptime)

| Macro | Default value | Description |
|-------|---------------|-------------|
| `SNMPVERSION` |  | SNMP version |
| `SNMPCOMMUNITY` |  | SNMP community |
| `SNMPUSERNAME` |  | SNMP v3 only: User name (`securityName`). |
| `SNMPAUTH-PASSPHRASE` |  | SNMP v3 only: Pass phrase hashed using the authentication protocol defined in the --authprotocol option. |
| `SNMPAUTH-PROTOCOL` |  | SNMP v3 only: Authentication protocol: MD5\|SHA. Since net-snmp 5.9.1: SHA224\|SHA256\|SHA384\|SHA512. |
| `SNMPPRIV-PASSPHRASE` |  | SNMP v3 only: Privacy pass phrase (`privPassword`) to encrypt messages using the protocol defined in the --privprotocol option. |
| `SNMPPRIV-PROTOCOL` |  | SNMP v3 only: Privacy protocol (`privProtocol`) used to encrypt messages. Supported protocols are: DES\|AES and since net-snmp 5.9.1: AES192\|AES192C\|AES256\|AES256C. |

#### Macros

<div className="plugin-pack-macros">

| Macro | Default value | Description |
|-------|---------------|-------------|
| `WARNING-CHARGE-REMAINING` | `40:` | Threshold warning battery charge remaining (%) |
| `WARNING-CHARGE-REMAINING-MINUTES` | `30:` | Threshold warning battery charge remaining in minutes |
| `WARNING-TEMPERATURE` | `15:30` | Threshold warning temperature (C) |
| `CRITICAL-CHARGE-REMAINING` | `20:` | Threshold critical battery charge remaining (%) |
| `CRITICAL-CHARGE-REMAINING-MINUTES` | `15:` | Threshold critical battery charge remaining in minutes |
| `CRITICAL-TEMPERATURE` | `10:40` | Threshold critical temperature (C) |
| `CRITICAL-STATUS` | `'%{status} =~ /depleted\|failure/i'` | Define the conditions to match for the status to be CRITICAL (default: '%\{status\} =~ /depleted\|failure/i'). You can use the following variables: %\{status\} |
| `WARNING-STATUS` | `'%{status} =~ /low/i'` | Define the conditions to match for the status to be WARNING (default: '%\{status\} =~ /low/i'). You can use the following variables: %\{status\} |
| `UNKNOWN-STATUS` | `'%{status} =~ /unknown/i'` | Define the conditions to match for the status to be UNKNOWN (default: '%\{status\} =~ /unknown/i'). You can use the following variables: %\{status\} |
| `WARNING-CURRENT` |  | Threshold warning current (A) |
| `WARNING-VOLTAGE` |  | Threshold warning voltage (V) |
| `CRITICAL-CURRENT` |  | Threshold critical current (A) |
| `CRITICAL-VOLTAGE` |  | Threshold critical voltage (V) |
| `CRITICAL-TEMPERATURE-AMBIENT` |  | Threshold critical ambient temperature (C) |
| `WARNING-TEMPERATURE-AMBIENT` |  | Threshold warning ambient temperature (C) |

</div>

## Description

Monitors Cyberpower UPS devices through SNMP: battery status (charge, voltage, temperature, runtime) and the voltage, frequency and load of the input and output lines.

The plugin pack provides these checks:

* [Battery Status](#hardware-ups-cyberpower-snmp-battery-status)
* [Input Lines](#hardware-ups-cyberpower-snmp-input-lines)
* [Output Lines](#hardware-ups-cyberpower-snmp-output-lines)
* [Uptime](#os-linux-snmp-uptime)

## Discovery

#### Macros

<div className="plugin-pack-macros">

| Macro | Default value | Description |
|-------|---------------|-------------|
| `UNKNOWN-STATUS` | `'%{status} =~ /unknown\|notPresent/i'` | Set warning threshold for status (Default: '%\{status\} =~ /unknown\|notPresent/i'). Can used special variables like: %\{status\} |
| `WARNING-STATUS` | `'%{status} =~ /low/i'` | Set warning threshold for status (Default: '%\{status\} =~ /low/i'). Can used special variables like: %\{status\} |
| `WARNING-CHARGE-REMAINING` | `40:` | Threshold warning charge remaining (%) |
| `WARNING-TEMPERATURE` | `15:30` | Threshold warning temperature (°C) |
| `CRITICAL-CHARGE-REMAINING` | `20:` | Threshold critical charge remaining (%) |
| `CRITICAL-TEMPERATURE` | `10:40` | Threshold critical temperature (°C) |
| `CRITICAL-STATUS` | `'%{replace} =~ /yes/i'` | Set critical threshold for status (Default: '%\{replace\} =~ /yes/i'). Can used special variables like: %\{status\}, %\{replace\} |
| `CRITICAL-BATTERY-LIFE-TIME` | `1:` | Threshold critical battery life time in months |
| `WARNING-BATTERY-LIFE-TIME` | `3:` | Threshold warning battery life time in months |
| `WARNING-VOLTAGE` |  | Threshold warning voltage (V) |
| `CRITICAL-VOLTAGE` |  | Threshold critical voltage (V) |
| `CRITICAL-TIME-ON-BATTERY` |  | Threshold critical time on battery. Use --unit to change the unit |
| `WARNING-TIME-ON-BATTERY` |  | Threshold warning time on battery. Use --unit to change the unit |

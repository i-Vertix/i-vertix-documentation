## Description

Monitors HMS Netbiter Argos systems through the Argos REST API: the sensors and the alerts of the connected devices.

The plugin pack provides these checks:

* [Alerts](#hardware-devices-hms-netbiter-argos-restapi-alerts)
* [Sensors](#hardware-devices-hms-netbiter-argos-restapi-sensors)

## Discovery

### Service Discovery

The service discovery creates one service per discovered object, with these rules:

| Service template | Service name |
|------------------|--------------|
| [Sensors](#hardware-devices-hms-netbiter-argos-restapi-sensors) | `Sensor - <name>` |

See [Service Discovery](/monitoring/monitoring-resources/discovery/service-discovery) for how to run it.

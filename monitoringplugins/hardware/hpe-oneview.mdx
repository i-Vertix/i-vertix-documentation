## Description

Monitors HPE OneView through its REST API: the status of the managed hardware and the space usage of the storage pools.

The plugin pack provides these checks:

* [Hardware](#hardware-server-hp-oneview-restapi-hardware)
* [Storage pools](#hardware-server-hp-oneview-restapi-storage-pools)

## Description

Monitors IBM Hardware Management Consoles over SSH: hardware errors and the LED status of the managed systems.

The plugin pack provides these checks:

* [Hardware errors](#hardware-server-ibm-hmc-ssh-hardware-errors)
* [LED status](#hardware-server-ibm-hmc-ssh-led-status)

#### Macros

<div className="plugin-pack-macros">

| Macro | Default value | Description |
|-------|---------------|-------------|
| `RETENTION` | `1` | Retention of errors in days |
| `HMC-COMMAND` | `lssvcevents` | Hmc command to list events (default: lssvcevents) |
| `FILTER-STATUS` |  | Filter by status ("open" or "closed") (Default : open) |
| `FILTER-PROBLEM-NUMS` |  | Filter by problem number (several number can be specified, separated by coma) |
| `FILTER-SYSTEM` |  | Filter by system. The name may either be the user-defined name for the managed system, or be in the form tttt-mmm*ssssssss, where tttt is the machine type, mmm is the model, and ssssssss is the serial number of the managed system |

</div>

</details>

<details className="plugin-pack-details">
<summary>

### LED status {/* #hardware-server-ibm-hmc-ssh-led-status */}

</summary>

#### Macros

<div className="plugin-pack-macros">

| Macro | Default value | Description |
|-------|---------------|-------------|
| `CRITICAL-PHYSICAL-STATUS` | `'%{ledstate} =~ /on/'` | Set critical threshold (Default: '%\{ledstate\} =~ /on/'). Can used special variables like: %\{ledstate\}, %\{display\} |
| `CRITICAL-VIRTUALLPAR-STATUS` | `'%{ledstate} =~ /on/'` | Set critical threshold (Default: '%\{ledstate\} =~ /on/'). Can used special variables like: %\{ledstate\}, %\{display\} |
| `FILTER-NAME` |  | Filter name (can be a regexp). Format of names: systemname[\:lparname] |
| `WARNING-PHYSICAL-STATUS` |  | Set warning threshold (Default: ''). Can used special variables like: %\{ledstate\}, %\{display\} |
| `WARNING-VIRTUALLPAR-STATUS` |  | Set warning threshold (Default: ''). Can used special variables like: %\{ledstate\}, %\{display\} |

</div>

</details>

## Description

Monitors Sun SPARC Enterprise (SFXXK) servers over SSH: boards, environment and failover status.

The plugin pack provides these checks:

* [Boards](#hardware-server-sun-sfxxk-boards)
* [Environment](#hardware-server-sun-sfxxk-environment)
* [Failover](#hardware-server-sun-sfxxk-failover)


## Host Templates

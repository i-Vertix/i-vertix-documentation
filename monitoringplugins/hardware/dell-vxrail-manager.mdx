## Description

Monitors Dell VxRail clusters through the VxRail Manager REST API: the status of the chassis, power supplies, hosts, NICs and disks.

The plugin pack provides these checks:

* [Chasis](#hardware-server-dell-vxm-chassis)
* [Hosts](#hardware-server-dell-vxm-hosts)
